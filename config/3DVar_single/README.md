# MPAS Temperature Single-Observation 3DVar

This configuration reproduces the Jung et al. (2024) temperature
single-observation test with the static MPAS GEN_BE covariance generated by
the NMC workflow in `config/4DVar_single/nmc.yaml`.

The observation is placed at the MPAS cell nearest 40.4113 degrees north and
38.68 degrees west, on the native model level nearest 800 hPa. The innovation
and observation-error standard deviation are both 1 K. Diagnostics show
temperature, zonal-wind, and meridional-wind increments on the native levels
nearest 675, 800, and 925 hPa.

The 3DVar and 4DVar experiment bundles reference the same fitted GEN_BE file.
The finalized larger-amplitude comparison preserves the fitted horizontal
length scales and applies a standard-deviation multiplier of three. This
changes covariance magnitude without changing the single-observation spatial
correlation structure. Analysis increments are not rescaled after
assimilation.

Run model and JAX workloads inside a scheduler allocation:

```bash
python scripts/run/mpas_3dvar_single/run_assimilation.py \
  --config config/3DVar_single/experiment.yaml

python scripts/plot/plot_mpas_temperature_single_obs_3dvar.py \
  --config config/3DVar_single/experiment.yaml
```

Large NMC samples, fitted GEN_BE parameters, and experiment results are
external artifacts and are not stored in Git. Input and output paths may be
overridden on the command line.
