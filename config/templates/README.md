# Experiment templates

Versioned, named `legoesm run` config YAMLs — the starting point for every
experiment (instead of hand-editing a mega-runner). Each carries an
`experiment:` metadata block:

```yaml
experiment:
  tier: tier1                # tier0..tier3 (research -> operational; see docs/validation/TESTING.md)
  complexity: shallow_water  # ModelComplexity / *Complexity rung
  extent: global             # grids.capability extent (global/regional/double_periodic/column)
  maturity: run_tested       # run_tested | init_only | structurally_validated
  description: "..."
  data: []                   # dataset ids (config/data_catalog.yaml); empty = idealized
  conservation_gates: [mass, energy]   # the matrix PASS/FAIL gates this case asserts
```

Everything below `experiment:` is a standard `legoesm run` config
(`model`/`grid`/`atmosphere`/`physics`/`conservation`/`time`/`output`/`hardware`)
— `Config` ignores the `experiment:` block when resolving to `ExperimentConfig`.

## Layout (by domain/extent; tier is derived from `experiment.tier`)

| Category | Tier(s) | Contents |
|---|---|---|
| `1d/` | tier1 | single-column (SCM) — column extent |
| `2d/` | tier1 | shallow-water (Williamson, Galewsky) |
| `3d_idealized/` | tier1–2 | dry/idealized 3D (Held-Suarez, baroclinic wave, aquaplanet) |
| `global_ocean/` | tier3 | OMIP / global ocean |
| `coupled/` | tier2–3 | coupled & AMIP/ERA5 |

## Use

```bash
python scripts/experiment/validate_templates.py --write-status      # validate all + regen project_status.md
python scripts/experiment/init_experiment.py 2d/williamson2_sw --name w2 --output-dir ./runs/w2 \
    -o grid.resolution=96                                            # resolve + override
```

The canonical per-template run-status table is `project_status.md` (repo root),
auto-generated by `validate_templates.py --write-status`. Reproducibility of a
*run* is the driver's `run_manifest.json` + `legoesm reproduce` — see
`docs/validation/TESTING.md`.
