Findings:

- **Silent no-op off MPAS.** `hard_sat_ice_curve` validates for any grid, but is read only in `_run_mpas`; the spectral/coupled resolver still enables the liquid-only adjustment. Thus a valid non-MPAS config silently does not use the ice curve. [config.py](/work/bd1083/b309178/diffESM/legoesm_pg/legoESM/packages/coupler/legoesm/driver/config.py:630) [physics_pipeline.py](/work/bd1083/b309178/diffESM/legoesm_pg/legoESM/packages/coupler/legoesm/driver/physics_pipeline.py:3193) [model_driver.py](/work/bd1083/b309178/diffESM/legoesm_pg/legoESM/packages/coupler/legoesm/driver/model_driver.py:5955)

- **`q_i` existence is not an ice-scheme capability check.** Kessler has only `q_v/q_c/q_r`, so the fallback deposits liquid `q_c` while heating with \(L_\mathrm{eff}>L_v\). It conserves water but creates energy: \(\Delta(c_pT+L_vq_v)=(1-w)(L_s-L_v)dq>0\). Seifert–Beheng has a placeholder `q_i` slot, but explicitly returns zero ice and ice-number tendencies, so this hook creates orphan cloud ice. Both schemes are allowed by validation. [model_driver.py](/work/bd1083/b309178/diffESM/legoesm_pg/legoESM/packages/coupler/legoesm/driver/model_driver.py:339) [integration.py](/work/bd1083/b309178/diffESM/legoesm_pg/legoESM/packages/atmosphere/legoesm/atmosphere/physics/microphysics/integration.py:603) [seifert_beheng.py](/work/bd1083/b309178/diffESM/legoesm_pg/legoESM/packages/atmosphere/legoesm/atmosphere/physics/microphysics/seifert_beheng.py:263)

- **Ice mass can be created with zero ice number.** The post-step accepts/updates `q_i` but never receives or updates `N_i`. In a freshly ice-free Morrison/Thompson/P3 cell, it can set `q_i>0, N_i=0`; Morrison’s PSD/deposition uses both fields. Landing near saturation also removes the supersaturation that would normally seed nucleation. Deposition onto existing crystals need not alter number, but the zero-number case must be handled. [model_driver.py](/work/bd1083/b309178/diffESM/legoesm_pg/legoESM/packages/coupler/legoesm/driver/model_driver.py:272) [model_driver.py](/work/bd1083/b309178/diffESM/legoesm_pg/legoESM/packages/coupler/legoesm/driver/model_driver.py:6966) [morrison.py](/work/bd1083/b309178/diffESM/legoesm_pg/legoESM/packages/atmosphere/legoesm/atmosphere/physics/microphysics/morrison.py:455)

- **The claimed enthalpy conservation is not the model’s phase enthalpy.** The appropriate Morrison invariant is \(c_pT+L_vq_v-L_fq_i\), not \(c_pT+L_\mathrm{eff}(T_0)q_v\). Even with `q_i`, the increment leaves \((1-w)(L_s-L_v-L_f)dq\neq0\), since the supplied constants differ by 700 J kg⁻¹. [morrison.py](/work/bd1083/b309178/diffESM/legoesm_pg/legoESM/packages/atmosphere/legoesm/atmosphere/physics/microphysics/morrison.py:1190) [constants.py](/work/bd1083/b309178/diffESM/legoesm_pg/legoESM/packages/core/legoesm/constants.py:37)

- **Frozen routing conflicts with the final curve.** The solve evaluates \(w\) at warmed `t_new`, but heating and phase routing use \(w(T_0)\). A cap-sized adjustment from \(T_0\in[268.15,273.15)\) can end above freezing while retaining `q_i`, with no compensating melt/fusion term. This is not a final mixed-phase equilibrium. [\_warm_rain.py](/work/bd1083/b309178/diffESM/legoesm_pg/legoESM/packages/atmosphere/legoesm/atmosphere/physics/microphysics/_warm_rain.py:279) [model_driver.py](/work/bd1083/b309178/diffESM/legoesm_pg/legoESM/packages/coupler/legoesm/driver/model_driver.py:342)

- **Test evidence gap.** The new test forces x64, so it does not exercise the fp32 branch or demonstrate fp32/fp64 parity; it only checks a finite \(d/dq_v\), not the claimed FD agreement for \(T,p\). It also lacks non-MPAS, Kessler fallback, Seifert placeholder, zero-`N_i`, and ramp-crossing cases. [test_hard_sat_ice_curve.py](/work/bd1083/b309178/diffESM/legoesm_pg/legoESM/tests/unit/test_hard_sat_ice_curve.py:18) [test_hard_sat_ice_curve.py](/work/bd1083/b309178/diffESM/legoesm_pg/legoESM/tests/unit/test_hard_sat_ice_curve.py:108)

Non-findings: the separate 40 K helper is reasonable; the frozen-\(L\) residual remains monotone/nondecreasing and the implicit-gradient correction is sound away from intended hard/clip kinks. The 1.1 threshold and log formatting are policy/formatting choices, not static defects. The “exact 5 K” claim also assumes matching `T`/`q_v` dtypes; the driver normally has that, though the public helper does not enforce it.

OVERALL VERDICT: findings remain: silent non-MPAS no-op, invalid phase/moment routing, and thermodynamic-conservation violations.
