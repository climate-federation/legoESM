A hydrostatic sigma-coordinate atmospheric model (levels indexed k=0 at the top,
k=nlev-1 at the surface, layer thickness dsigma_k, surface pressure p_s) applies
this vertical biharmonic filter to temperature AND to every moisture tracer,
with nu = 2.0e-6 1/s, every dynamics timestep:

  Tp     = pad(x, (1,1), mode="reflect")            # inner
  lap    = Tp[:-2] - 2*Tp[1:-1] + Tp[2:]
  lap_p  = pad(lap, (1,1), mode="edge")             # outer, zero-gradient
  bih    = lap_p[:-2] - 2*lap_p[1:-1] + lap_p[2:]
  tend   = -nu * bih

It is a fourth difference on the LEVEL INDEX (no dsigma anywhere). Its docstring
says: "a no-flux boundary -> the column-integrated tendency is ZERO to machine
precision for ANY profile, so the filter dissipates grid-scale variance WITHOUT
spurious column heating/cooling", and the tracer call site says it "conserves
column moisture to machine precision".

The grid used to be uniform (dsigma constant). It is being changed to a
non-uniform grid: layer thicknesses top->bottom, in hPa, at p_s = 985 hPa:

I measure: sum_k(tend_k) = 0 to machine precision on BOTH grids, but
sum_k(tend_k * dsigma_k) is 0 only on the uniform grid. On the new grid, for a
2-delta checkerboard of +-5 K in T and +-1 g/kg in q_v, I get a spurious column
enthalpy sink of -7.86 W/m2 and a spurious column moisture sink of
-0.135 mm/day (linear in the checkerboard amplitude: +-1 K gives -1.57 W/m2).
This is a 100-year climate run whose target top-of-atmosphere energy imbalance
is below 1 W/m2.
