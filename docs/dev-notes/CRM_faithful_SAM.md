## Accepted structural differences (converge in stats)
- Anelastic (SAM) vs compressible (legoESM) — domain-mean budgets + convective stats agree.
- RRTMG vs RRTMGP — both correlated-k; band/gas-optics differ (few W/m²).
- Differentiable ⇒ some SAM hard thresholds → AD-safe sigmoid ramps (codex-validated).
- Tetens/C-C saturation within 0.3%/0.6% of SAM Flatau (220-270K).
- Sponge: explicit `-coeff·w` vs SAM implicit `w/(1+taudamp)` (coeff·dt=0.25 stable).
- **Hyperdiff (iter-54):** SAM has NONE (monotone advection+SGS dissipate the grid scale);
  legoESM's compressible dycore adds a WEAK biharmonic ∇⁴ for the acoustic 2Δx scale,
  dx-aware (`dx_aware_hyperdiff` `K=1e8·(dx/1000)⁴`) + `cfl_guard`. 2Δx-selective in the
  40-step sweep; codex caveat: mature-convection spectra/cold-pools unverified (CPU-limited).
- **Subsidence θ-vs-t (FORCING-SUB, iter-55 codex MED, OPEN #75):** LS subsidence advects
  full θ; SAM advects static-energy `t`. Clear-air identical; diverges only on large
  condensate gradients. MOOT now (GATE lsf `wls≡0`; RCE/RCEMIP impose no subsidence). A
  cloudy-subsidence case (DYNAMO) would need a static-energy path.
- **Resolution (CPU-blocked):** SAM GATE=`2048²×256 @ dx=100m, dt=2s`; legoESM smokes
  dx=1000m. Faithful dx=100m/256-lvl multi-day run CPU-prohibitive.
- C4 SAM θ' random noise: **✅ LBA uses band-limited random seed (iter-82)**; RCE/GATE keep
  smooth-k1 (k1 validated for RCE deep convection #83; GATE compute-bound). ⬜ minor remaining:
  GATE diurnal SW cycle (RAD-8 daily-mean); M2005 M1b deposition size-split + no graupel self-collect.
