\chapter{Introduction}
\label{ch:intro}

\section{Overview}

legoESM is a modular, fully differentiable Earth System Model (ESM) written
entirely in JAX.  Every component---atmosphere, ocean, land, sea ice, lake,
and biogeochemistry---is compatible with JAX's automatic differentiation
(\texttt{jit}, \texttt{grad}, \texttt{vmap}, \texttt{scan}), enabling novel
applications in data assimilation (4D-Var with exact adjoints), parameter
estimation, hybrid AI--physics modelling, and sensitivity analysis.

The model features:
\begin{itemize}[nosep]
  \item \textbf{25+ dynamical cores} spanning five discretisation families
    (C-D grid FV3, spectral, finite-volume lat-lon, C-grid lat-lon, and
    MPAS/Voronoi), with shallow water, hydrostatic primitive equation,
    and non-hydrostatic compressible Euler equation sets;
  \item \textbf{35+ physics parameterisations} for radiation, convection,
    microphysics, boundary-layer turbulence, clouds, gravity wave drag,
    and surface exchange;
  \item A \textbf{3D Boussinesq ocean} with split-explicit and implicit
    barotropic solvers, KPP, TKE and CATKE vertical mixing, GM-Redi eddy
    parameterisation, an optional conservative frazil-ice closure, and
    biogeochemistry (abiotic carbon cycle + NPZD ecosystem);
  \item A \textbf{multi-layer land model} with Richards-equation
    soil hydrology, Johansen thermal diffusion, a two-leaf (sunlit/shaded)
    canopy energy balance with Farquhar photosynthesis and stomatal
    control, an optional CLM-ML multilayer canopy, and a DALEC-990 carbon
    cycle;
  \item \textbf{Sea-ice dynamics} with EVP rheology, multi-category
    thickness distribution, and thermodynamic coupling;
  \item A \textbf{tile-based coupler} with Monin-Obukhov surface layer,
    area-weighted flux blending, and radiation sub-cycling;
  \item \textbf{CMIP6-class infrastructure}: CF/CMOR output, six
    experiment templates, checkpointing with SHA-256 reproducibility
    verification, and a 16-parameter tuning registry;
  \item A \textbf{Spherical Fourier Neural Operator} (SFNO) for
    learned dynamics and physics emulation.
\end{itemize}

\section{What Is New in legoESM 1.0}
\label{sec:whats-new}

Version~1.0 is the first release whose production AMIP configuration runs the
full atmospheric physics suite over an interactive land model and a prognostic
sea-ice skin, on the MPAS/Voronoi grid.  The principal scientific changes since the previous edition of this guide are:
\begin{itemize}[nosep]
  \item \textbf{A CAM6-homogenised production atmosphere}
    (Section~\ref{sec:production-amip}): the CAM6 32-level hybrid
    coordinate, a faithful port of the CAM6 Zhang--McFarlane deep convection
    (Section~\ref{sec:zm-cam6}), the full prognostic CLUBB higher-order
    closure (Section~\ref{sec:clubb}) with the CAM6 cloud-fraction assembly
    (Section~\ref{sec:cam6-clouds}), MG2-style in-cloud warm rain in the
    Morrison microphysics, McICA cloud overlap in radiation
    (Section~\ref{sec:cloud-overlap}), and a CAM-style physics cadence with
    macro/microphysics sub-cycling (Section~\ref{sec:physics-cadence}).
  \item \textbf{One temperature-dependent latent-heat family}
    (Section~\ref{sec:latent-heat}) used by the surface-flux interface,
    the coupler tiles, the land canopy and the sea ice, with $\Ls=\Lv+\Lf$
    closed identically; schemes ported from a reference model keep that
    model's conventions.
  \item \textbf{Conservative transport}: energy-conserving
    Simmons--Burridge vertical transport and frictional heating on the
    spectral core, a conservative slope-limited vertical tracer transport
    on the MPAS hybrid lane, and a column-conserving tracer positivity
    borrow on every grid (Chapter~\ref{ch:conservation}).
  \item \textbf{Interactive land in production AMIP}: the multilayer
    Richards land with the two-leaf canopy as default surface scheme,
    calibrated parameters and a seasonal boundary-data update
    (Section~\ref{sec:two-leaf}).
  \item \textbf{A prognostic sea-ice skin} for prescribed-ice AMIP runs
    (Section~\ref{sec:ice-skin}).
  \item \textbf{Additional schemes}: the IFS/Bechtold convection port
    (Section~\ref{sec:bechtold}), the E3SM/CAM spectral gravity-wave
    solver with frontal and orographic sources, a Hines launch level above the
    boundary layer (Section~\ref{sec:gwd-schemes}), homogeneous cirrus ice nucleation, and a
    native FV3 duo-grid dynamical-core lane scored against the GFDL Fortran.
  \item \textbf{Ocean}: a fixed-iteration preconditioned conjugate-gradient
    implicit free surface on the MPAS mesh (Section~\ref{sec:barotropic}),
    NEMO-faithful TKE vertical mixing, and an optional frazil-ice closure.
  \item \textbf{Numerical precision} selectable per run (fp32, fp64,
    mixed, mixed with fp64 storage; Section~\ref{sec:precision}).
\end{itemize}

\section{Design Principles}

\begin{enumerate}[nosep]
  \item \textbf{JAX-first}: All code uses pure-functional JAX with no
    Python loops in hot paths.  Conditional branching uses
    \texttt{jnp.where} or \texttt{jax.lax.cond} to preserve
    differentiability.
  \item \textbf{Grid-agnostic physics}: Operators implement a shared
    protocol (\texttt{GridProtocol}); physics schemes accept any grid
    via column adapters that reshape to \texttt{(ncol, nlev)}.
  \item \textbf{Modular composition}: Each parameterisation follows a
    factory pattern returning a callable
    $\texttt{physics\_fn}(\text{state}, \text{grid}, \text{coord})
    \to \text{Tendencies}$.
  \item \textbf{Unified C-D grid}: Atmosphere and ocean share the same
    FV3-style C-D grid operator module on the cubed sphere, eliminating
    code duplication and the Hollingsworth--Kallberg instability.
  \item \textbf{Pytree registration}: \texttt{Field} and state objects
    are registered as JAX pytrees for seamless autodiff through the
    entire model.
\end{enumerate}

\section{Notation and Conventions}

Throughout this document:
\begin{itemize}[nosep]
  \item Vectors are denoted in bold: $\vect{v}=(u,v)$;
  \item $\hat{f}$ denotes spectral (spherical harmonic) coefficients;
  \item Subscript $k$ indexes vertical levels (increasing downward);
  \item Half-integer subscripts ($k\pm\half$) denote layer interfaces;
  \item SI units are used unless otherwise noted;
  \item $f = 2\Omega\sin\phi$ is the Coriolis parameter.
\end{itemize}

\chapter{Software Architecture and Package Federation}
\label{ch:architecture}
% #############################################################################

The scientific content of the following chapters maps onto a concrete software
structure: legoESM is a \emph{federation} of independently-installable Python
packages that all share one import namespace.  This chapter documents that
structure --- one subsection (``subchapter'') per package --- so the equations
of later chapters can be located in code.

\section{Design: one namespace, independently-installable members}
\label{sec:arch-federation}

legoESM is a \texttt{uv} workspace of eight distribution packages laid out under
\texttt{packages/<member>/legoesm/<subpkg>/}.  All members ship into a single
\texttt{legoesm} PEP-420 \emph{namespace package}, so user code always writes
\texttt{import legoesm.<subpkg>} regardless of which wheel provides it.  The
design goal is that each Earth-system component can be installed and run on its
own---\texttt{pip install legoesm-ocean} yields a working ocean model---while a
single meta-package \texttt{legoesm} pulls the whole stack.

The members obey a strict one-way \textbf{dependency DAG}, enforced in CI by
\texttt{import-linter} contracts (\texttt{lint-imports}):
\[
  \underbrace{\texttt{core}}_{\text{substrate}}
  \;\prec\;
  \underbrace{\{\texttt{atmosphere},\,\texttt{ocean},\,\texttt{land},\,\texttt{ice}\}}_{\text{components}}
  \;\prec\;
  \underbrace{\{\texttt{coupler},\,\texttt{ml},\,\texttt{tools}\}}_{\text{orchestration}}.
\]
Components depend \emph{only} on \texttt{legoesm-core} and never on one another
or on the coupler; shared physics (e.g.\ the FV3 shallow-water barotropic
solver reused by the ocean) is exposed through the substrate or via
\texttt{importlib.metadata} entry points (\texttt{legoesm.sw\_barotropics}), not
direct cross-component imports.

\section{The substrate: \texttt{legoesm-core}}
\label{sec:arch-core}

\texttt{legoesm-core} ships the subpackages \texttt{core} (fields, operators,
state, conservation accumulators, EOS), \texttt{grids} (cubed-sphere, lat-lon,
Gaussian/spectral, MPAS/Voronoi, vertical coordinates, and the grid+complexity
\emph{capability matrix}; Chapter~\ref{ch:grids}), \texttt{runtime}
(device/precision/backend bootstrap), \texttt{parallel} (halo exchange and
reductions; Chapter on parallelism), \texttt{io}, \texttt{timestepping}
(RK integrators), and \texttt{components} (the complexity-ladder taxonomy and
component protocols), together with the loose modules \texttt{constants},
\texttt{thermo}, \texttt{registry}, and \texttt{surface\_albedo}.  It imports
nothing above itself.

\section{Earth-system components}
\label{sec:arch-components}

\subsection{\texttt{legoesm-atmosphere}}
The \texttt{atmosphere} subpackage: all atmospheric dynamical cores
(Chapter~\ref{ch:dynamics})---cubed-sphere C-D grid, spectral, lat-lon
finite-volume and C-grid, MPAS/Voronoi, and SFNO---the physics parameterisation
packages (radiation, convection, microphysics, boundary layer, clouds,
gravity-wave drag), and the dycore-free single-column model (SCM).

\subsection{\texttt{legoesm-ocean}}
The \texttt{ocean} subpackage: the 3-D split-explicit Boussinesq ocean
(baroclinic/barotropic on cubed-sphere, lat-lon C-grid, and MPAS), vertical and
lateral mixing (KPP, GM-Redi, tidal), bottom drag and surface forcing,
biogeochemistry, the idealized-experiment suite, the centennial spin-up library,
and the peer-comparison fidelity harness.

\subsection{\texttt{legoesm-land}}
The \texttt{land} subpackage: slab (bucket-hydrology) and multi-layer
(Richards-equation, Johansen-thermal) land, the DALEC carbon cycle, snow, and
PFT-weighted parameter providers.

\subsection{\texttt{legoesm-ice}}
The \texttt{ice} subpackage: thermodynamic slab and EVP/mEVP dynamic sea ice
with the multi-category ice-thickness distribution and optional snow/brine/
ridging/pond physics.

\section{Orchestration: coupler, ML, and tools}
\label{sec:arch-orchestration}

\subsection{\texttt{legoesm-coupler}}
The \texttt{coupler} subpackage (tile-based surface coupling, bulk-flux and
surface-energy closure; Chapter~\ref{ch:coupling}) and the \texttt{driver}
subpackage (\texttt{ModelDriver} for atmosphere-only AMIP, \texttt{CoupledESMDriver}
for full coupling, \texttt{EarthSystemDriver} for arbitrary compositions, plus
the reproducibility \emph{run manifest}).

\subsection{\texttt{legoesm-ml}}
The \texttt{ml} (SFNO blocks, spectral convolutions, conservation-aware losses),
\texttt{training} (differentiable training driver, ERA5 ingestion, S2S
workflows), and \texttt{da} (variational 4D-Var on \texttt{jax.grad} through the
compiled segment kernel) subpackages.

\subsection{\texttt{legoesm-tools}}
The \texttt{forcing} (GHG/ozone/aerosol/SST/runoff loaders), \texttt{diagnostics}
(energy/mass budgets, column integrals, and the conservation PASS/FAIL
\emph{gates}), \texttt{experiments} (including the shared component-agnostic
\emph{test-matrix framework}, \texttt{experiments.matrix}), and
\texttt{visualization} subpackages.

\section{Reproducibility, scripts, and experiments}
\label{sec:arch-reproducibility}

Runnable code lives in bucketed directories under \texttt{scripts/}:
\texttt{run/} (production drivers), \texttt{matrix/} (the complexity-tiered
test-matrix runners), \texttt{experiment/} (the template/provenance harness:
\texttt{init\_experiment}, \texttt{validate\_templates}, \texttt{fetch\_data},
\texttt{lego\_detect\_machine}), and \texttt{bench/}, \texttt{plot/},
\texttt{validate/}, \texttt{data/}.  Experiments are versioned, tier-annotated
YAML \emph{templates} (\texttt{config/templates/}) resolved into a runnable
directory; every run writes a \texttt{run\_manifest.json} (resolved config,
state digest, git commit, and library versions) so that
\texttt{legoesm reproduce} can re-execute it bit-for-bit.  Tests carry
complexity-tier markers \texttt{tier0}--\texttt{tier3} (research $\to$
operational) and assert conservation through the same gates as the matrix
runners.

\section{Cubed-Sphere Grid}
\label{sec:cubed-sphere}

Six faces of a cube are mapped to the sphere via \textbf{gnomonic (central)
projection} \citep{Ronchi1996,PutmanLin2007}.  This quasi-uniform tiling avoids
the polar singularity and convergence of meridians inherent to a latitude--longitude
mesh, so the maximum stable timestep is set by a near-uniform grid spacing rather
than by the vanishing zonal spacing at the poles.  Let
$(\alpha_x,\alpha_y)\in[-\pi/4,\pi/4]^2$ be the equiangular gnomonic
coordinates on a face; great circles map to straight lines in $(\alpha_x,\alpha_y)$,
which is what makes the projection convenient for conservative finite-volume
discretisation \citep{Sadourny1972}.

\subsection{Face-to-Cartesian Mapping}

For face~0 ($+x$ face):
\begin{equation}
  (x,y,z) = \bigl(1,\;\tan\alpha_x,\;\tan\alpha_y\bigr).
\end{equation}
Points are normalised to the unit sphere: $\hat{\vect{r}}=\vect{r}/|\vect{r}|$,
with geographic coordinates $\lambda=\mathrm{atan2}(\hat y,\hat x)$,
$\phi=\arcsin(\hat z)$.

\subsection{Cell Area}
\begin{equation}
  \Delta A = \frac{R^2\,\Delta\alpha^2}
    {\cos^2\!\alpha_x\,\cos^2\!\alpha_y\,D^3},
  \qquad D = \sqrt{1+\tan^2\!\alpha_x+\tan^2\!\alpha_y},
  \qquad \Delta\alpha=\frac{\pi}{2n}.
\end{equation}
Here $R$ is the planetary radius, $\Delta\alpha$ the uniform angular cell width
for a C$n$ face of $n\times n$ cells, and the metric factor $D$ is the distance
from the cube centre to the projected point.  The $D^{-3}$ weighting concentrates
area away from the face centres and is exactly the Jacobian of the gnomonic map;
integrating $\Delta A$ over the six faces recovers $4\pi R^2$, which is the
discrete area-conservation property the finite-volume operators rely on.

\subsection{Grid Spacing}

Great-circle distances use the chord-to-arc formula:
\begin{equation}
  d = R\cdot 2\arcsin\!\Bigl(\frac{|\vect{r}_1-\vect{r}_2|}{2}\Bigr).
\end{equation}
The minimum grid spacing on a C$n$ cubed sphere is
\begin{equation}
  \Delta x_{\min} = \frac{\pi R}{2n\sqrt{3}},
\end{equation}
occurring at the cube corners where the gnomonic distortion is maximal.

\subsection{Grid Angle and Wind Rotation}

The angle $\theta$ between the grid $x$-axis and geographic east:
\begin{equation}
  \theta = \mathrm{atan2}\!\Bigl(\frac{\pp\phi}{\pp i},\;
  \frac{\pp\lambda}{\pp i}\cos\phi\Bigr).
\end{equation}
Wind rotation between geographic $(u_E,v_N)$ and grid-aligned $(u_g,v_g)$:
\begin{equation}
  \begin{pmatrix}u_E\\v_N\end{pmatrix}
  =\begin{pmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{pmatrix}
  \begin{pmatrix}u_g\\v_g\end{pmatrix}.
\end{equation}

\subsection{Halo Exchange}

Scalar fields are exchanged directly across the six-face connectivity table.
Vector fields are first rotated to geographic components, padded as scalars,
then rotated back, because the grid-aligned basis is discontinuous across a
panel edge and a naive copy of $(u_g,v_g)$ would inject a spurious rotation at
the seam.  A discrete duo-grid treatment of the panel edges removes the residual
edge imprint that a single-grid halo leaves on differential operators
\citep{Mouallem2023}.  Two halo widths are supported: halo\,=\,1 for second-order
and MUSCL stencils, and halo\,=\,2 for PPM/WENO5 and biharmonic operators.

\paragraph{Native 4D halo exchange.}
All 3D operators use a 4D halo path (\texttt{pad\_halo\_4d},
\texttt{pad\_halo\_vector\_4d}) that exchanges all vertical levels in a
single MPI message per neighbour, replacing the earlier
\texttt{vmap(pad\_halo)} path which issued $n_{\mathrm{lev}}$ separate
messages.

\paragraph{MPI differentiability.}
All \texttt{sendrecv} calls go through a \texttt{@jax.custom\_vjp}
wrapper (\texttt{\_sendrecv\_vjp} in \texttt{halo\_exchange.py}) that
swaps source and destination ranks in the backward pass, enabling
\texttt{jax.grad} through distributed halo exchange.  Only
\texttt{allreduce(SUM)} is AD-safe among MPI reductions;
\texttt{MAX}/\texttt{MIN}/\texttt{allgather}/\texttt{bcast} are used
only in diagnostics and are not differentiable.

\section{Gaussian Grid and Spectral Transforms}
\label{sec:spectral-grid}

The spectral dynamical cores represent fields by their spherical-harmonic
coefficients and use a Gaussian grid with triangular truncation at total
wavenumber $n_{\max}$ \citep{Bourke1972,HoskinsSimmons1975}.  Triangular
truncation is chosen because it is isotropic: the retained set of harmonics is
invariant under rotation of the sphere, so no direction is preferentially
resolved.

\subsection{Grid Dimensions}
\begin{equation}
  n_{\mathrm{lat}} = \lceil\tfrac{3}{2}(n_{\max}+1)\rceil_{\mathrm{even}},
  \qquad n_{\mathrm{lon}} = 2\,n_{\mathrm{lat}},
  \qquad n_{\mathrm{sh}} = \frac{(n_{\max}+1)(n_{\max}+2)}{2}.
\end{equation}
Here $n_{\mathrm{lat}}$, $n_{\mathrm{lon}}$, and $n_{\mathrm{sh}}$ are the number
of latitudes, longitudes, and retained spectral coefficients.  The $\tfrac{3}{2}$
factor is the standard transform-grid choice that makes the Gaussian quadrature
exact for the quadratic (advective) products, eliminating spectral aliasing.
Latitudes are Gaussian quadrature points $\mu_k=\sin\phi_k$ with weights
$w_k$; longitudes are equispaced so the zonal direction can be treated by FFT.

\subsection{Associated Legendre Polynomials}

Fully normalised ($4\pi$) polynomials $P_n^m(\mu)$ satisfy
$\int|Y_n^m|^2\,\dd A=1$.  Computed via the recursion:
\begin{align}
  P_m^m &= -\sqrt{\frac{2m+1}{2m}}\;\sqrt{1-\mu^2}\;P_{m-1}^{m-1},\\
  P_n^m &= \sqrt{\frac{4n^2-1}{n^2-m^2}}
    \Bigl(\mu\,P_{n-1}^m -
    \sqrt{\frac{(n-1)^2-m^2}{4(n-1)^2-1}}\;P_{n-2}^m\Bigr).
\end{align}
The derivative operator $H_n^m=-(1-\mu^2)\,\dd P_n^m/\dd\mu$ is used for
meridional gradients.

\subsection{Spherical Harmonic Transforms}

\paragraph{Analysis (grid $\to$ spectral).}
\begin{equation}
  \hat f_{nm} = 2\pi\sum_k w_k\,P_n^m(\mu_k)\,\tilde f_m(\mu_k),
  \qquad \tilde f_m = \frac{1}{n_{\mathrm{lon}}}\,\mathrm{FFT}[f]_m.
\end{equation}
The transform is split into a fast Fourier transform in longitude followed by a
Gaussian-quadrature sum over latitude $\mu_k$ weighted by $w_k$ and the Legendre
function $P_n^m$ \citep{Bourke1972}.  Because the quadrature is exact at this
resolution, analysis followed by synthesis returns the resolved field to round-off.

\paragraph{Synthesis (spectral $\to$ grid).}
\begin{equation}
  f(\phi,\lambda) = \mathrm{iFFT}\Bigl[\sum_{n=m}^{n_{\max}}\hat f_{nm}\,P_n^m(\mu)\Bigr].
\end{equation}

\subsection{Spectral Operators}

Laplacian eigenvalue:
$\nabla^2\hat f_{nm}=-n(n+1)/a^2\cdot\hat f_{nm}$.
Inverse Laplacian:
$\nabla^{-2}\hat f_{nm}=-a^2/[n(n+1)]$ for $n>0$.
Hyperdiffusion:
$-\nu[n(n+1)/a^2]^p\,\hat f_{nm}$.

\subsection{Velocity from Vorticity and Divergence}

Streamfunction $\psi=\nabla^{-2}\zeta$, velocity potential
$\chi=\nabla^{-2}\delta$.  Velocity reconstruction:
\begin{equation}
  u\cos\phi = \frac{\pp\psi}{\pp\theta}+\frac{\pp\chi}{\pp\lambda},
  \qquad
  v\cos\phi = \frac{\pp\psi}{\pp\lambda}-\frac{\pp\chi}{\pp\theta},
\end{equation}
where $\theta$ is colatitude.

\section{Lat-Lon Grid}
\label{sec:latlon-grid}

A uniform $n_{\mathrm{lat}}\times n_{\mathrm{lon}}$ latitude-longitude grid
with A-grid (collocated) staggering.  All operators use second-order centred
differences.  A Fourier polar filter is applied to tendencies at high
latitudes to prevent the CFL constraint from becoming prohibitively small
near the poles.


% ---------------------------------------------------------------------------
\section{Voronoi/MPAS Grid}
\label{sec:voronoi-grid}

An unstructured Voronoi tessellation generated from an icosahedral parent
mesh \citep{Skamarock2012}.  The TRiSK (Thuburn--Ringler--Skamarock--Klemp)
scheme provides mimetic discrete operators on this C-grid
\citep{Thuburn2009,Ringler2010}.  Mimetic here means the discrete divergence,
gradient, and curl satisfy the same vector-calculus identities as their
continuous counterparts ($\divg\,\grad\times=0$ and $\grad\times\grad=0$ to
machine precision), which in turn guarantees discrete conservation of mass and
potential vorticity and suppresses the spurious computational modes that a
non-mimetic C-grid would admit.  The placement is
\begin{itemize}[nosep]
  \item Scalars (height, tracers, pressure) at cell centres;
  \item Normal velocity at edges;
  \item Vorticity at vertices (triangle dual).
\end{itemize}
Variable resolution is supported by mesh refinement.

\section{Vertical Coordinates}
\label{sec:vertical}

\subsection{Sigma Coordinate}
\begin{equation}
  \sigma = p\,/\,p_s, \qquad \sigma\in[\sigma_{\mathrm{top}},\;1].
\end{equation}
Half-level interfaces $\sigma_{k+1/2}$ are uniformly spaced; full levels
$\sigma_k=(\sigma_{k-1/2}+\sigma_{k+1/2})/2$.

\subsubsection{Simmons--Burridge Geopotential}

The vertical finite differencing follows \citet{SimmonsBurridge1981}, which is
constructed so that the discrete pressure-gradient and energy-conversion terms
conserve total energy under adiabatic, frictionless flow.  The geopotential at
full level $k$ is
\begin{equation}
  \Phi_k = \Phi_s + \Rd\!\sum_{k'=k+1}^{N-1}T_{k'}\ln\frac{\sigma_{k'+1/2}}{\sigma_{k'-1/2}}
  + \alpha_k\,\Rd\,T_k,
\end{equation}
where the Simmons--Burridge coefficient is
\begin{equation}
  \alpha_k = 1 - \frac{\sigma_{k-1/2}}{\Delta\sigma_k}
  \ln\frac{\sigma_{k+1/2}}{\sigma_{k-1/2}}.
\end{equation}
Here $\Phi_s$ is the surface geopotential, $\Rd$ the dry gas constant, $T_{k'}$
the layer temperature, and $\alpha_k$ the Simmons--Burridge weighting that
distributes the within-layer geopotential increment consistently with the
hydrostatic relation, so that the discrete hydrostatic balance is exact.

\subsubsection{Sigma-Dot (Vertical Velocity)}
\begin{equation}
  \dot\sigma_{k+1/2} =
  \frac{\sigma_{k+1/2}-\sigma_{\mathrm{top}}}{1-\sigma_{\mathrm{top}}}
  \,D_{\mathrm{tot}}
  - \sum_{k'=0}^{k}\divg\vect{v}_{k'}\,\Delta\sigma_{k'},
  \qquad D_{\mathrm{tot}}=\sum_{k'=0}^{N-1}\divg\vect{v}_{k'}\,\Delta\sigma_{k'}.
\end{equation}

\subsubsection{Pressure Velocity}
\begin{equation}
  \omega \equiv \frac{\dd p}{\dd t}
  = \sigma\,\frac{\dd p_s}{\dd t} + p_s\,\dot\sigma.
\end{equation}

\subsection{Hybrid Sigma-Pressure Coordinate}

\begin{equation}
  p(k) = A(k)\,p_{\mathrm{ref}} + B(k)\,p_s,
\end{equation}
where $A(k)$ and $B(k)$ are the prescribed hybrid coefficients with
$A(k)\to 1,\,B(k)\to 0$ at the model top (pure pressure levels)
and $A(k)\to 0,\,B(k)\to 1$ near the surface (pure sigma).
Flattening the upper levels to pressure surfaces eliminates the large
pressure-gradient force errors over steep topography that afflict the pure
sigma coordinate, where the two large terms of the pressure gradient must
cancel along a steeply sloping surface.

\subsection{Terrain-Following Height Coordinate ($z^*$)}

Used by the non-hydrostatic compressible Euler equations:
\begin{equation}
  z^* = H\,\frac{z-z_s}{H-z_s}, \qquad
  J=\frac{\pp z}{\pp z^*}=\frac{H-z_s}{H}.
\end{equation}
A 1D reference state $(\rho_0(z),\,\theta_0(z),\,\pi_0(z))$ is
pre-computed for the perturbation formulation.

\subsection{Ocean $z^*$ Coordinate}

The ocean uses a dynamic $z^*$ coordinate with free-surface elevation $\eta$:
\begin{equation}
  J(\eta) = \frac{\eta+H}{H_{\max}},
\end{equation}
where $H$ is the resting depth and $J$ the layer-thickness Jacobian.  Stretching
each column by $J(\eta)$ lets every level dilate uniformly with the moving free
surface, so the coordinate stays a smooth function of the surface state, in the
same spirit as the Lagrangian-then-remap vertical treatment of the finite-volume
atmosphere core \citep{Lin2004}.

\chapter{Coupling of Dynamics and Physics}
\label{ch:coupling}
% #############################################################################

\section{Physics Pipeline}

The \texttt{PhysicsPipeline} class composes all physical parameterisations
into a single callable that is invoked once per dynamics timestep.  The ordering
is not arbitrary: each parameterisation operates on the state already updated by
the preceding ones, so radiation sets the column heating that drives convection,
convection conditions the moisture field seen by the microphysics, and the
boundary layer mixes the resulting profiles before the surface fluxes close the
column energy and water budgets.  The calling sequence within a single step is:

\begin{enumerate}[nosep]
  \item \textbf{Dynamics step}: Update winds, temperature, surface pressure,
    and tracers via the selected dynamical core.
  \item \textbf{Physics step}: Apply parameterisations in the following order:
    \begin{enumerate}[nosep]
      \item Radiation (with optional sub-cycling),
      \item Deep convection,
      \item Shallow convection / large-scale condensation,
      \item Cloud microphysics,
      \item Boundary-layer turbulence and vertical diffusion,
      \item Gravity wave drag,
      \item Surface fluxes (tile coupler).
    \end{enumerate}
  \item \textbf{Conservation fixers}: Mass, moisture, and optionally energy.
  \item \textbf{Diagnostics}: Energy budget, monthly means, snapshots.
\end{enumerate}

\section{Radiation Sub-Cycling}

Radiation is the most expensive physics component.  The pipeline supports
calling radiation every $N_{\mathrm{rad}}$ dynamics steps while holding
radiative heating rates constant between calls.  The branching is implemented
via \texttt{jax.lax.cond} with both branches returning identical array
shapes and dtypes.

\section{Physics Cadence and Macro/Microphysics Sub-Cycling}
\label{sec:physics-cadence}

On the MPAS lane the whole column physics can run on a longer timestep than
the dynamics, following the CAM-FV coupling sequence.  With
$N_{\mathrm{phys}}$ dynamics steps of length $\Delta t$ per physics step, the
physics is evaluated every $N_{\mathrm{phys}}$-th step with timestep
$\Delta t_{\mathrm{phys}}=N_{\mathrm{phys}}\Delta t$, and its entire
increment
\begin{equation}
  \vect{x} \leftarrow \vect{x} + \Delta t_{\mathrm{phys}}\,
  \Bigl(\frac{\pp\vect{x}}{\pp t}\Bigr)_{\mathrm{phys}}
\end{equation}
is applied once, on that step; the intervening dynamics steps apply no physics
tendency and only republish the cached diagnostic rates (precipitation,
surface and top-of-atmosphere fluxes) to the accumulators.  Schemes that
carry prognostic memory (turbulence moments, convective memory) integrate it
over $\Delta t_{\mathrm{phys}}$.  Applying the increment once, rather than
holding a tendency rate fixed for $N_{\mathrm{phys}}$ dynamics steps, prevents
a condensation rate diagnosed at the start of the window from continuing to
heat a column after the dynamics has removed its vapour.  The radiation
interval must be a multiple of $N_{\mathrm{phys}}$, so every radiation call
falls on a physics step.  Within each physics step the boundary-layer
macrophysics and the cloud microphysics can be sub-cycled
$N_{\mathrm{mac}}$ times at $\Delta t_{\mathrm{phys}}/N_{\mathrm{mac}}$,
after the convective increment, as in CAM's \texttt{macmic} loop.  The
production configuration uses $\Delta t=112.5$~s, $N_{\mathrm{phys}}=16$
($\Delta t_{\mathrm{phys}}=1800$~s), radiation every 3600~s and
$N_{\mathrm{mac}}=3$.  Two documented departures from CAM remain: the
dynamics on a physics step sees the pre-increment state, and the land
surface keeps its own coupling interval (set independently; 1800~s in
production, equal to the physics step).

\section{Grid-Agnostic Column Adapter}

The \texttt{ColumnAdapter} reshapes any grid's 3D state into a
\texttt{(ncol, nlev)} column format for physics, then unflattens back
to the native grid shape.  This allows all physics schemes to operate
on simple column arrays regardless of the underlying horizontal
discretisation.

\section{Time-Split vs Process-Split}

legoESM uses \textbf{time-split} coupling: dynamics and physics operate
sequentially within each timestep, so the physics sees the fully advected state
rather than a partial tendency.  Physics tendencies are computed from
the dynamics-updated state and applied as a forward-Euler update.  In
process-split coupling, by contrast, dynamics and physics tendencies are
evaluated from the same time-level state and summed; the sequential update
chosen here keeps each parameterisation consistent with the column the previous
one produced, and is natural for the finite-volume dycores that remap onto a
Lagrangian vertical coordinate internally before physics is applied.

\section{Shallow Water Equations}
\label{sec:sw}

The shallow water system is the canonical proving ground for horizontal
dynamical cores: it retains the rotational and gravity-wave dynamics that
control the fast modes of the full equations while collapsing the vertical
structure to a single layer, so the standard test set of \citet{Williamson1992}
can isolate grid imprinting, dispersion, and conservation errors. The rotating
shallow water equations in \textbf{vector-invariant form}:
\begin{align}
  \frac{\pp h}{\pp t} &= -\divg(h\,\vect{v}),
  \label{eq:sw-mass}\\
  \frac{\pp u}{\pp t} &= (\zeta+f)\,v - \frac{\pp B}{\pp x} + D_u,
  \label{eq:sw-u}\\
  \frac{\pp v}{\pp t} &= -(\zeta+f)\,u - \frac{\pp B}{\pp y} + D_v,
  \label{eq:sw-v}
\end{align}
where $h$ is the fluid depth, $\vect{v}=(u,v)$ the horizontal velocity,
$f$ the Coriolis parameter, $g$ gravity, and $h_s$ the bottom topography.
$B=\half(u^2+v^2)+g(h+h_s)$ is the Bernoulli function,
$\zeta=\pp v/\pp x - \pp u/\pp y$ is the relative vorticity,
and $D_u,D_v$ represent hyperdiffusion. The first equation expresses exact mass
(volume) conservation in flux form; the momentum equations express the balance
between the absolute-vorticity ($\zeta+f$) flux, the Bernoulli gradient that
combines kinetic energy and free-surface pressure, and scale-selective
dissipation. Writing the advection through $(\zeta+f)$ rather than as
$\vect{v}\cdot\grad\vect{v}$ keeps the Coriolis and metric terms in a single
discretely consistent operator, which is what permits simultaneous mass,
energy, and potential-enstrophy control on the staggered grids below.

\subsection{C-D Grid Cubed-Sphere Discretisation}

This is the primary shallow water solver. It maps the equations onto the
gnomonic cubed sphere \citep{Ronchi1996,PutmanLin2007}, a quasi-uniform tiling
of six logically rectangular panels that avoids the polar singularity of the
lat-lon mesh, and uses the FV3-style C-D grid staggering of \citet{Lin2004} and
\citet{PutmanLin2007}. The C-D arrangement carries momentum on the D-grid (so
vorticity is cleanly defined at corners) while diagnosing C-grid mass fluxes for
transport, combining the favourable geostrophic adjustment of the C-grid with
the well-resolved vorticity dynamics of the D-grid.

\paragraph{Prognostic variables.}
D-grid winds $(u_d,v_d)$ at cell corners, shape $(6,n\!+\!1,n\!+\!1)$;
height $h$ at cell centres, shape $(6,n,n)$.

\paragraph{D-grid vorticity.}
Vorticity at each cell corner is the discrete circulation divided by the
corner dual-cell area:
\begin{equation}
  \zeta_{\mathrm{corner}} = \frac{1}{A_c}\oint\vect{u}\cdot\dd\vect{l}
  \approx \frac{1}{A_c}\bigl[u^D_{i,j}\Delta x - u^D_{i+1,j}\Delta x
  + v^D_{i,j+1}\Delta y - v^D_{i,j}\Delta y\bigr].
\end{equation}
Here $A_c$ is the corner dual-cell area and $\Delta x,\Delta y$ are the local
edge lengths. Because vorticity is defined as the line integral of the
tangential wind around the dual cell, the discrete curl inherits the
Stokes-theorem identity exactly, so the kinetic-energy and enstrophy budgets
remain mutually consistent. This circulation-based discretisation is exact on
the D-grid and \textbf{eliminates the Hollingsworth--Kallberg instability} that
plagues A-grid vorticity operators, in which a vorticity stencil inconsistent
with the kinetic-energy gradient feeds a spurious symmetric-instability mode.

\paragraph{Arakawa--Lamb gradient.}
The Bernoulli gradient at D-grid corners uses a 4-point average:
\begin{equation}
  \left.\frac{\pp B}{\pp x}\right|_{i+\half,j+\half}
  = \frac{B_{i+1,j}+B_{i+1,j+1}-B_{i,j}-B_{i,j+1}}{2\Delta x}.
\end{equation}

\paragraph{C-grid mass flux.}
C-grid velocities are diagnosed from D-grid winds by face-edge averaging.
Scalar transport uses upwind C-grid mass fluxes:
\begin{equation}
  \frac{\dd h}{\dd t} = -\frac{1}{A}
  \bigl[(hu_c)_{i+\half,j}-(hu_c)_{i-\half,j}
  +(hv_c)_{i,j+\half}-(hv_c)_{i,j-\half}\bigr].
\end{equation}

\paragraph{FV3-faithful PPM transport.}
As of v3.9, the C-D grid operator module underwent a complete rewrite
to implement FV3-faithful Piecewise Parabolic Method (PPM) transport
\citep{ColellaWoodward1984} on staggered D/C grids.  Key elements include:
\begin{itemize}[nosep]
  \item PPM reconstruction with Colella--Woodward monotonicity limiters
    for all scalar fields;
  \item Flux-form mass transport on staggered D-grid and C-grid;
  \item Corrected geographic-to-grid wind rotation eliminating
    sign errors in cross-face interpolation;
  \item Tuned hyperdiffusion with physical $e$-folding time
    ($\nu_4 = \Delta x^4/\tau_{\mathrm{efold}}$).
\end{itemize}
The module spans approximately 740~lines of JAX code.

\paragraph{FV3 forward--backward shallow-water core.}
An FV3-style implementation (kernels certified bit-exact; whole-chain fidelity in progress) of the c\_sw/d\_sw forward--backward
stepping algorithm is provided in \texttt{fv3\_sw\_core.py}.  The forward
step (c\_sw) computes C-grid mass fluxes and height tendencies; the backward
step (d\_sw) updates D-grid winds using the vorticity flux and Bernoulli
gradient.

\subparagraph{d2a2c\_vect.}
The D-grid $\to$ A-grid $\to$ C-grid vector conversion faithfully ports
the GFDL FV3 algorithm, including:
\begin{itemize}[nosep]
  \item Edge-boundary stencils with one-sided 4-point interpolation at
    cube-face edges;
  \item Non-orthogonality corrections via $\cos\alpha$ and
    $(\sin^2\!\alpha)^{-1}$ corner metrics;
  \item Halo-aware padding with face-boundary detection.
\end{itemize}

\subparagraph{PPM wind and vorticity transport.}
C-grid wind tendencies (\texttt{xtp\_u}, \texttt{ytp\_v}) and absolute
vorticity flux use Piecewise Parabolic Method reconstruction with
FV3-specific interpolation coefficients ($A_1$, $A_2$, $C_1$--$C_3$)
and Colella--Woodward monotonicity limiters.

\subparagraph{Cell-centred kinetic energy.}
Kinetic energy is computed from A-grid velocities at cell centres, with
an optional 4th-order averaging stencil (\texttt{a2b\_ord4}).

\paragraph{Duo-grid sub-grid metrics (Mouallem et al.\ 2023).}
Following the duo-grid construction of \citet{Mouallem2023}, the cubed-sphere
C-D grid computes 9-point sub-grid angle metrics per cell:
\begin{equation}
  \sin\alpha_{\mathrm{sg}},\;\cos\alpha_{\mathrm{sg}} \in \mathbb{R}^{6 \times n \times n \times 9},
\end{equation}
encoding the local deviation from orthogonality at cell centres, edge
midpoints, and corners.  These enable FV3-faithful flux scaling at
cube-face boundaries where the gnomonic projection introduces
non-orthogonality.  Additional C-D grid metrics:
\begin{itemize}[nosep]
  \item Centre-to-centre distances $\Delta x_c$ (shape $6 \times (n\!+\!1) \times n$)
    and $\Delta y_c$ (shape $6 \times n \times (n\!+\!1)$);
  \item Non-orthogonality factors $\cos\alpha_{\mathrm{corner}}$ and
    $(\sin^2\!\alpha_{\mathrm{corner}})^{-1}$ at D-grid corners.
\end{itemize}

\paragraph{Fidelity calibration and 3D edge-artifact sentinels.}
The C-D-grid FV3 port is gated on a dual-target Williamson 2 / Williamson 5
calibration drawn from the standard sphere test set
\citep{Williamson1992}: at C36 with $\Delta t=300$~s the production knobs
\texttt{div\_damp\_order = 8} and \texttt{damp\_v = 0.030} (iter-1030)
satisfy both criteria simultaneously --- Williamson 2 v-wind error
$|v_{\mathrm{ll}}|<0.119$~m\,s$^{-1}$ and Williamson 5 day-5 height
$h>0$ with $|\vect{u}|<80$~m\,s$^{-1}$.  A 48-test sentinel suite
exercises the full 3D coverage matrix
(hydrostatic / non-hydrostatic $\times$ rest / edge / long
integration $\times$ cube-edge $i,j\in\{0,n{-}1\}$) and a long
100-step cosine-bell closure within $\pm 5\%$.  Visual verification
of $v$-wind snapshots is mandatory --- error norms can improve while
edge artifacts shift in character; see \texttt{docs/fv3\_fortran\_fidelity\_review.md}
and \texttt{docs/cubed\_sphere\_edge\_artifacts.md} for the iter-1045
status snapshot.

\subsection{Lat-Lon Finite Volume Discretisation}

A-grid staggering on a uniform $n_{\mathrm{lat}}\times n_{\mathrm{lon}}$
grid.  Centred differences for all operators.  A Fourier polar filter
damps meridional wavelengths near the poles to maintain CFL stability.

\subsection{C-Grid Lat-Lon Discretisation}

Height at cell centres; $u$ at longitude interfaces; $v$ at latitude
interfaces.  The operators follow the energy- and enstrophy-conserving
finite-difference construction of \citet{Sadourny1972} for the sphere.
Advantages: exact pressure gradient (just cell differences),
mass flux naturally at cell interfaces (no interpolation), and better
gravity wave dispersion.  The Coriolis term requires 4-point interpolation,
which is the price the C-grid pays for placing $u$ and $v$ on different
interfaces; the interpolation weights are chosen to preserve the discrete
energy conversion between kinetic and potential reservoirs.

\subsection{TRiSK Discretisation on Voronoi Mesh}

The unstructured Spherical Centroidal Voronoi Tessellation places scalars at
cell centres and the normal velocity component $u_e$ on edges. The TRiSK
(Thuburn--Ringler--Skamarock--Klemp) family of mimetic operators
\citep{Thuburn2009,Ringler2010} is built so that the discrete divergence, curl,
and gradient satisfy the same vector-calculus identities as the continuum
($\divg\curl=0$, $\curl\grad=0$), guaranteeing exact mass conservation and a
consistent potential-vorticity budget on a fully unstructured mesh. Following
\citet{Ringler2010}, the discrete operators on the Voronoi mesh are:
\begin{align}
  \text{Divergence at cell } c: &\quad
    (\divg\vect{u})_c = \frac{1}{A_c}\sum_e n_{e,c}\,u_e\,l_e, \\
  \text{Gradient at edge } e: &\quad
    (\grad\phi)_e = \frac{\phi_{c_2}-\phi_{c_1}}{d_e}, \\
  \text{Curl at vertex } v: &\quad
    (\curl\vect{u})_v = \frac{1}{A_v}\sum_e t_{e,v}\,u_e\,d_e,
\end{align}
where $n_{e,c}$ and $t_{e,v}$ are orientation signs, $l_e$ is edge length,
$d_e$ is distance between adjacent cell centres, and $A_c,A_v$ are
cell/vertex areas.

\subsection{Spectral Shallow Water}

The state is represented by spherical-harmonic coefficients and advanced in the
vorticity--divergence formulation of \citet{Bourke1972}, in which the prognostic
scalars $\hat\zeta$ and $\hat\delta$ replace the vector momentum and the
horizontal Laplacian is diagonal in spectral space:
\begin{align}
  \frac{\pp\hat\zeta}{\pp t} &= -\widehat{\divg[(\zeta+f)\vect{v}]}, \\
  \frac{\pp\hat\delta}{\pp t} &= \widehat{\curl[(\zeta+f)\vect{v}]}
    - \nabla^2\widehat{(E+\Phi+\Phi_s)}, \\
  \frac{\pp\hat\Phi}{\pp t} &= -\widehat{\divg(\Phi\,\vect{v})},
\end{align}
where $E=\half(u^2+v^2)$ is the kinetic energy, $\Phi=g\,h$ the free-surface
geopotential, $\Phi_s$ the surface geopotential, and the hat denotes the
forward spherical-harmonic transform. Pseudospectral: nonlinear products are
computed on the grid, where they are local and cheap, then transformed back to
spectral space, where the linear gravity-wave and diffusion terms are exact and
free of grid imprinting.

\section{Hydrostatic Primitive Equations}
\label{sec:pe}

Prognostic variables: $u,v$ (horizontal winds), $T$ (temperature),
$p_s$ (surface pressure), and tracers $q_i$.

\subsection{Continuous Equations}

In $\sigma$-coordinates:
\begin{align}
  \frac{\pp p_s}{\pp t} &= -\int_0^1 \divg(p_s\,\vect{v})\,\dd\sigma,
  \label{eq:pe-ps}\\
  \frac{\pp u}{\pp t} &= (\zeta+f)\,v - \frac{\pp B}{\pp x}
  - \Rd T\,\frac{\pp\ln p_s}{\pp x} + D_u,
  \label{eq:pe-u}\\
  \frac{\pp v}{\pp t} &= -(\zeta+f)\,u - \frac{\pp B}{\pp y}
  - \Rd T\,\frac{\pp\ln p_s}{\pp y} + D_v,
  \label{eq:pe-v}\\
  \frac{\pp T}{\pp t} &= -\divg(T\,\vect{v})+T\,\divg\vect{v}
  - \dot\sigma\,\frac{\pp T}{\pp\sigma}
  + \kappa\,T\,\frac{\omega}{p} + Q,
  \label{eq:pe-T}
\end{align}
Here $\sigma=p/p_s$ is the terrain-following vertical coordinate, $\dot\sigma$
the associated vertical velocity, $\omega=\dd p/\dd t$ the pressure velocity,
$\Phi$ the geopotential, $\Rd$ the dry gas constant, and $Q$ the diabatic
heating from physics; $B=K+\Phi$, $K=\half(u^2+v^2)$, and $\kappa=\Rd/\cpd$.
The surface-pressure tendency~\eqref{eq:pe-ps} is the vertically integrated mass
continuity that closes the hydrostatic system: with the vertical momentum
equation replaced by hydrostatic balance, mass divergence in the column---rather
than vertical acceleration---sets the surface pressure. The pressure-gradient
force splits into the along-$\sigma$ Bernoulli gradient and the
$\Rd T\,\grad\ln p_s$ term that accounts for the tilt of the $\sigma$ surfaces.
The adiabatic heating term $\kappa T\omega/p$ represents compression
warming during descent and is the thermodynamic counterpart of the work done by
the pressure-gradient force.

\subsection{C-D Grid Cubed-Sphere Discretisation}
\label{sec:pe-cdgrid}

Prognostic state: $u_d,v_d$ at D-grid corners $(6,n\!+\!1,n\!+\!1,N_{\mathrm{lev}})$;
$T$ and $p_s$ at cell centres.  Spatial operators are identical to the
shallow water C-D grid (Section~\ref{sec:sw}), extended to 3D with:
\begin{itemize}[nosep]
  \item Simmons--Burridge energy-conserving geopotential integration
    \citep{SimmonsBurridge1981} (Section~\ref{sec:vertical});
  \item Sigma-dot computation with discrete continuity closure;
  \item Upwind vertical advection: $-\dot\sigma\,\pp f/\pp\sigma$.
\end{itemize}

\subsection{Spectral Transform Discretisation}
\label{sec:spe}

On the Gaussian grid, the momentum equations are recast in the
vorticity--divergence form \citep{Bourke1972}:
\begin{align}
  \frac{\pp\hat\zeta}{\pp t} &=
  \widehat{\curl[(\zeta+f)\vect{v}]}
  + \widehat{\text{vert.\ adv.}} - \nu\nabla^{2p}\hat\zeta,
  \label{eq:spe-vor}\\
  \frac{\pp\hat\delta}{\pp t} &=
  \widehat{\divg[(\zeta+f)\vect{v}]}
  - \nabla^2\widehat{(K+\Phi+\Rd T\ln p_s)}
  + \widehat{\text{vert.\ adv.}} - \nu\nabla^{2p}\hat\delta,
  \label{eq:spe-div}\\
  \frac{\pp\hat T}{\pp t} &=
  \widehat{-\divg(T\vect{v})+T\divg\vect{v}}
  - \widehat{\dot\sigma\,\pp T/\pp\sigma}
  + \widehat{\kappa T\omega/p},
  \label{eq:spe-T}\\
  \frac{\pp\widehat{\ln p_s}}{\pp t} &= -\int_0^1\hat\delta\,\dd\sigma.
  \label{eq:spe-lnps}
\end{align}

\paragraph{Spectral curl and divergence.}
For flux vectors $(U,V)=(F_u\cos\phi,\,F_v\cos\phi)$:
\begin{equation}
  \widehat{\text{curl}} = \frac{im}{a}\,\mathcal{S}\bigl[V/\cos^2\!\phi\bigr]
  + \frac{1}{a}\,\mathcal{S}_\mu[U],
  \qquad
  \widehat{\text{div}} = \frac{im}{a}\,\mathcal{S}\bigl[U/\cos^2\!\phi\bigr]
  - \frac{1}{a}\,\mathcal{S}_\mu[V],
\end{equation}
where $\mathcal{S}$ and $\mathcal{S}_\mu$ denote the SH analysis with
standard and $\dd P_n^m/\dd\mu$ Legendre matrices.  The $\cos\phi$ weighting
is absorbed into the Legendre basis, making the formulation pole-safe.

\paragraph{Semi-implicit treatment of gravity waves.}
Following \citet{HoskinsSimmons1975}, the fast gravity-wave terms are
treated implicitly.  Linearising about a reference temperature $T_{\mathrm{ref}}=300$~K
yields a Helmholtz equation per spectral mode:
\begin{equation}
  \bigl[\mathbf{I} + \alpha^2\Delta t^2\,\lambda_n\,\mathbf{\Gamma}\bigr]\,
  \hat\delta^{n+1} = \hat\delta^{\mathrm{explicit}},
\end{equation}
where $\lambda_n = n(n+1)/a^2$ is the Laplacian eigenvalue and $\mathbf{\Gamma}$
is the vertical coupling matrix built from the energy-conserving vertical
finite differences of \citet{SimmonsBurridge1981}. Because the harmonics
diagonalise the horizontal Laplacian, the implicit system decouples by
wavenumber into a small block-tridiagonal solve in the vertical; this is
pre-factored (LU decomposition) for each wavenumber $n$ at initialisation,
removing the gravity-wave CFL constraint and allowing 3--4$\times$ larger
timesteps.

\paragraph{Energy-conserving vertical transport and frictional heating.}
By default the vertical transport of $u$, $v$ and $T$ uses the centred
Simmons--Burridge form \citep{SimmonsBurridge1981}, which pairs discretely with
the continuity equation on both the sigma and the hybrid coordinate, and the
kinetic energy removed by the vorticity/divergence hyperdiffusion is returned
to the temperature as local frictional heating.  The first-order upwind
alternative has no such pairing: in a zero-physics integration it leaked
0.48~K\,day$^{-1}$ of mass-weighted global-mean temperature, against
0.015~K\,day$^{-1}$ with the centred form, and it remains selectable only to
reproduce older results.  Tracers keep the upwind form, whose diffusion
preserves the positivity of moisture.

\paragraph{Verification.}
A comprehensive spectral dycore test suite validates conservation
(mass, energy, enstrophy), long-integration stability under
Held--Suarez forcing, spectral convergence with increasing truncation
wavenumber, and semi-implicit scheme correctness.  See
Chapter~\ref{ch:verification} for details.

\subsection{Lat-Lon Finite-Volume Discretisation}

Identical equations to the C-D grid version, discretised on the A-grid
lat-lon mesh with centred differences.  Polar filter applied to all
tendencies.  Optional Rayleigh sponge layer above a configurable
$\sigma$ cutoff.

\subsection{MPAS/Voronoi Discretisation}

TRiSK operators (Section~\ref{sec:sw}) extended to 3D, following the MPAS
atmosphere formulation of \citet{Skamarock2012}.  Uses RK4 or SSP-RK3
\citep{ShuOsher1988} time stepping with energy- or enstrophy-conserving
potential vorticity flux options; the choice of PV flux selects which
quadratic invariant the discretisation conserves to round-off, trading
energetic fidelity against the enstrophy control that suppresses spurious
grid-scale vorticity.

\paragraph{Vertical transport on the MPAS lane.}
On the sigma coordinate the vertical advection of the resolved fields is
first-order upwind or a second-order, slope-limited van Leer scheme.  On the
hybrid sigma--pressure coordinate (the production lane) the momentum and
temperature use the conservative Simmons--Burridge flux form, and every
tracer is transported in the face-minus-cell increment form
\begin{equation}
  \frac{\pp q_k}{\pp t}\Big|_{\mathrm{vert}} =
  -\frac{\dot m_{k+\half}\,(q_{k+\half}-q_k)
         -\dot m_{k-\half}\,(q_{k-\half}-q_k)}{\Delta p_k},
\end{equation}
with the interface mass flux $\dot m$ (zero at the top and the surface), the
layer thickness $\Delta p_k$ and van Leer face values reconstructed in
pressure.  Paired with the continuity that defines $\dot m$, the column
integral of $q\,\Delta p$ telescopes to the zero boundary fluxes, so the
vertical transport neither creates nor destroys water; a constant field has
zero tendency.  The earlier advective upwind operator lacked this property
and created water at a rate comparable to the model's whole global water
imbalance.  The horizontal MPAS tracer operator remains advective.

\paragraph{FV3 duo-grid lane.}
Separately from the operator-level C-D grid core above, a native port of the
GFDL FV3 dynamical core runs on the duo-grid cubed sphere: the hydrostatic and
non-hydrostatic acoustic cores, tracer transport and vertical remapping,
each scored against a pinned build of the Fortran.  It couples to
Held--Suarez forcing and to Kessler warm-rain microphysics, and runs sharded
by cube face across devices.

\section{Non-Hydrostatic Compressible Euler Equations}
\label{sec:nh}

Dropping the hydrostatic approximation restores vertically propagating acoustic
and gravity waves, so the core integrates the fully compressible Euler equations
with a split-explicit, height-based formulation in the manner of the WRF/MPAS
nonhydrostatic solvers \citep{Klemp2007,SkamarockKlemp2008}. In the $z^*$
terrain-following coordinate, the prognostic variables are perturbations from a
hydrostatically balanced reference state $(\rho_0,\theta_0,\pi_0)$, which
removes the dominant hydrostatic balance from the pressure-gradient and buoyancy
terms and leaves only the dynamically active residuals:

\begin{align}
  \frac{\pp u}{\pp t} &= (\zeta+f)\,v - \frac{\pp K}{\pp x}
  - \cpd\theta\,\frac{\pp\pi'}{\pp x} + D_u - r\,u,
  \label{eq:nh-u}\\
  \frac{\pp v}{\pp t} &= -(\zeta+f)\,u - \frac{\pp K}{\pp y}
  - \cpd\theta\,\frac{\pp\pi'}{\pp y} + D_v - r\,v,
  \label{eq:nh-v}\\
  \frac{\pp w}{\pp t} &= -\frac{\cpd\theta}{J}\,\frac{\pp\pi'}{\pp z^*}
  - g\,\frac{\theta'}{\theta_0} - r\,w,
  \label{eq:nh-w}\\
  \frac{\pp\theta'}{\pp t} &= -\divg(\theta\,\vect{v}_h)
  - \frac{w}{J}\,\frac{\pp\theta}{\pp z^*} + D_\theta,
  \label{eq:nh-theta}\\
  \frac{\pp\rho'}{\pp t} &= -\frac{1}{J}
  \Bigl[\grad_h\!\cdot\!(J\rho\,\vect{v}_h)
  + \frac{\pp(\rho w)}{\pp z^*}\Bigr],
  \label{eq:nh-rho}
\end{align}
Here $w$ is the vertical velocity, $\theta'$ and $\rho'$ the potential-temperature
and density perturbations, $\pi'$ the Exner-pressure perturbation, $J$ the
Jacobian of the terrain-following map, $K$ the horizontal kinetic energy, and
$r(z)$ the Rayleigh sponge coefficient. The horizontal momentum equations carry
the non-hydrostatic pressure gradient $\cpd\theta\,\grad\pi'$ in place of the
geopotential gradient, the $w$ equation balances the same vertical
pressure-gradient force against buoyancy $-g\,\theta'/\theta_0$, and the density
equation is the unapproximated mass continuity. The Exner perturbation closes
the system through the equation of state:
\begin{equation}
  \pi' = \pi_0\Bigl[\Bigl(1+\frac{\rho'}{\rho_0}\Bigr)\!
  \Bigl(1+\frac{\theta'}{\theta_0}\Bigr)\Bigr]^{\Rd/\cvd}-\pi_0.
\end{equation}

\subsection{Split-Explicit Time Integration}

Acoustic modes propagate roughly an order of magnitude faster than the
meteorologically relevant advective and gravity-wave modes, so an explicit
single-rate scheme would be acoustically CFL-limited and wasteful. The core
therefore time-splits the integration \citep{WickerSkamarock2002,Klemp2007}:
the slow, meteorologically important terms are advanced on the long RK3 step,
while the acoustically active terms are sub-cycled on short forward--backward
substeps.

\paragraph{Slow modes} (SSP-RK3): advection, Coriolis, horizontal pressure
gradient force, and diffusion.

\paragraph{Fast modes} (forward--backward acoustic substeps):
vertical sound/gravity waves.  Typically $N_s=6$ substeps per RK stage. The
forward--backward ordering---updating $w$ from the current pressure, then the
density and temperature from the just-updated $w$---makes the vertical acoustic
substep implicitly stable without a tridiagonal solve.

\paragraph{Forward step (vertical velocity).}
\begin{equation}
  w^{n+1} = w^n + \Delta t_s
  \Bigl[-\frac{\cpd\theta}{J}\,\frac{\pp\pi'}{\pp z^*}
  - g\,\frac{\theta'}{\theta_0}\Bigr].
\end{equation}

\paragraph{Backward step (density, potential temperature).}
\begin{equation}
  \rho'^{n+1} = \rho'^n
  - \Delta t_s\,\frac{\pp(\rho\,w^{n+1})}{\pp z^*},
  \qquad
  \theta'^{n+1} = \theta'^n
  - \Delta t_s\,\frac{w^{n+1}}{J}\,\frac{\pp\theta}{\pp z^*}.
\end{equation}

\paragraph{Acoustic off-centering.}
To damp vertically propagating acoustic/gravity wave noise
\citep{SkamarockKlemp2008}:
\begin{equation}
  \rho'^{n+1}_{\beta} = (1+\beta)\,\rho'^{n+1} - \beta\,\rho'^{n},
\end{equation}
where $\beta\ge 0$ is the off-centering parameter (default 0.1).

\subsection{Sponge Layer}
\begin{equation}
  r(z) = r_{\max}\sin^2\!\Bigl(\frac{\pi}{2}\,
  \frac{\max(0,\,z-z_{\mathrm{bot}})}{z_{\mathrm{top}}-z_{\mathrm{bot}}}\Bigr).
\end{equation}

\subsection{Turbulence Closure: CRM, LES, and DNS}
\label{sec:crm-les-dns}

The diffusion terms $D_u,\,D_v,\,D_w,\,D_\theta$ in
Eqs.~\eqref{eq:nh-u}--\eqref{eq:nh-theta} are evaluated in flux form,
$D_\phi = \rho_0^{-1}\,\partial_j\!\bigl(\rho_0\,K_\phi\,\partial_j\phi\bigr)$
over the horizontal directions $j\in\{x,y\}$ and, optionally, the vertical
$j=z^*$ (a mass-weighted leg matching the SAM \texttt{diffuse\_*}
operators).  The \emph{same} discrete operator serves a hierarchy of three
turbulence-resolving regimes that differ only in the viscosity $K_m$ and the
grid spacing $\Delta x$; the heat and scalar diffusivity is
$K_h = K_m/\mathrm{Pr}$.

\begin{description}
\item[CRM (convection-permitting), $\Delta x\sim 1$--$4$\,km.]
The Smagorinsky--Lilly eddy viscosity \citep{Smagorinsky1963}
\begin{equation}
  K_m = (C_s\Delta)^2\,
  \sqrt{\max\!\bigl(0,\;|S|^2 - \mathrm{Pr}\,N^2\bigr)},
  \qquad \Delta = (\Delta x\,\Delta y\,\Delta z)^{1/3},
  \label{eq:smag}
\end{equation}
with the full strain magnitude $|S|^2 = 2\,S_{ij}S_{ij}$ (all six
components, including the vertical-shear terms $S_{13},S_{23},S_{33}$),
$C_s\approx 0.19$, and the moist sub-grid stratification cutoff $N^2$ (the
SAM \texttt{dosmagor} correction) that suppresses mixing in statically
stable layers.  The energy-containing eddies are entirely sub-grid, so
Eq.~\eqref{eq:smag} parameterizes \emph{all} turbulent transport.  This is
the configuration validated against gSAM for the GATE, LBA, and RCE deep
convection cases.

\item[LES (large-eddy simulation), $\Delta x\sim 10$--$100$\,m.]
The \emph{same} closure~\eqref{eq:smag} with $C_s\approx 0.15$ and an
optional near-wall mixing-length limiter $\ell_m=\min(C_s\Delta,\,\kappa z)$.
The energy-containing eddies are now resolved and $K_m$ models only the
inertial-subrange stress.  The gSAM reference simulations of GATE and LBA
are themselves $\Delta x=100$\,m LES, so the LES mode applies the identical
closure at the identical resolution as the oracle.

\item[DNS (direct numerical simulation), $\Delta x\to$ the Kolmogorov scale.]
No turbulence model.  $K_m$ is replaced by the constant molecular kinematic
viscosity $\nu$ (with $K_h=\nu/\mathrm{Pr}$ and $\mathrm{Pr}\approx 0.71$ for
air), yielding the molecular dissipation $\nu\nabla^2\vect{u}$ directly; all
turbulent scales down to dissipation are resolved.
\end{description}

The regime is selected by the \texttt{turbulence\_closure} parameter
(\texttt{smagorinsky} / \texttt{molecular} / \texttt{none}).  Because the
three regimes share the single discrete flux-form operator, LES and DNS are
a configuration change rather than a separate code path.  The molecular
closure has been verified to reproduce the analytical viscous decay
$\partial_t\hat u = -\nu k^2\hat u$ of an isolated shear mode to within the
time-integration error.

\section{Finite-Volume Transport}
\label{sec:fv-transport}

Scalar advection in the finite-volume cores is cast in flux form, so the
cell-averaged tracer changes only through fluxes across its faces; this enforces
discrete conservation by construction. The remaining task is to reconstruct the
sub-grid profile used to evaluate those face fluxes, trading formal order of
accuracy against the monotonicity needed to keep tracers (mixing ratios,
densities) physically bounded. The cores offer a hierarchy of reconstructions of
increasing order.

\subsection{MUSCL Reconstruction (2nd Order)}

Piecewise-linear reconstruction with slope limiting \citep{vanLeer1979}:
\begin{equation}
  q_L = q_i + \half\,\phi_i, \qquad q_R = q_{i+1} - \half\,\phi_{i+1},
\end{equation}
with minmod or MC (monotonised central) limiters. The limiter $\phi$ reduces the
cell slope wherever it would create a new extremum, yielding a second-order,
total-variation-diminishing scheme that suppresses the spurious oscillations of
unlimited centred differences near sharp gradients.

\subsection{PPM Reconstruction (4th Order)}

The Piecewise Parabolic Method \citep{ColellaWoodward1984} constructs a
monotone parabola in each cell.  Fourth-order edge values:
\begin{equation}
  \hat q_{i+1/2} = \frac{7}{12}(q_i+q_{i+1})
  - \frac{1}{12}(q_{i-1}+q_{i+2}).
\end{equation}
Monotonicity constraint:
$\hat q_{i+1/2} \leftarrow \mathrm{median}(\hat q_{i+1/2},\,q_i,\,q_{i+1})$.
Colella--Woodward limiting prevents new extrema in the parabolic profile. The
parabolic in-cell profile delivers fourth-order accuracy in smooth flow while
the edge-value clipping and the flattening of the parabola near discontinuities
preserve monotonicity, making PPM the default tracer scheme where both accuracy
and positivity matter.

\subsection{WENO5 Reconstruction (5th Order)}

Three sub-stencil polynomials combined with nonlinear weights adapting to
local smoothness \citep{JiangShu1996}:
\begin{equation}
  q_L = \sum_k \omega_k\,q^{(k)}, \qquad
  \omega_k = \frac{\alpha_k}{\sum_j\alpha_j}, \qquad
  \alpha_k = \frac{d_k}{(\varepsilon+\beta_k)^2},
\end{equation}
where $d_k$ are ideal weights $(1/10,\,6/10,\,3/10)$ and $\beta_k$ are
smoothness indicators. The nonlinear weights $\omega_k$ collapse onto the
optimal fifth-order stencil in smooth regions but smoothly drop any sub-stencil
that straddles a discontinuity, giving high order without the Gibbs oscillations
of a fixed wide stencil; $\varepsilon$ is a small floor preventing division by
zero where the field is locally constant.

\subsection{Rusanov Flux}

The reconstructed left and right interface states $(q_L,q_R)$ are combined into a
single-valued face flux by a local Lax--Friedrichs (Rusanov) approximate Riemann
solver:
\begin{equation}
  F = \half(h_L u_L + h_R u_R) - \half\,\alpha\,(h_R-h_L),
  \qquad \alpha=\max\!\bigl(|u_L|+c_L,\;|u_R|+c_R\bigr),
\end{equation}
where $c=\sqrt{g\,h}$ is the gravity-wave speed. The first term is the centred
average and the second is an upwind dissipation proportional to the maximum
local signal speed $\alpha$, which provides exactly enough numerical viscosity
to stabilise the discontinuity while remaining conservative.

\section{Time Integration}
\label{sec:timestepping}

\subsection{SSP-RK3}

The three-stage strong-stability-preserving (SSP) Runge--Kutta method
\citep{ShuOsher1988} is the workhorse explicit integrator. Each stage is a
convex combination of forward-Euler updates, so any monotonicity or
positivity property that holds for a single forward-Euler step under the
stage CFL also holds for the full higher-order step---exactly the guarantee the
limited finite-volume reconstructions above need:
\begin{align}
  \vect{u}^{(1)} &= \vect{u}^n + \Delta t\,F(\vect{u}^n), \\
  \vect{u}^{(2)} &= \tfrac{3}{4}\vect{u}^n + \tfrac{1}{4}\vect{u}^{(1)}
  + \tfrac{1}{4}\Delta t\,F(\vect{u}^{(1)}), \\
  \vect{u}^{n+1} &= \tfrac{1}{3}\vect{u}^n + \tfrac{2}{3}\vect{u}^{(2)}
  + \tfrac{2}{3}\Delta t\,F(\vect{u}^{(2)}).
\end{align}
SSP-RK(4,3) and SSP-RK(5,4) variants are also available.

\subsection{Robert--Asselin--Williams (RAW) Time Filter}

The leapfrog scheme used by the semi-implicit spectral PE solver supports two
time levels and therefore admits a spurious computational mode that must be
damped. The classical Robert--Asselin filter \citep{Asselin1972} suppresses
this mode but at the cost of degrading the scheme to first-order accuracy and
spuriously damping the physical mode. The \citet{Williams2009} modification
distributes the filter increment across the time levels to recover second-order
accuracy:
\begin{align}
  d^n &= \frac{\gamma}{2}\bigl(X^{n-1}-2X^n+X^{n+1}\bigr), \\
  X^n_{\mathrm{filt}} &= X^n + (1-\alpha)\,d^n, \\
  X^{n+1}_{\mathrm{filt}} &= X^{n+1} + \alpha\,d^n,
\end{align}
with $\alpha=0.5$ (default).  This restores second-order accuracy while
preserving the damping of the computational mode.

\subsection{CFL Conditions and Adaptive Hyperdiffusion}

For an explicit core the timestep is bounded so that the fastest signal
crosses at most a fraction $C_{\mathrm{CFL}}$ of the smallest grid cell per step:
\begin{equation}
  \Delta t_{\max} = \frac{C_{\mathrm{CFL}}\,\Delta x_{\min}}
  {(u_{\max}+c_{\mathrm{gw}})\sqrt{n_{\mathrm{dim}}}},
\end{equation}
where $c_{\mathrm{gw}}=\sqrt{gH}$ is the gravity wave speed, $u_{\max}$ the peak
advective speed, and the $\sqrt{n_{\mathrm{dim}}}$ factor accounts for
simultaneous propagation along each dimension on a multidimensional grid.

The maximum stable hyperdiffusion coefficient for $p$-th order:
\begin{equation}
  \nu_p = S\cdot\frac{C(p)\,\Delta x^{2p}}{\Delta t},
  \qquad
  C(2)=\tfrac{1}{2},\quad C(4)=\tfrac{1}{8},\quad C(6)=\tfrac{1}{48},
\end{equation}
where $S\in(0,1]$ is a safety factor.  The physical e-folding time for
$2\Delta x$ waves is $\tau_{\mathrm{efold}} = \Delta x^{2p}/\nu_p$.

\section{Thermodynamic Preliminaries}
\label{sec:thermo}

\subsection{Saturation Mixing Ratio}

The saturation vapour pressure $e_s$ sets the moisture capacity of the air
and underlies condensation, evaporation, and convective triggering. It is
obtained from the empirical Tetens (August--Roche--Magnus) fit, which
approximates the Clausius--Clapeyron integral over liquid water:
\begin{equation}
  e_s(T) = 611.2\exp\!\Bigl(\frac{17.67\,T_c}{T_c+243.5}\Bigr),
  \qquad q_s = \frac{\varepsilon\,e_s}{p-e_s},
  \qquad \varepsilon=\Rd/\Rv\approx 0.622,
\end{equation}
where $T_c = T - 273.15$~K is the Celsius temperature, $p$ the total
pressure, and $\varepsilon$ the ratio of dry-air to vapour gas constants
that converts the partial-pressure ratio into a saturation mixing ratio
$q_s$.  Over ice the latent heat of sublimation $\Ls$ is larger, so the
saturation curve is steeper; we evaluate it directly from the
Clausius--Clapeyron form referenced to the freezing point
$T_{\mathrm{freeze}}$:
\begin{equation}
  e_{s,i}(T) = 611.2\exp\!\Bigl[\frac{\Ls}{\Rv}
  \Bigl(\frac{1}{T_{\mathrm{freeze}}}-\frac{1}{T}\Bigr)\Bigr].
\end{equation}

\subsection{Virtual Temperature}

The buoyancy of moist, condensate-laden air is governed by the virtual
temperature $T_v$, which is the temperature dry air would need to match the
density of the moist parcel. Water vapour lightens the parcel (positive
$0.608\,q_v$) while suspended condensate loads it (negative $q_c,q_r,q_i$):
\begin{equation}
  T_v = T\,(1 + 0.608\,q_v - q_c - q_r - q_i).
\end{equation}

\subsection{Moist Adiabatic Lapse Rate}

When a saturated parcel rises, condensation releases latent heat and damps
the cooling relative to the dry-adiabatic rate. The moist lapse rate
$\Gamma_m$ balances adiabatic expansion against this latent-heat feedback,
the correction terms in numerator and denominator scaling with $\Lv q_s$:
\begin{equation}
  \Gamma_m = \frac{\Rd T}{\cpd p}\,
  \frac{1+\Lv q_s/(\Rd T)}{1+\Lv^2 q_s/(\cpd\Rv T^2)}.
\end{equation}

\subsection{Temperature-Dependent Latent Heats}
\label{sec:latent-heat}

The latent heats of phase change vary with temperature because the heat
capacities of vapour, liquid and ice differ.  legoESM uses a single
Kirchhoff-form family, referenced to the freezing point
$T_{\mathrm{freeze}}=273.15$~K.  The surface-flux interface, the coupler
tiles, the land canopy and the sea-ice categories evaluate their latent heats
from it; schemes ported term by term from a reference model (for example
the CAM6 convection) keep that model's own latent-heat conventions.  The family is:
\begin{align}
  \Lv(T) &= \Lv^{0} - (c_{pw}-c_{pv})\,(T-T_{\mathrm{freeze}}),\\
  \Ls(T) &= \Ls^{0} + (c_{pv}-c_{pi})\,(T-T_{\mathrm{freeze}}),\\
  \Lf(T) &= \Ls(T)-\Lv(T),
\end{align}
with $\Lv^{0}=2.501\times10^{6}$~J\,kg$^{-1}$,
$\Lf^{0}=3.337\times10^{5}$~J\,kg$^{-1}$ and $\Ls^{0}=\Lv^{0}+\Lf^{0}$, so
the three heats close identically at every temperature.  The heat capacities
are $c_{pv}=1846$, $c_{pw}=4218$ and $c_{pi}=2106$~J\,kg$^{-1}$\,K$^{-1}$:
$\Lv$ falls by 2372~J\,kg$^{-1}$ per kelvin (about 3\% lower at
30\,$^\circ$C) while $\Ls$ increases in the cold.  Water leaving a partly
frozen surface carries the phase-weighted heat
\begin{equation}
  L_{\mathrm{sfc}}(T_{\mathrm{sfc}}) = (1-f)\,\Lv(T_{\mathrm{sfc}})
  + f\,\Ls(T_{\mathrm{sfc}}),
\end{equation}
where $f\in[0,1]$ is the frozen (snow or ice) fraction of the evaporating
surface; the weighting is fractional rather than a threshold, so the flux stays
continuous and differentiable through melt-out.  A tile with several
evaporating components (a transpiring canopy above a sublimating snowpack, or
several ice-thickness categories) sums $L\,E$ component by component rather
than applying one heat to an aggregate temperature.

\section{Radiation}
\label{sec:radiation}

\subsection{Gray Two-Stream Radiation}
\label{sec:gray-rad}

The gray scheme replaces spectrally-resolved transfer with a single
broadband longwave channel whose optical depth is prescribed analytically,
following the aquaplanet formulation of \citet{Frierson2006}. This yields a
smooth, inexpensive, and fully differentiable radiative forcing suitable for
idealised and process-study configurations.

\subsubsection{Longwave Optical Depth}

The total longwave optical depth $\tau$ is the integral of absorber along
the path. A prescribed background term, scaled to be larger in the tropics
($\phi$ latitude) and to increase toward the surface in $\sigma$, is
augmented by an interactive water-vapour contribution proportional to the
column vapour mass:
\begin{equation}
  \tau(\sigma,\phi) = \bigl[f_l\,\sigma+(1-f_l)\,\sigma^4\bigr]
  \bigl[\tau_e+(\tau_p-\tau_e)\sin^2\!\phi\bigr]
  + \sum_k \tau_{\mathrm{moist}}\,q_{v,k}\,\frac{\Delta p_k}{g},
\end{equation}
where the moisture optical depth per layer is
$\Delta\tau_{\mathrm{moist},k}=\tau_{\mathrm{moist}}\,q_{v,k}\,\Delta p_k/g$,
with $\tau_e=7.2$, $\tau_p=1.8$, $f_l=0.2$,
$\tau_{\mathrm{moist}}=0.0115$~m$^2$\,kg$^{-1}$.

\subsubsection{Two-Stream Longwave Fluxes}

Each layer absorbs and re-emits in the gray band. Its transmittance
$\mathcal{T}_k$ follows Beer's law in the layer optical depth
$\Delta\tau_k$, and by Kirchhoff's law the emissivity $\varepsilon_k$ is its
complement:
\begin{equation}
  \mathcal{T}_k = e^{-D\,\Delta\tau_k},
  \qquad \varepsilon_k = 1-\mathcal{T}_k,
  \qquad D=1.66.
\end{equation}
The diffusivity factor $D\approx 5/3$ accounts for the hemispheric-mean
angular integration, converting the slant-path absorption into an effective
vertical two-stream transfer.

The hemispheric fluxes are then accumulated by two sweeps that propagate
boundary emission through the absorbing/emitting column. The upward stream
starts from surface emission
($F^\uparrow_{\mathrm{sfc}}=\varepsilon_s\,\SB\,T_s^4$, with $\SB$ the
Stefan--Boltzmann constant and $T_s$ the surface temperature) and gains each
layer's Planck source:
\begin{equation}
  F^\uparrow_k = \mathcal{T}_k\,F^\uparrow_{k+1} + \varepsilon_k\,\SB\,T_k^4.
\end{equation}
The downward stream starts from a dark top of atmosphere ($F^\downarrow_0=0$)
and accumulates emission on the way down:
\begin{equation}
  F^\downarrow_k = \mathcal{T}_k\,F^\downarrow_{k-1} + \varepsilon_k\,\SB\,T_k^4.
\end{equation}

\subsubsection{Shortwave (Beer--Lambert)}

Solar heating is treated as a single attenuated beam. The top-of-atmosphere
flux $S_0/4$ (the diurnal- and geometry-averaged solar constant) is absorbed
exponentially with depth, and a fixed surface albedo $\alpha_s$ reflects the
remainder back to space:
\begin{equation}
  F^\downarrow_{\mathrm{SW}}(k) = \frac{S_0}{4}\,
  e^{-\tau_{\mathrm{SW},0}\,\sigma_k},
  \qquad
  F^\uparrow_{\mathrm{SW}}(k) = \alpha_s\,F^\downarrow_{\mathrm{SW}}(\mathrm{sfc}),
\end{equation}
with $\tau_{\mathrm{SW},0}=0.22$, $S_0=1361$~W\,m$^{-2}$, $\alpha_s=0.31$.
Only the downward beam is absorbed; reflected SW escapes to space.

\subsubsection{Heating Rate}

The radiative temperature tendency follows from energy conservation: the
heating of a layer equals the convergence of the net radiative flux
$F^\uparrow_{\mathrm{net}}$ across its interfaces, divided by its heat
capacity per unit area $\cpd\,\Delta p/g$:
\begin{equation}
  \frac{\dd T}{\dd t}\bigg|_{\mathrm{rad},k}
  = \frac{g}{\cpd}\,
  \frac{F^{\uparrow}_{\mathrm{net},k+1/2}-F^{\uparrow}_{\mathrm{net},k-1/2}}
  {p_{k+1/2}-p_{k-1/2}}.
\end{equation}
Writing the heating as a flux difference makes it conservative by
construction: summing over the column telescopes to the net top-of-atmosphere
minus surface flux.

\subsection{RRTMGP Correlated-$k$ Radiation}
\label{sec:rrtmgp}

For realistic radiative transfer the model offers a correlated-$k$ backend
that resolves the spectral dependence of gaseous absorption. It descends
from the RRTM longwave model of \citet{Mlawer1997} and its modern,
accelerator-friendly RRTMGP reformulation \citep{Pincus2019}, in which
line-by-line absorption is reorganised into a small set of pseudo-monochromatic
$g$-points per band. The RRTMGP backend uses JAX-RRTMGP with:
\begin{itemize}[nosep]
  \item 128 LW and 112 SW $g$-points for correlated-$k$ gas absorption;
  \item Two-stream delta-Eddington radiative transfer equation;
  \item Spectral line absorption for H$_2$O, CO$_2$, CH$_4$, N$_2$O, O$_3$;
  \item Cloud optics via liquid/ice water path and effective radii lookup
    tables;
  \item Optional aerosol optical depth with prescribed single-scattering
    albedo ($\omega_0=0.93$) and asymmetry factor ($g=0.70$), or with
    per-shortwave-band values of both.
\end{itemize}

Default trace-gas concentrations: CO$_2$=415~ppmv, CH$_4$=1900~ppbv,
N$_2$O=332~ppbv.

\subsection{Cloud Vertical Overlap and Sub-Grid Cloud Optics}
\label{sec:cloud-overlap}

Handing every layer's grid-mean water path to a single homogeneous column
solves a sky whose cloud is spread thinly over many partly cloudy layers as one
deep uniform cloud, and over-estimates the cloud albedo.  Three treatments of
partial cloudiness are selectable:
\begin{itemize}[nosep]
  \item \textbf{none}: one homogeneous column carrying the grid-mean paths;
  \item \textbf{max\_random}: $n_{\mathrm{sub}}$ (default 8) binary cloud
    masks drawn with maximum--random overlap, each carrying the in-cloud
    water path, solved as independent columns and averaged.  The random
    numbers are a deterministic stratified set $(i+\half)/n_{\mathrm{sub}}$
    permuted per layer from a fixed table, so each layer keeps an exact
    uniform marginal, the result is reproducible, and \texttt{jax.grad}
    flows through it;
  \item \textbf{mcica}: the Monte Carlo Independent Column Approximation of
    \citet{Pincus2003} as used in CAM6 --- the same maximum--random
    generator, but one subcolumn per $g$-point inside a single radiative
    solve, so the cost is that of one column.
\end{itemize}
The production configuration uses McICA and, as CAM6's RRTMG does, applies no
additional in-cloud inhomogeneity reduction to the cloud optical depth.

\subsection{Solar Geometry}

The cosine of the solar zenith angle:
\begin{equation}
  \mu_0 = \sin\phi\sin\delta + \cos\phi\cos\delta\cos h,
\end{equation}
where $\delta$ is the solar declination and $h$ is the hour angle.
Daily-mean insolation and perpetual-equinox modes are also available.

\section{Deep Convection}
\label{sec:convection}

Ten convection schemes are selectable (\texttt{sbm}, \texttt{dca},
\texttt{kuo}, \texttt{mass\_flux}, \texttt{edmf}, \texttt{zhang\_mcfarlane},
\texttt{tiedtke}, \texttt{bechtold}, \texttt{kain\_fritsch},
\texttt{emanuel}), all JAX-differentiable; an unknown name is rejected.  The
schemes most used in practice are described below and the remainder in
Section~\ref{sec:conv-additional}.

\subsection{Simplified Betts--Miller (SBM) Relaxation}
\label{sec:sbm}

The SBM scheme is an adjustment closure: rather than resolving updraughts, it
relaxes temperature and moisture toward a post-convective reference profile.
It follows the convective-adjustment philosophy of \citet{BettsMiller1986} in
the simplified, single-timescale form of \citet{Frierson2007}.

\subsubsection{CAPE Computation}

The available energy for convection is the convective available potential
energy (CAPE), the vertically integrated buoyancy of an ascending parcel
relative to its environment. Only positively buoyant layers
($T_{\mathrm{parcel}}>T_{\mathrm{env}}$) contribute:
\begin{equation}
  \mathrm{CAPE} = \Rd\sum_k
  \max\!\bigl(0,\;T_{\mathrm{parcel},k}-T_{\mathrm{env},k}\bigr)\,
  \frac{\Delta p_k}{p_k}.
\end{equation}

\subsubsection{Smooth Trigger}

Convection is switched on by a trigger function $\mathcal{F}$ that activates
once CAPE exceeds a threshold $\mathrm{CAPE}_c$. A sigmoid $\sigma$ of
sharpness $\kappa_s$ replaces the discontinuous on/off switch, keeping the
parameterisation differentiable for end-to-end training:
\begin{equation}
  \mathcal{F} = \sigma\!\bigl(\kappa_s(\mathrm{CAPE}-\mathrm{CAPE}_c)\bigr),
  \qquad \kappa_s=0.01\;\text{(J/kg)}^{-1}.
\end{equation}

\subsubsection{Enthalpy-Conserving Relaxation}

The reference profile $T_{\mathrm{ref}}$ is adjusted so that column-integrated
moist enthalpy is conserved:
\begin{equation}
  \sum_k\bigl[\cpd(T_{\mathrm{ref},k}-T_k)
  +\Lv(q_{\mathrm{ref},k}-q_{v,k})\bigr]\,\Delta p_k = 0.
\end{equation}
This constraint guarantees that the latent heat released by drying the
column exactly matches the sensible heating, so the adjustment redistributes
energy without spuriously creating or destroying it. The state is then
relaxed toward the reference on a fixed convective timescale $\tau_c$, gated
by the trigger $\mathcal{F}$:
\begin{equation}
  \frac{\dd T}{\dd t} = \mathcal{F}\,\frac{T_{\mathrm{ref}}-T}{\tau_c},
  \qquad
  \frac{\dd q_v}{\dd t} = \mathcal{F}\,\frac{q_{\mathrm{ref}}-q_v}{\tau_c},
  \qquad \tau_c=7200\;\text{s}.
\end{equation}

\subsubsection{Precipitation}

Because the column dries during adjustment, surface precipitation is just the
mass of vapour removed per unit area, recovered by integrating the moisture
tendency over the column:
\begin{equation}
  P = -\frac{1}{g}\sum_k \frac{\dd q_v}{\dd t}\,\Delta p_k.
\end{equation}

\subsection{Kuo Column Moisture-Excess Scheme}

Convection proportional to column-integrated moisture excess above
saturation [kg\,m$^{-2}$].  Heating and moistening are partitioned
via a parameter $\alpha_{\mathrm{heat}}$:
\begin{align}
  MC &= \int \max(q_v - q_s, 0)\,\frac{\dd p}{g}, \\
  \frac{\dd T}{\dd t} &= \mathcal{F}\,\alpha_{\mathrm{heat}}\,
  \frac{T_{\mathrm{moist}}-T}{\tau_c}, \qquad
  \frac{\dd q_v}{\dd t} = \mathcal{F}\,(1-\alpha_{\mathrm{heat}})\,
  \frac{q_{s,\mathrm{moist}}-q_v}{\tau_c},
\end{align}
with $\alpha_{\mathrm{heat}}=0.75$ and $\tau_c=3600$~s.

\subsection{Mass-Flux Convection (Arakawa--Wu Type)}

In contrast to adjustment schemes, the mass-flux approach explicitly carries
a cloud-base convective mass flux and an entraining updraught, in the spirit
of the bulk mass-flux closures of \citet{Tiedtke1989} and
\citet{ZhangMcFarlane1995}. A prognostic base mass flux $M_c$ relaxes toward
an equilibrium value set by CAPE:
\begin{equation}
  M_{\mathrm{eq}} = \sigma\!\bigl[(\mathrm{CAPE}-\mathrm{CAPE}_{\mathrm{thresh}})
  /\mathrm{scale}\bigr]\cdot M_{\mathrm{scale}},
  \qquad
  \frac{\dd M_c}{\dd t} = \frac{M_{\mathrm{eq}}-M_c}{\tau_{\mathrm{adj}}}.
\end{equation}
The prognostic relaxation on timescale $\tau_{\mathrm{adj}}$ lets the cloud
ensemble respond to large-scale destabilisation with a finite memory rather
than instantaneously equilibrating CAPE.

The mass-flux profile is sinusoidal:
$m(p) = \sin[\pi(p_{\mathrm{base}}-p)/\Delta p]$.
The entraining updraft uses exponential dilution: as the plume rises it mixes
in environmental air at rate $\epsilon_0$, so its properties interpolate
between the undilute moist-adiabatic value and the environment:
\begin{equation}
  T_u(z) = e^{-\epsilon_0 z}\,T_{\mathrm{moist}}
  + (1-e^{-\epsilon_0 z})\,T_{\mathrm{env}},
\end{equation}
with entrainment rate $\epsilon_0=10^{-3}$~m$^{-1}$ and detrainment
rate $\delta_0=10^{-3}$~m$^{-1}$.

\paragraph{Precipitation.}
Precipitation is diagnosed from detrainment of updraft condensate,
integrated over the column using layer thickness $\Delta z$:
\begin{equation}
  P = \sum_k \delta_0\,M_k\,q_{\ell,k}\,\Delta z_k
  \quad [\text{kg\,m}^{-2}\,\text{s}^{-1}],
\end{equation}
where $q_{\ell,k}=\max(q_{u,k}-q_{s,k},\,0)$ is the updraft condensate
and $M_k=M_c\,m(p_k)$ is the mass flux profile [kg\,m$^{-2}$\,s$^{-1}$].
The vertical measure $\Delta z$ is used (not $\Delta p/g$) because $M$
already carries units of mass flux per unit area, so $\delta_0\,M\,q_\ell$
has units [kg\,m$^{-3}$\,s$^{-1}$] and multiplying by $\Delta z$ [m]
yields [kg\,m$^{-2}$\,s$^{-1}$].

\subsection{EDMF Convection}

Eddy-Diffusivity Mass-Flux with a prognostic updraft area fraction $a_u$:
\begin{equation}
  \frac{\dd a_u}{\dd t} = \frac{a_{u,\mathrm{eq}}-a_u}{\tau_a},
\end{equation}
combining mass-flux (updraft) and eddy-diffusivity (environmental mixing)
contributions.

\paragraph{Precipitation.}
As in the mass-flux scheme (\S\ref{sec:microphysics}), precipitation
is diagnosed from condensate detrainment using $\Delta z$:
\begin{equation}
  P = \sum_k \delta_0\,M_{u,k}\,q_{\ell,k}\,\Delta z_k
  \quad [\text{kg\,m}^{-2}\,\text{s}^{-1}],
\end{equation}
with $M_{u,k}=\rho_k\,a_u\,w_{u,k}$ and $\delta_0=2\times10^{-3}$~m$^{-1}$.

\subsection{Zhang--McFarlane (CAM6)}
\label{sec:zm-cam6}

The production deep convection is a port of the CESM2.1/CAM6
\texttt{zm\_conv\_tend} sequence \citep{ZhangMcFarlane1995}, pinned against
a transcription of the Fortran.  One step of the original is not wired: CAM6
also transports cloud liquid and ice with \texttt{convtran}, but the
convection interface here receives no cloud condensate, so that transport is
omitted.  Each call runs, in order:
\begin{enumerate}[nosep]
  \item a dilute-parcel CAPE computation, with the parcel entraining
    environmental air at the rate set by \texttt{dmpdz}
    ($-10^{-3}$~m$^{-1}$), followed by the entraining/detraining updraught
    and downdraught cloud model and the quasi-equilibrium closure, in which
    the cloud-base mass flux removes the CAPE in excess of the threshold
    $\mathrm{CAPE}_{\mathrm{lim}}=70$~J\,kg$^{-1}$ over
    $\tau=3600$~s, capped at its CFL bound;
  \item application of these tendencies to the state;
  \item Sundqvist-type evaporation of the falling convective rain on the
    updated state, with snow formation and the associated fusion heating;
  \item convective momentum transport following Richter and Rasch, with the
    dissipated kinetic energy returned as heat.
\end{enumerate}
The rain-conversion coefficient differs over land and ocean
($c_0=0.0075$ and $0.03$~m$^{-1}$), so the scheme requires the land fraction
unless the run is explicitly declared an aquaplanet.  As in CAM6 the base mass
flux is diagnosed afresh each call and carries no memory.  The scheme
publishes its updraught mass flux and in-cloud water to the CAM6
cloud-fraction assembly (Section~\ref{sec:cam6-clouds}).

\subsection{Bechtold / IFS Convection}
\label{sec:bechtold}

The \texttt{bechtold} scheme builds on the Tiedtke bulk mass-flux skeleton
and follows the ECMWF IFS formulation of \citet{Bechtold2008}.  The
cloud-base mass flux is diagnosed from a boundary-layer (departure) CAPE
rather than the surface parcel, which sharpens the diurnal cycle over land,
and is relaxed on a convective-turnover timescale.  Ported from the IFS source
and pinned against it are the CAPE closure with its resolution factor, the
in-plume precipitation conversion, the sub-cloud rain-evaporation march, the
IFS downdraught, the diurnal-cycle CAPE correction, the land/ocean split of the
relative-humidity threshold for rain evaporation, and snow melt.  An
autoregressive stochastic perturbation of the base mass flux
\citep{Bechtold2014} is available and off by default.  Smooth sigmoid gates
replace the hard thresholds of the Fortran so that the scheme remains
differentiable.

\subsection{Deep Convective Adjustment}

The simplest parameterisation: scans bottom-to-top adjusting unstable
layer pairs toward moist-adiabatic neutrality while conserving total
enthalpy.  Uses sigmoid activation for smooth, differentiable blending.

\section{Cloud Microphysics}
\label{sec:microphysics}

\subsection{Kessler Warm-Rain Scheme}

The single-moment Kessler scheme \citep{Kessler1969} is the canonical
warm-rain bulk parameterisation, tracking only condensate mass through the
sequence saturation adjustment $\to$ autoconversion $\to$ accretion $\to$
evaporation $\to$ sedimentation. Prognostic variables: $q_c$ (cloud water),
$q_r$ (rain).

\paragraph{Saturation adjustment.}
Supersaturation is removed by converting the excess vapour above $q_s$ into
cloud water. The saturation excess is converted to a tendency (rate) by
dividing by the time step $\Delta t$:
\begin{equation}
  \frac{\dd q_v}{\dd t}\bigg|_{\mathrm{sat}}
  = -\frac{\sigma(\kappa_s(q_v-q_s))\cdot(q_v-q_s)}{\Delta t},
\end{equation}
with sigmoid sharpness $\kappa_s$.  This ensures all microphysics outputs
have consistent units of kg\,kg$^{-1}$\,s$^{-1}$.

\paragraph{Autoconversion (cloud $\to$ rain).}
Once cloud water exceeds a threshold $q_{c,\mathrm{thresh}}$, collision and
coalescence initiate rain at rate $k_{\mathrm{auto}}$; the \texttt{softplus}
smooths the Kessler threshold so the onset stays differentiable:
\begin{equation}
  \frac{\dd q_c}{\dd t}\bigg|_{\mathrm{auto}}
  = -k_{\mathrm{auto}}\,\mathrm{softplus}(q_c - q_{c,\mathrm{thresh}}),
  \qquad k_{\mathrm{auto}}=10^{-3}\;\text{s}^{-1},\quad
  q_{c,\mathrm{thresh}}=10^{-3}\;\text{kg/kg}.
\end{equation}

\paragraph{Accretion (collection of cloud by rain).}
Existing raindrops sweep up cloud droplets at a rate set by the product of
cloud and rain content, the fractional power on $q_r$ reflecting the
mass-weighted fall-speed/cross-section of the rain spectrum:
\begin{equation}
  \frac{\dd q_c}{\dd t}\bigg|_{\mathrm{accr}}
  = -k_{\mathrm{accr}}\,q_c\,q_r^{0.875},
  \qquad k_{\mathrm{accr}}=2.2.
\end{equation}

\paragraph{Rain evaporation.}
\begin{equation}
  \frac{\dd q_r}{\dd t}\bigg|_{\mathrm{evap}}
  = k_{\mathrm{evap}}\,\frac{q_s-q_v}{q_s}\,q_r^{0.525}.
\end{equation}

\paragraph{Sedimentation.}
Fall speed: $V_t = V_0\sqrt{\rho_{\mathrm{sfc}}/\rho}$ with $V_0=5$~m/s.

\paragraph{Latent heating.}
$\dd T/\dd t = (\Lv/\cpd)\cdot(\text{condensation} - \text{evaporation})$.

\subsection{Seifert--Beheng Two-Moment Warm Rain}

The two-moment scheme of \citet{SeifertBeheng2001} predicts both mass and
number, allowing the mean droplet size, and hence autoconversion efficiency,
to evolve with the drop spectrum rather than being fixed. Prognostic mass
($q_c,q_r$) and number concentration ($N_c,N_r$).

\paragraph{Autoconversion.}
Autoconversion is keyed to the mean droplet mass $x_c=q_c\rho/N_c$: rain forms
efficiently only once droplets grow past the separation mass $x^*$, the
sigmoid $\sigma$ providing a smooth onset in place of a hard size cutoff:
\begin{equation}
  \frac{\dd q_c}{\dd t}\bigg|_{\mathrm{auto}}
  = -k_{\mathrm{au}}\,q_c^2\,
  \sigma\!\bigl[\kappa(x_c - x^*)\bigr],
  \qquad x_c = \frac{q_c\,\rho}{N_c},
\end{equation}
where $k_{\mathrm{au}}=600$~m$^3$/(kg\,s), $x^*=2.6\times 10^{-10}$~kg
is the separation mass, and the sigmoid onset replaces the hard threshold.

\paragraph{Self-collection and breakup.}
\begin{equation}
  \frac{\dd N_r}{\dd t}\bigg|_{\mathrm{sc}}
  = -k_{\mathrm{sc}}\,N_r\,q_r\,\rho,
  \qquad
  \frac{\dd N_r}{\dd t}\bigg|_{\mathrm{br}}
  = +k_{\mathrm{br}}\,\sigma\bigl[\kappa(D_r-D_{\mathrm{eq}})\bigr]\,
  \bigl|\frac{\dd N_r}{\dd t}\big|_{\mathrm{sc}}\bigr|.
\end{equation}

\subsection{Morrison Double-Moment (Ice + Liquid)}

The Morrison two-moment scheme \citep{Morrison2005} extends the warm-rain
spectrum to mixed-phase clouds, adding prognostic cloud ice and snow and the
ice-microphysical pathways that convert between them:

\paragraph{Ice nucleation \citep{Cooper1986}.}
The number of activated ice crystals rises exponentially as temperature falls
below freezing, following the Cooper diagnostic:
\begin{equation}
  N_{i,\mathrm{target}} = \frac{N_{i,0}}{\rho}\,
  \exp\!\bigl[a_C(T_{\mathrm{freeze}}-T)\bigr].
\end{equation}

\paragraph{Depositional growth.}
\begin{equation}
  \frac{\dd q_i}{\dd t}\bigg|_{\mathrm{dep}}
  = k_{\mathrm{dep}}\,\mathrm{softplus}(S_i)\,\sqrt{N_i},
  \qquad S_i = \frac{q_v}{q_{s,i}}-1.
\end{equation}

\paragraph{Bergeron process (mixed-phase).}
Cloud water converts to ice in the temperature window
$T_{\mathrm{center}}-T_{\mathrm{width}} < T < T_{\mathrm{freeze}}$:
\begin{equation}
  \frac{\dd q_c}{\dd t}\bigg|_{\mathrm{Berg}}
  = -k_{\mathrm{Berg}}\,q_c\,f_{\mathrm{ice}}(T).
\end{equation}

\paragraph{Riming, aggregation, melting.}
Riming: $q_{c}\to q_i$ and $q_c\to q_s$ via collection.
Aggregation: $q_i\to q_s$ when crystals grow large enough.
Melting: sigmoid-activated near $T_{\mathrm{freeze}}$.

\paragraph{Fall speeds (power law).}
\begin{equation}
  V_t = a\Bigl(\frac{\rho\,q}{\rho_{\mathrm{sfc}}}\Bigr)^b,
  \qquad \text{rain: } a=130,\,b=0.5;\quad
  \text{ice: } a=50,\,b=0.25;\quad
  \text{snow: } a=30,\,b=0.3.
\end{equation}

\paragraph{Warm rain.}
Autoconversion and accretion default to \citet{KhairoutdinovKogan2000}
(KK2000), $P_{\mathrm{auto}}=1350\,q_c^{2.47}N_c^{-1.79}$ with $N_c$ in
cm$^{-3}$ and $P_{\mathrm{acc}}=67\,(q_cq_r)^{1.15}$.  The CAM6 MG2 variant
(\texttt{kk2000\_cam6}) uses CAM6's coefficient ($0.01\times1350$) and droplet-number exponent ($-1.1$) and adds MG2's enhancement for sub-grid liquid variance.
With \emph{in-cloud warm rain} enabled, as in the production configuration,
both rates are evaluated on the in-cloud water $q_c/f_\ell$ and rain
$q_r/f_p$ and multiplied back by $f_\ell$, where $f_\ell$ is the CLUBB liquid
cloud fraction (floored at $10^{-4}$) and $f_p$ the precipitation fraction.
Because the rates are strongly non-linear in $q_c$, evaluating them on the
grid mean would under-produce drizzle in partly cloudy cells.

\paragraph{Sedimentation sub-stepping.}
Hydrometeor sedimentation is sub-stepped per column with
$n=1+\lfloor\max_k V_k\Delta t/\Delta z_k\rfloor$ steps, as in MG2, so that a
fast-falling species can cross more than one layer per call; the number of
sub-steps is bounded by a static cap, and the count each column required is
reported.

\paragraph{Homogeneous ice nucleation.}
Optionally, haze droplets freeze homogeneously when the ice supersaturation
exceeds the threshold
$S_{\mathrm{hom}}(T)=a-bT$ ($a=2.349$, $b=1/259$~K$^{-1}$), the
linear fit of Ren and MacKenzie (2005) to the water-activity criterion of
\citet{Koop2000}, restricted to cirrus temperatures below about
$-38\,^\circ$C.  The production configuration enables it.

\subsection{Thompson Hybrid-Moment Microphysics}

The Thompson scheme \citep{Thompson2008} adds a graupel category, predicting
number for cloud ice and rain while diagnosing the remaining species. Rimed
ice exceeding a critical threshold converts to graupel, the sigmoid gating
the conversion smoothly above $R_{\mathrm{thresh}}$:
\begin{equation}
  \frac{\dd q_g}{\dd t}\bigg|_{\mathrm{rime}}
  = f_g\,\frac{\dd q_i}{\dd t}\bigg|_{\mathrm{rime}}
  \cdot\sigma\!\Bigl[\kappa\Bigl(\frac{\dd q_i}{\dd t}\bigg|_{\mathrm{rime}}
  - R_{\mathrm{thresh}}\Bigr)\Bigr].
\end{equation}

\section{Cloud Fraction}
\label{sec:clouds}

\subsection{Sundqvist (1988)}

The Sundqvist closure \citep{Sundqvist1989} diagnoses cloud fraction from
grid-mean relative humidity, assuming subgrid moisture variability fills the
cell with cloud as RH rises from a critical value $\mathrm{RH}_{\mathrm{crit}}$
to saturation:
\begin{equation}
  c_f = \mathrm{clamp}\!\Bigl(\frac{\mathrm{RH}-\mathrm{RH}_{\mathrm{crit}}}
  {1-\mathrm{RH}_{\mathrm{crit}}},\;0,\;1\Bigr),
  \qquad \mathrm{RH}_{\mathrm{crit}}=0.8.
\end{equation}
The clamp ensures $c_f\in[0,1]$, with clear skies below threshold and full
overcast at saturation.

\subsection{Xu--Randall}

\citet{XuRandall1996} combine relative humidity and condensate amount, so that cloud fraction
responds both to ambient RH and to the presence of condensate $q_c$:
\begin{equation}
  c_f = \mathrm{RH}^p\,\Bigl[1-\exp\!\Bigl(
  -\frac{\alpha\,q_c}{(1-\mathrm{RH})\,q_s}\Bigr)\Bigr],
  \qquad p=2,\;\alpha=100.
\end{equation}

\subsection{CAM6 Cloud Fraction with CLUBB}
\label{sec:cam6-clouds}

The \texttt{cam6\_clubb} scheme (MPAS lane, production) assembles the cloud
fraction as CAM6 does from three parts: the liquid fraction $a_{\ell}$ of the
CLUBB assumed PDF (Section~\ref{sec:clubb}), an ice-stratus fraction
$a_i$, and a deep-convective fraction $a_{\mathrm{dc}}$:
\begin{equation}
  c_f=\min\bigl(\max(a_\ell,a_i)+a_{\mathrm{dc}},\,1\bigr).
\end{equation}
The ice-stratus fraction ramps quadratically in the ice relative humidity
$\mathrm{RH}_i=(q_v+q_i)/q_s\cdot e_{s,\ell}/e_{s,i}$,
\begin{equation}
  a_i=\min\Bigl\{1,\Bigl[\max\Bigl(\frac{\mathrm{RH}_i-\mathrm{RH}_{\min}}
  {\mathrm{RH}_{\max}-\mathrm{RH}_{\min}},0\Bigr)\Bigr]^2\Bigr\},
\end{equation}
with $\mathrm{RH}_{\min}=0.80$ and $\mathrm{RH}_{\max}=1.0$ in the
troposphere and a step at ice saturation above an analytic tropopause
$p_{\mathrm{trop}}=250-150\cos^2\phi$~hPa, followed by CAM's limiters on
in-cloud ice.  The deep-convective fraction follows the updraught mass flux
$M_u$ of the convection scheme,
$a_{\mathrm{dc}}=\min\bigl(0.1\ln(1+500\,M_u),\,0.6\bigr)$ with $M_u$ in
kg\,m$^{-2}$\,s$^{-1}$, and is zeroed
where it is below 0.01 or the convective in-cloud water vanishes.  The scheme
requires the CLUBB cloud-fraction carry and explicit condensate from the
microphysics, and refuses the generic convective-cloud overlay.

\paragraph{Scheme dispatch.}
\texttt{cloud\_fraction.compute\_cloud\_properties} dispatches on
\texttt{config.scheme} and accepts \texttt{"sundqvist"},
\texttt{"xu\_randall"}, \texttt{"resolved"} (cloud-resolving: a cell is
smoothly fully cloudy where it holds condensate) or \texttt{"cam6\_clubb"};
any other value raises \texttt{ValueError}.  The relative humidity of the
RH-based schemes is measured against either the liquid or a mixed-phase
saturation curve.
Disabling cloud diagnostics is handled \emph{upstream} by setting
\texttt{cloud\_scheme="none"} on the caller's config so that
\texttt{compute\_cloud\_properties} is not invoked at all --- passing
\texttt{"none"} to this function directly is itself an error.  Earlier
versions silently fell back to Sundqvist for any unrecognised string,
masking config typos and dead branches; this is now uniform with the
rest of the \texttt{integration.py} factory contract.

\section{Boundary-Layer Turbulence}
\label{sec:pbl}

\subsection{Louis (1979) Local Closure}

The Louis scheme \citep{Louis1979} is a first-order local closure: eddy
diffusivities are set point-by-point from the local shear, mixing length, and
stability, with no nonlocal transport. It is robust and inexpensive, which is
why it remains a standard fallback above the boundary layer.

\subsubsection{Mixing Length}

The mixing length $l$ interpolates between the surface-layer scaling
$\kappa_{\mathrm{vK}}z$ near the ground and an asymptotic ceiling $l_{\max}$
aloft, where $\kappa_{\mathrm{vK}}$ is the von K\'arm\'an constant:
\begin{equation}
  l = \frac{\kappa_{\mathrm{vK}}\,z}{1+\kappa_{\mathrm{vK}}\,z/l_{\max}},
  \qquad \kappa_{\mathrm{vK}}=0.4,\quad l_{\max}=300\;\text{m}.
\end{equation}

\subsubsection{Richardson Number}

The gradient Richardson number $\mathrm{Ri}$ measures the competition between
stabilising buoyancy ($N^2$, the squared Brunt--V\"ais\"al\"a frequency in
virtual potential temperature $\theta_v$) and destabilising shear ($S^2$);
turbulence is suppressed where $\mathrm{Ri}$ is large and positive:
\begin{equation}
  \mathrm{Ri} = \frac{N^2}{S^2}, \qquad
  N^2 = \frac{g}{\theta_v}\frac{\pp\theta_v}{\pp z}, \qquad
  S^2 = \Bigl(\frac{\pp u}{\pp z}\Bigr)^2
  +\Bigl(\frac{\pp v}{\pp z}\Bigr)^2.
\end{equation}

\subsubsection{Stability Functions}
\begin{equation}
  f_m(\mathrm{Ri}) = \begin{cases}
    \displaystyle 1-\frac{2b\,\mathrm{Ri}}
    {1+3bc\,l^2|\mathrm{Ri}|^{1/2}/\Delta z^2} & \mathrm{Ri}<0,\\[8pt]
    \displaystyle \frac{1}{1+2b\,\mathrm{Ri}/\sqrt{1+d\,\mathrm{Ri}}}
    & \mathrm{Ri}\ge 0,
  \end{cases}
\end{equation}
with $b=c=d=5$.  Eddy diffusivities: $K_m=l^2\,S\,f_m$, $K_h=K_m$.

\subsection{Holtslag--Boville Nonlocal K-Profile}

Convective boundary layers transport heat and moisture even against the local
gradient, which a purely local closure cannot capture. The nonlocal
K-profile scheme \citep{HoltslagBoville1993} instead prescribes the
diffusivity as a fixed-shape profile spanning the diagnosed PBL depth,
optionally with a countergradient correction.

\subsubsection{PBL Height Diagnosis}

The PBL top is found from the bulk Richardson number, which compares the
buoyancy deficit relative to the surface against the bulk wind shear:
\begin{equation}
  \mathrm{Ri}_{\mathrm{bulk}}(z) = \frac{g}{\theta_{v,\mathrm{sfc}}}\,
  \frac{(\theta_v-\theta_{v,\mathrm{sfc}})\,z}{|\vect{V}|^2}.
\end{equation}
PBL height $h$ is diagnosed where $\mathrm{Ri}_{\mathrm{bulk}}$
crosses $\mathrm{Ri}_{\mathrm{crit}}=0.3$ (LMD94 default), using
sigmoid-weighted averaging for a smooth, differentiable diagnosis.

\subsubsection{K-Profile Inside PBL}

Within the PBL the diffusivity follows the cubic O'Brien-type profile: it
scales with the friction velocity $u_*$ and vanishes at both the surface and
$z=h$, peaking in the mixed layer:
\begin{equation}
  K_m = \kappa_{\mathrm{vK}}\,u_*\,z\,(1-z/h)^2.
\end{equation}
Above the PBL, Louis (1979) Ri-dependent mixing applies.

\subsection{TKE-Based Closure}

Prognostic turbulent kinetic energy:
\begin{equation}
  \frac{\pp\mathrm{TKE}}{\pp t} = P - \varepsilon + D + B,
\end{equation}
where $P$ is shear production, $\varepsilon=c_\varepsilon\,\mathrm{TKE}^{3/2}/l$
is dissipation, $D$ is diffusion, and $B$ is buoyancy production/destruction.
Closure: $K_m = c_m\sqrt{\mathrm{TKE}}\cdot l$, $K_h = K_m/\mathrm{Pr}_t$.

\subsection{Implicit Vertical Diffusion}

The backward-Euler tridiagonal system
$-a_k\,\varphi_{k-1}+b_k\,\varphi_k-c_k\,\varphi_{k+1}=d_k$ is solved
with the Thomas algorithm:
\begin{align}
  a_k &= \frac{\Delta t\,K_{k-1/2}}{\rho_k\,\Delta z_k\,\Delta z_{k-1/2}},
  \quad c_k = \frac{\Delta t\,K_{k+1/2}}{\rho_k\,\Delta z_k\,\Delta z_{k+1/2}},
  \quad b_k = 1+a_k+c_k.
\end{align}

\section{Surface Exchange Formulations}
\label{sec:surface}

\subsection{Neutral Bulk Aerodynamic Fluxes}

Surface fluxes are parameterised by bulk aerodynamic formulae, in which each
flux is the product of air density $\rho$, a transfer coefficient, the wind
speed $|\vect{V}|$, and the air--surface difference of the transported
quantity. Momentum stress $(\tau_x,\tau_y)$, sensible heat $\mathrm{SH}$, and
latent heat $\mathrm{LH}$ follow the same structure:
\begin{align}
  \tau_x &= -\rho\,C_D\,|\vect{V}|\,u, &
  \tau_y &= -\rho\,C_D\,|\vect{V}|\,v, \\
  \mathrm{SH} &= \rho\,\cpd\,C_H\,|\vect{V}|\,(T_s-T_a), &
  \mathrm{LH} &= \rho\,\Lv\,C_E\,|\vect{V}|\,(q_s-q_a),
\end{align}
with $C_D=C_H=C_E=1.5\times10^{-3}$. The neutral limit takes these
coefficients as constants; the next section makes them stability-dependent.

\subsection{Monin--Obukhov Similarity Theory (MOST)}

Monin--Obukhov similarity theory \citep{MoninObukhov1954} organises
surface-layer turbulence around a single stability parameter $\zeta=z/L$,
making the transfer coefficients functions of stability rather than constants.

\paragraph{Obukhov length.}
The Obukhov length $L$ is the height at which buoyant and shear production of
turbulence are comparable; it is built from the friction velocity $u_*$ and
the turbulent scales $\theta_*,q_*$ of temperature and humidity:
\begin{equation}
  L = -\frac{u_*^3\,T_v}
  {\kappa_{\mathrm{vK}}\,g\,(\theta_*+0.61\,T_a\,q_*)}.
\end{equation}

\paragraph{Businger--Dyer stability functions.}
The integrated stability corrections $\psi_m,\psi_h$ modify the neutral
logarithmic profile: convex unstable forms ($\zeta<0$) enhance mixing while
the linear stable branch ($\zeta\ge0$) of \citet{Businger1971} suppresses it.
For strongly stable conditions the \citet{Beljaars1995} formulation prevents
the fluxes from collapsing to zero:
\begin{equation}
  \psi_m(\zeta) = \begin{cases}
    2\ln\!\bigl(\frac{1+x}{2}\bigr)+\ln\!\bigl(\frac{1+x^2}{2}\bigr)
    -2\arctan x+\frac{\pi}{2}, & \zeta<0,\quad x=(1-16\zeta)^{1/4}, \\[4pt]
    -5\zeta, & \zeta\ge 0,
  \end{cases}
\end{equation}
\begin{equation}
  \psi_h(\zeta) = \begin{cases}
    2\ln\!\bigl(\frac{1+y}{2}\bigr), & \zeta<0,\quad y=(1-16\zeta)^{1/2}, \\[4pt]
    -5\zeta, & \zeta\ge 0.
  \end{cases}
\end{equation}

\paragraph{Transfer coefficients.}
The coefficients then follow from the stability-corrected logarithmic
profiles, with $z_0$ and $z_{0t}$ the momentum and thermal roughness lengths:
\begin{equation}
  C_D = \Bigl[\frac{\kappa_{\mathrm{vK}}}
  {\ln(z/z_0)-\psi_m(\zeta)}\Bigr]^2, \qquad
  C_H = \frac{\kappa_{\mathrm{vK}}^2}
  {[\ln(z/z_0)-\psi_m(\zeta)][\ln(z/z_{0t})-\psi_h(\zeta)]}.
\end{equation}
Because $\zeta$ itself depends on the fluxes, this is a fixed-point problem.
The iterative solver (5 iterations via \texttt{jax.lax.fori\_loop}) is
fully differentiable.

\subsection{COARE 3.0 Roughness}

Over ocean the momentum roughness is sea-state dependent, combining a
wind-driven Charnock term with a viscous smooth-flow limit, following the
COARE 3.0 algorithm \citep{Fairall2003}:
\begin{equation}
  z_0 = \alpha_c\,\frac{u_*^2}{g}+0.11\,\frac{\nu}{u_*},
  \qquad
  z_{0t} = \min\!\bigl(1.15\times10^{-4},\;
  5.5\times10^{-5}\,\mathrm{Re}_*^{-0.6}\bigr),
\end{equation}
where $\alpha_c=0.011$ is the Charnock parameter.

\subsection{Large \& Yeager (2004) Roughness}

An alternative parameterises the neutral $10$-m drag coefficient $C_{DN}$
directly as a function of the neutral wind speed $U_{10N}$, following the CORE
bulk formulae of \citet{LargeYeager2004}:
\begin{equation}
  C_{DN}\times10^3 = \frac{2.7}{U_{10N}}+0.142+0.0764\,U_{10N}.
\end{equation}
The three terms capture the low-wind viscous regime, a roughly constant
mid-wind plateau, and the linear growth of drag in high winds.

\section{Gravity Wave Drag}
\label{sec:gwd}

\subsection{Orographic GWD (Lindzen 1981)}

Stably-stratified flow over topography launches vertically-propagating gravity
waves that carry momentum upward and deposit it where they break, decelerating
the resolved flow. The launch stress follows the orographic drag closure of
\citet{McFarlane1987} and the saturation/wave-breaking criterion of
\citet{Lindzen1981}.

\paragraph{Surface stress.}
The launched stress $\tau_0$ scales with density, the Brunt--V\"ais\"al\"a
frequency $N$, the horizontal wavenumber $k$, the squared obstacle height
$h_{\mathrm{topo}}^2$, and the low-level wind $U$:
\begin{equation}
  \tau_0 = \rho\,N\,k\,h_{\mathrm{topo}}^2\,U,
  \qquad N = \sqrt{\frac{g}{\theta}\frac{\dd\theta}{\dd z}}.
\end{equation}

\paragraph{Saturation criterion.}
As the wave amplitude grows with height it eventually overturns the local
stratification. Waves break when the Froude number
$\mathrm{Fr}=U/(N\,h_{\mathrm{topo}})$ drops below a critical value.  Stress is
capped at the saturation value $\tau_{\mathrm{sat}}=\rho\,|U|^3\,k/N$, so that
the excess momentum flux is deposited locally.

\paragraph{Momentum deposition.}
The drag on the resolved flow is the vertical divergence of the wave stress:
where $\tau$ decreases with height, momentum is delivered to the mean flow:
\begin{equation}
  \frac{\dd u}{\dd t}\bigg|_{\mathrm{GWD}} = -\frac{1}{\rho}\,
  \frac{\dd\tau}{\dd z}.
\end{equation}

\paragraph{Frictional heating.}
Energy conservation requires that the kinetic energy lost to wave drag reappear
as heat, recovered from the dot product of wind and momentum tendency:
\begin{equation}
  \frac{\dd T}{\dd t}\bigg|_{\mathrm{GWD}} =
  -\frac{1}{\cpd}\Bigl(u\,\frac{\dd u}{\dd t}+v\,\frac{\dd v}{\dd t}\Bigr).
\end{equation}

\section{Held--Suarez Forcing}
\label{sec:held-suarez}

The idealised forcing benchmark of \citet{HeldSuarez1994} replaces full
physics with analytic relaxation, providing a reproducible test of a dry
dynamical core's general circulation.

\paragraph{Equilibrium temperature.}
The radiative-equilibrium target $T_{\mathrm{eq}}$ imposes an equator-to-pole
contrast ($\Delta T_y$) and a static-stability gradient ($\Delta\theta_z$),
floored at $200$~K to mimic the stratosphere:
\begin{equation}
  T_{\mathrm{eq}} = \max\!\Bigl(200,\;
  \bigl[315-\Delta T_y\sin^2\!\phi
  - \Delta\theta_z\ln(p/\pref)\cos^2\!\phi\bigr]
  (p/\pref)^\kappa\Bigr),
\end{equation}
with $\Delta T_y=60$~K, $\Delta\theta_z=10$~K.

\paragraph{Newtonian relaxation.}
Temperature is restored toward $T_{\mathrm{eq}}$ at a rate $k_T$ that is fast
in the tropical boundary layer (mimicking strong surface coupling) and slow in
the free atmosphere, the transition keyed to $\sigma_b$:
\begin{equation}
  \frac{\dd T}{\dd t} = -k_T(\sigma,\phi)\,(T-T_{\mathrm{eq}}),
  \qquad
  k_T = k_a + (k_s-k_a)\max\!\Bigl(0,\frac{\sigma-\sigma_b}{1-\sigma_b}\Bigr)
  \cos^4\!\phi,
\end{equation}
with $k_a=1/(40\;\text{day})$, $k_s=1/(4\;\text{day})$, $\sigma_b=0.7$.

\paragraph{Rayleigh friction.}
Low-level momentum is damped to represent boundary-layer drag, again confined
below $\sigma_b$:
\begin{equation}
  \frac{\dd\vect{v}}{\dd t} = -k_v(\sigma)\,\vect{v},
  \qquad
  k_v = k_f\max\!\Bigl(0,\frac{\sigma-\sigma_b}{1-\sigma_b}\Bigr),
  \qquad k_f=1/(1\;\text{day}).
\end{equation}


\section{Additional Turbulence Schemes}

\subsection{Smagorinsky}
Constant eddy diffusivity: $K_m = K_h = \mathrm{const}$.

\subsection{YSU (Yonsei University)}
Nonlocal K-profile boundary-layer scheme with explicit entrainment at the PBL top, following \citet{HoltslagBoville1993} with enhanced counter-gradient terms.

\subsection{CLUBB-lite}
A reduced higher-order closure in the spirit of CLUBB \citep{Golaz2002},
carrying five prognostic second moments:
$\overline{w'^2}$, $\overline{\theta_l'^2}$, $\overline{r_t'^2}$,
$\overline{w'\theta_l'}$, $\overline{w'r_t'}$.
Cloud fraction and condensate are diagnosed by integrating an assumed
bivariate Gaussian PDF of $\theta_l$ and $r_t$, unifying boundary-layer
turbulence and shallow-cloud closure in a single framework.

\subsection{CLUBB}
\label{sec:clubb}
The \texttt{clubb} scheme is a fuller port of CLUBB \citep{Golaz2002},
restricted to the call tree of the CAM-default model flags, with every
component either reproduced to round-off against the CLUBB-JAX port or pinned
against an independent transcription of the CLUBB Fortran.  Its eddy
diffusivity uses CLUBB's parcel buoyancy-sorting mixing length $L$,
$K_m=c_K\,L\,\sqrt{e}$, and it diagnoses cloud fraction and liquid water from
the ADG1 double-Gaussian PDF.  In its default (diagnostic) form the mean fields
are advanced by the shared implicit eddy diffusion with $\overline{w'^2}$
carried as a prognostic budget.  In the prognostic form, used in production,
the full set of higher-order moments is advanced --- the coupled
$\overline{w'^2}$/$\overline{w'^3}$ system, the variances and covariances of
$\theta_l$ and $r_t$, and the turbulent fluxes
$\overline{w'\theta_l'}$, $\overline{w'r_t'}$ --- through implicit tridiagonal
and pentadiagonal solves coupled by the PDF buoyancy flux, with the surface
second moments set by CLUBB's surface-variance boundary condition.  As in CAM,
the PDF closure is evaluated on both the thermodynamic and momentum level sets.
With the liquid partition enabled (production), CLUBB exchanges cloud liquid
with the host as CAM's interface does: total water $r_t=q_v+q_c$ enters, and
the PDF liquid $\bar r_c$ is returned as cloud water with $q_v=r_t-\bar r_c$,
so the microphysics and radiation see the condensate whose cloud fraction
CLUBB diagnosed.  The mixing is tapered to zero above a configurable pressure
(150~hPa in production).

\subsection{EDMF Turbulence}
Eddy-diffusivity mass-flux unified boundary-layer framework combining
diffusive transport (for weakly convective conditions) with explicit
updraft mass flux (for strongly convective conditions) in a single scheme.

\section{Additional Convection Schemes}
\label{sec:conv-additional}

\subsection{Tiedtke, Kain--Fritsch and Emanuel}
The \citet{Tiedtke1989} bulk mass-flux scheme blends deep, mid-level and
shallow cloud types smoothly on cloud depth and carries its per-level updraught
mass-flux profile between steps.  The Kain--Fritsch scheme fires on a smoothed
boundary-layer parcel trigger at the lifting condensation level and blends
deep and shallow branches.  The Emanuel scheme mixes the parcel with
environmental air over a spectrum of mixing fractions and sorts the mixtures
by buoyancy, giving a per-level spread of detrainment heights, with an
optional unsaturated downdraught.  In all three the thresholds are sigmoid
gates so that gradients flow through the triggers.

\subsection{Kuo}
The \citet{Kuo1974} column moisture-excess scheme activates when column-integrated moisture
convergence exceeds a threshold.  Excess moisture is partitioned between
heating (fraction $\alpha_{\mathrm{heat}}$) and moistening
($1-\alpha_{\mathrm{heat}}$).

\subsection{Deep Convective Adjustment (DCA)}
Bottom-to-top column adjustment toward a moist-adiabatic reference profile,
with smooth sigmoid activation for JAX differentiability.

\section{Gravity Wave Drag Schemes}
\label{sec:gwd-schemes}

Seven GWD parameterisations are available, and several may be combined into
one composite source (for example \texttt{hines+mcfarlane}, orographic plus
non-orographic):
\begin{enumerate}[nosep]
  \item \textbf{Rayleigh friction}: Linear damping above a threshold height.
  \item \textbf{Lindzen (1981)}: Orographic GWD with saturation and critical-level absorption \citep{Lindzen1981}.
  \item \textbf{McFarlane (1987)}: Enhanced orographic scheme with improved wave saturation \citep{McFarlane1987}.
  \item \textbf{Hines-inspired}: a bulk non-orographic GWD closure motivated by \citet{Hines1997}.  A single rms wave amplitude grows as $\rho^{-1/2}$ upward and saturates against the scale $N/m_*$, and the stress decrement is deposited as drag; the Doppler-spread spectrum of the full Hines scheme is not represented.  Waves are launched at 700\,hPa by default (legal range 300--900\,hPa), above the boundary layer: no drag is deposited at or below the launch level, and a column whose launch level would be its lowest model level (for example, terrain whose surface pressure is below the launch pressure) has no source.  There is no surface launch, because there the weak stratification of the mixed layer makes the wave break immediately and deposit most of its momentum near the ground.
  \item \textbf{E3SM/CAM spectral GWD}: a term-by-term port of the
    spectral solver of E3SM version 3.0.1 --- a bottom-up stress
    profile with Lindzen saturation and WKB damping, then a top-down
    stress-divergence tendency with stability limiters --- driven by
    selectable orographic (McFarlane), frontal (frontogenesis-triggered
    Gaussian spectrum) and convective (Beres) sources.
  \item \textbf{Prognostic Spectral}: Multi-azimuthal ($N_{\mathrm{az}}$), multi-wavenumber ($N_k$) spectrum with prognostic wave momentum flux and vertical propagation via \texttt{jax.lax.scan}, following the spectral non-orographic approach of \citet{AlexanderDunkerton1999}.
  \item \textbf{ML Emulator}: Equinox MLP surrogate mapping column state to GWD tendencies.
\end{enumerate}

\section{Neural and Learned Physics}

Because every parameterisation above is differentiable, learned components can
be substituted for, or blended with, the physical schemes and trained
end-to-end through the dynamical core. This mirrors the hybrid neural--physical
modelling strategy of \citet{Kochkov2024}; related operator-learning work uses
Fourier neural operators \citep{Li2021} and their spherical variant
\citep{Bonev2023} for the global maps (see Chapter~\ref{ch:ml}).

\subsection{NeuralPhysics}
An Equinox MLP column model that maps the column state (temperature, moisture, wind, surface fluxes) to physics tendencies.  Hybrid mode blends learned corrections with conventional parameterisation output via a configurable blending coefficient.

\subsection{LearnedColumn}
Per-column physics replacement following \citet{Rasp2018}, mapping the full column state vector to temperature and moisture tendencies via a neural network, trainable end-to-end with the dynamical core.

\section{Boussinesq Hydrostatic Primitive Equations}

The ocean dynamical core integrates the hydrostatic Boussinesq primitive
equations in finite-volume form \citep{Marshall1997}, in which the full
in-situ density is replaced by a constant reference density $\rho_0$ in
the inertial terms while density variations are retained only in the
buoyancy (pressure-gradient) term.  Writing the horizontal momentum
balance in vector-invariant form on the cubed sphere isolates the
absolute vorticity and kinetic-energy gradient, which keeps the
advection operator energy- and enstrophy-aware on the staggered grid:
\begin{align}
  \frac{\pp u}{\pp t} &= (\zeta+f)\,v - \frac{\pp K}{\pp x}
  - \frac{1}{\rho_0}\frac{\pp p'}{\pp x}
  + A_h\nabla^2 u + \frac{\pp}{\pp z}\!\Bigl(A_v\frac{\pp u}{\pp z}\Bigr)
  - w\frac{\pp u}{\pp z}, \\
  \frac{\pp v}{\pp t} &= -(\zeta+f)\,u - \frac{\pp K}{\pp y}
  - \frac{1}{\rho_0}\frac{\pp p'}{\pp y}
  + A_h\nabla^2 v + \frac{\pp}{\pp z}\!\Bigl(A_v\frac{\pp v}{\pp z}\Bigr)
  - w\frac{\pp v}{\pp z}.
\end{align}
Here $u,v$ are the horizontal velocity components, $\zeta$ the relative
vorticity, $f$ the Coriolis parameter, $K=\half(u^2+v^2)$ the kinetic
energy per unit mass, $p'$ the baroclinic pressure perturbation, and
$A_h,A_v$ the lateral and vertical eddy viscosities; the final term
$-w\,\pp u/\pp z$ is vertical advection of momentum.  Each line therefore
expresses the local acceleration as the sum of Coriolis, kinetic-energy
gradient, pressure-gradient, lateral- and vertical-diffusion, and
vertical-advection contributions.  The Coriolis force is split: depth-mean
$f\vect{v}$ in the barotropic substeps, baroclinic shear $f\vect{v}'$ in
the slow tendencies, so that the fast surface-gravity-wave Coriolis
rotation is treated at the short barotropic step.

\subsection{Tracer Equations (Skew-Symmetric)}

Each active and passive tracer $\phi$ (potential temperature, salinity,
biogeochemical fields) obeys an advection--diffusion balance.  The
horizontal advection is written in skew-symmetric form, averaging the
advective $-\vect{v}\!\cdot\!\grad\phi$ and flux $-\divg(\phi\,\vect{v})$
operators; because the velocity field is discretely non-divergent, this
combination conserves both the tracer mean and its variance, suppressing
the spurious extrema a one-sided form would generate:
\begin{equation}
  \frac{\pp\phi}{\pp t} = \half\Bigl[-\vect{v}\!\cdot\!\grad\phi
  - \divg(\phi\,\vect{v})\Bigr]
  - w\frac{\pp\phi}{\pp z}
  + K_h\nabla^2\phi
  + \frac{\pp}{\pp z}\!\Bigl(K_v\frac{\pp\phi}{\pp z}\Bigr).
\end{equation}
The remaining terms are vertical advection and the lateral ($K_h$) and
vertical ($K_v$) diffusive fluxes.

\subsection{Free-Surface Equation}

Vertically integrating the continuity equation gives the prognostic
free-surface height $\eta$, whose tendency is the column-summed
horizontal volume-flux divergence:
\begin{equation}
  \frac{\pp\eta}{\pp t} = -\sum_k \divg(h_k\,\vect{v}_k).
\end{equation}
This sets the fast external-gravity-wave mode that the barotropic solver
below integrates with a short substep.


\section{Barotropic Solver}
\label{sec:barotropic}

To avoid resolving the fast surface-gravity wave at the slow baroclinic
timestep, the depth-integrated (barotropic) mode is advanced separately
with a split-explicit forward--backward integrator
\citep{ShchepetkinMcWilliams2005}, sub-cycled many short substeps
$\Delta t_s$ per baroclinic step.  The barotropic state is the surface
height $\eta$ and the depth-mean transport $\bar{\vect{V}}$, forced by the
slow tendency $\vect{F}_{\mathrm{slow}}$ that carries the vertically
integrated baroclinic pressure gradient and advection:
\begin{equation}
  \frac{\pp\eta}{\pp t} = -\divg(H\,\bar{\vect{V}}),
  \qquad
  \frac{\pp\bar{\vect{V}}}{\pp t} = f\hat{\vect{k}}\times\bar{\vect{V}}
  - g\grad\eta + \vect{F}_{\mathrm{slow}}.
\end{equation}
The forward--backward ordering (update $\eta$ first, then use the new
$\eta$ in the momentum step) damps the computational mode and extends the
stable substep relative to a centred scheme.

\paragraph{Semi-implicit Coriolis.}
With $\alpha=\half f\,\Delta t_s$:
\begin{equation}
  \bar U^{n+1} = \frac{R_u+\alpha\,R_v}{1+\alpha^2},
  \qquad
  \bar V^{n+1} = \frac{R_v-\alpha\,R_u}{1+\alpha^2},
\end{equation}
where $R_u=\bar U^n+\alpha\bar V^n-\Delta t_s\,g\,\pp\eta/\pp x$ and
$R_v=\bar V^n-\alpha\bar U^n-\Delta t_s\,g\,\pp\eta/\pp y$.  Treating the
Coriolis rotation implicitly over the substep prevents the inertial
oscillation from being amplified by the many barotropic sub-cycles and
keeps the substep stability set by the gravity-wave CFL alone.

\paragraph{Implicit free surface.}
As an alternative to sub-cycling, the barotropic mode can be advanced in one
step with a $\theta$-weighted Crank--Nicolson free surface
($\theta=0.55$ for both the surface elevation and the pressure gradient,
slightly past centred to suppress chequerboard noise), which reduces to a
Helmholtz equation for $\eta$ solved by preconditioned conjugate gradients.
On the MPAS mesh this removes the rotational null branch of the TRiSK
barotropic operator by construction.  In distributed runs the solve uses a
fixed number of iterations (20) so that its cost and its adjoint are
static; the default preconditioner is a communication-free Neumann-series
polynomial (four sweeps) in each device's block of the operator, and the
Chronopoulos--Gear single-reduction variant batches each iteration's two
inner products into one global reduction.  A variant that applies the same
polynomial to the global operator, making the result independent of the
device count, is available.


\section{Equation of State (Wright 1997)}
\label{sec:eos}

The ocean prognostic temperature variable $T$ is \textbf{potential
temperature} [degC].  The Wright~(1997) EOS \citep{Wright1997} computes
in-situ density $\rho(\theta,S,p)$ directly from potential temperature
$\theta$, salinity $S$~[PSU], and pressure $p$~[Pa].  This rational-function
fit captures the leading nonlinearity of seawater density (thermobaricity
and cabbeling), which drives the buoyancy term in the momentum equations;
a higher-order TEOS-10 polynomial alternative \citep{Roquet2015,
McDougallBarker2011} is available where conservative temperature is the
prognostic variable:
\begin{equation}
  \rho = \frac{p+p_0(\theta,S)}{\lambda(\theta,S)+\alpha_0(\theta,S)\,(p+p_0)},
\end{equation}
where
\begin{align}
  \alpha_0 &= a_0+a_1 \theta+a_2 S, \\
  p_0 &= (b_0+b_4 S)+\theta(b_1+\theta(b_2+b_3 \theta)+b_5 S), \\
  \lambda &= (c_0+c_4 S)+\theta(c_1+\theta(c_2+c_3 \theta)+c_5 S).
\end{align}
Here $\alpha_0$, $p_0$ and $\lambda$ are low-order polynomials in
$(\theta,S)$ with coefficients $a_i,b_i,c_i$.  Coefficients follow the
MOM6 implementation.  Only the density perturbation
$\rho'=\rho(\theta,S,p)-\rho_0$ enters the pressure-gradient computation,
consistent with the Boussinesq approximation in which $\rho_0$ carries the
inertia and $\rho'$ supplies the buoyancy.


\section{Hydrostatic Pressure and Vertical Velocity}

Under the hydrostatic approximation the vertical momentum equation reduces
to the balance between the vertical pressure gradient and buoyancy, so the
baroclinic pressure at level $k$ follows from downward integration of the
density perturbation, with the surface load $\rho_0 g\eta$ as the upper
boundary value and a half-cell term that centres the pressure within the
$k$-th layer:
\begin{equation}
  p'_k = \rho_0 g\eta + \sum_{k'=0}^{k-1}\rho'_{k'}\,g\,\Delta z_{k'}
  + \half\rho'_k\,g\,\Delta z_k.
\end{equation}

The vertical velocity is not prognostic; it is diagnosed from continuity
by integrating the horizontal-flux divergence upward from the rigid floor
($w=0$ at the bottom), so that the discrete velocity field remains
non-divergent layer by layer:
\begin{equation}
  w_{k-1/2} = -\sum_{k'=k}^{N-1}\divg(h_{k'}\,\vect{v}_{k'}).
\end{equation}


\section{Vertical Mixing: K-Profile Parameterisation (KPP)}
\label{sec:kpp}

Following \citet{LMD1994}:

\subsection{Boundary Layer Depth}

The boundary layer depth $h$ is diagnosed where the bulk Richardson number
crosses $\mathrm{Ri}_{\mathrm{crit}}=0.3$ (LMD94 default):
\begin{equation}
  \mathrm{Ri}_b(z) = \frac{g\,\Delta\rho\,z}
  {\rho_0\,(|\Delta\vect{V}|^2+V_t^2)},
\end{equation}
using sigmoid-weighted averaging for a differentiable diagnosis.

\subsection{K-Profile Shape}

Within the diagnosed boundary layer the eddy diffusivity is prescribed as
a smooth cubic shape function $G(\sigma)$ scaled by the layer depth $h$
and the turbulent velocity scale $w_s$, where $\sigma=z/h$ is the
fractional depth.  The shape vanishes at the surface and at the layer base
and peaks in the interior, matching the observed near-surface turbulent
diffusivity profile:
\begin{equation}
  K_m(\sigma) = h\,w_s(\sigma)\,G(\sigma),
  \qquad G(\sigma) = \sigma(1-\sigma)^2,
  \qquad \sigma=z/h,
\end{equation}
where $w_s$ is the turbulent velocity scale depending on surface fluxes
and stability.

\subsection{Non-Local Transport}

For unstable (convective) boundary layers ($B_f>0$), a non-local
counter-gradient flux is added to temperature and salinity tendencies.
The implementation uses a simplified form inspired by LMD94 Eq.~19:
\begin{equation}
  \frac{\pp T}{\pp t}\bigg|_{\mathrm{NL}} =
  \gamma_T\,\frac{w_s(0)\,G(\sigma)}{w_s(\sigma)\,h}\,
  \frac{\pp T}{\pp z}\bigg|_{\mathrm{sfc}},
\end{equation}
where $\gamma_T=\gamma_S=6.33$ are non-local transport coefficients
and $w_s(0)\,(\pp T/\pp z)|_{\mathrm{sfc}}$ is a surface heat flux
proxy [K\,m/s].  This differs from the full LMD94 non-local term, which
uses the explicit surface buoyancy flux $\overline{w'\theta'}_0$;
the present form approximates it via the near-surface gradient
and surface turbulent velocity scale.
This is active only within the diagnosed boundary layer ($\sigma<1$)
and only under unstable forcing.


\section{Vertical Mixing: Prognostic TKE Closures}
\label{sec:ocean-tke}

Two one-equation turbulent-kinetic-energy closures are available besides KPP.
The Gaspar/Burchard closure, as in NEMO's \texttt{zdftke} and Veros, solves
\begin{equation}
  \frac{\pp e}{\pp t}=K_M\Bigl[\Bigl(\frac{\pp u}{\pp z}\Bigr)^2
  +\Bigl(\frac{\pp v}{\pp z}\Bigr)^2\Bigr]-K_HN^2
  -c_\varepsilon\frac{e^{3/2}}{l_\varepsilon}
  +\frac{\pp}{\pp z}\Bigl(\alpha_e K_M\frac{\pp e}{\pp z}\Bigr),
  \qquad K_M=c_k\,l_k\sqrt{2e},
\end{equation}
with the mixing lengths from upward and downward integrations of the TKE
against the local stratification (Bougeault--Lacarr\`ere); NEMO's mixing-length
choices, surface boundary conditions and TKE floors are available as options so
the scheme can reproduce the NEMO configuration term by term.  CATKE
(Wagner et al.\ 2025) derives instead a dynamic convective mixing length from
the convective buoyancy flux and blends stable, shear and convective regimes with
separate coefficients for momentum, tracers and TKE.

\section{Lateral Mixing}
\label{sec:lateral}

Lateral mixing supplies the subgrid closure for unresolved horizontal
stirring and, in eddy-permitting configurations, the scale-selective
dissipation that controls the grid-scale noise the advection scheme
cannot.

\subsection{Harmonic (Laplacian) Diffusion}

The simplest closure is a constant-coefficient Laplacian diffusion, which
damps all scales monotonically:
\begin{equation}
  D_h = A_h\,\nabla^2\phi.
\end{equation}

\subsection{Biharmonic ($\nabla^4$) Diffusion}

A biharmonic operator is more scale-selective: it leaves the resolved
large scales nearly untouched while strongly damping the $2\Delta x$
computational mode, which is preferred for eddying solutions.  The
coefficient $A_4$ may be set by a Smagorinsky-like strain-rate closure
following \citet{GriffiesHallberg2000}:
\begin{equation}
  D_h = -A_4\,\nabla^4\phi.
\end{equation}

\subsection{Gent--McWilliams / Redi Parameterisation}

The GM parameterisation represents the effect of mesoscale eddies on
tracer transport via an additional advective flux (bolus velocity)
\citep{GM1990}:
\begin{equation}
  \vect{u}^* = -\kappa_{\mathrm{GM}}\,\grad_h s,
\end{equation}
where $s=-\grad_h\rho/(\pp\rho/\pp z)$ is the isopycnal slope and
$\kappa_{\mathrm{GM}}$ the thickness diffusivity.  This adiabatic eddy
transport flattens isopycnals and extracts available potential energy,
mimicking baroclinic-eddy restratification.  The accompanying Redi
diffusion tensor \citep{Redi1982} rotates the lateral diffusion to act
along isopycnal surfaces rather than along geopotentials, which suppresses
the spurious diapycnal mixing a horizontal Laplacian would otherwise
introduce on sloping density surfaces.


\section{Tracer Advection Schemes}
\label{sec:ocean-advection}

The legoESM ocean carries a family of flux-form tracer advection
schemes of increasing accuracy in
\texttt{packages/ocean/legoesm/ocean/advection.py} and
\texttt{advection\_som.py}.  Following \citet{Hill2012}, implicit
numerical mixing is the dominant source of spurious diapycnal
transport in $z$-coordinate models, so the volume-weighted variance
$\Var(T) = \int (T-\langle T\rangle)^2\,\dd V$ is used as the
definitive evaluation metric (it is an exact inviscid invariant in
closed-domain zero-$K_h$ Eady setups).

\section{Slab and Two-Layer Ocean}

For idealised experiments that do not require the full dynamical ocean, a
slab mixed layer evolves the surface temperature $T_s$ from the column
energy balance: net shortwave and longwave radiation, sensible (SH) and
latent (LH) turbulent fluxes, a prescribed ocean-heat-transport
convergence $Q_{\mathrm{flux}}$ that closes the climatological energy
budget, and a restoring exchange $K_{\mathrm{mix}}(T_{\mathrm{deep}}-T_s)$
with the deep reservoir:
\begin{equation}
  C_{\mathrm{mix}}\,\frac{\dd T_s}{\dd t}
  = \mathrm{SW}_{\mathrm{net}} + \mathrm{LW}_{\mathrm{net}}
  - \mathrm{SH} - \mathrm{LH}
  + Q_{\mathrm{flux}} + K_{\mathrm{mix}}(T_{\mathrm{deep}}-T_s),
\end{equation}
where $C_{\mathrm{mix}}=\rho_{\mathrm{ocn}}\,c_{\mathrm{ocn}}\,h_{\mathrm{mix}}$
is the mixed-layer heat capacity set by the mixed-layer depth
$h_{\mathrm{mix}}$, which fixes the thermal inertia and hence the seasonal
SST response.


\section{Realistic-Geometry Spinup on ETOPO Bathymetry}
\label{sec:realistic-geometry-ocean}

The lat-lon C-grid ocean supports global Wolfe--Cessi-style spinups on
real ETOPO/GEBCO bathymetry through a topology-aware loader and a set
of stability-conditioning operators specific to coastal partial cells
and high latitudes.

\paragraph{Bathymetry pre-processing.}
\texttt{packages/ocean/legoesm/ocean/bathymetry.py} exposes
\texttt{BathymetryConfig} and the per-grid loaders
(\texttt{load\_bathymetry\_latlon\_cgrid},
\texttt{load\_bathymetry\_cubed\_sphere},
\texttt{load\_bathymetry\_mpas},
\texttt{load\_bathymetry\_gaussian}).  The pipeline is:
\begin{enumerate}[nosep]
  \item Auto-detect the depth/elevation variable across ETOPO, GEBCO,
        NOAA ERDDAP, and generic CF conventions.
  \item Regrid to the model grid (conservative or bilinear) and clip
        to $H \in [H_{\min}, H_{\max}]$ with $H_{\min} = 50$~m by
        default (preserves mid-ocean ridges).
  \item Optional Laplacian smoothing on the cubed-sphere or
        Voronoi mesh (\texttt{\_laplacian\_smooth\_2d},
        \texttt{\_laplacian\_smooth\_voronoi}).
  \item Steepness-cap via the Mellor--Ezer--Oey iteration
        \texttt{apply\_meo\_r\_factor\_cap} which enforces
        $r_{\max} = |\Delta H|/(2\bar H) \le r_{\mathrm{cap}}$
        (typical $r_{\mathrm{cap}}=0.2$); the per-call
        \texttt{initial\_r\_max} / \texttt{final\_r\_max} are logged
        for the diagnostic scripts.
  \item Optional polar-cap mask (\texttt{north\_cap\_lat},
        \texttt{south\_cap\_lat}) and \texttt{enforce\_straits} to
        thread Drake / Indonesian throughflow at low resolution.
  \item Isolated-basin filling
        (\texttt{\_fill\_isolated\_basins}) so disconnected pockets
        do not trap tracers.
\end{enumerate}

\paragraph{AL81 partial-cell Coriolis.}
The vector-invariant momentum branch uses an Arakawa--Lamb 1981
(``EEN'') 12-corner-triad PV-flux closure
(\texttt{pv\_flux\_al81\_partial\_cell} in
\texttt{latlon\_cgrid\_operators.py}).  Each $f$-point carries four
$1/12$-weighted L-shaped triads of vertex potential vorticity
$q = \zeta/h_{\mathrm{vtx}}$; the partial-cell extension after
\citet{LeSommer2009} weights each triad by the local wet-cell
thickness so that discrete potential enstrophy is preserved across
bottom steps.  Coastal triads use a Neumann fill of $q$ (three-pass
smoothing band-aid pending the formal mask-projection closure
documented in \texttt{docs/ocean\_experiments/al81\_corner\_triad\_audit.md}).

\paragraph{Biharmonic viscosity scaling.}
Because lat-lon zonal spacing scales as $\cos\phi$, a constant
biharmonic coefficient $B_h$ violates CFL near the poles while
under-diffusing at the equator.
\texttt{biharmonic\_scaling\_factor(grid)} multiplies $B_h$ by
$\cos^4\phi$ at $u$- and $v$-faces following the MOM6 convention of
\citet{GriffiesHallberg2000}, so the effective diffusivity tracks
$dx^4_{\mathrm{local}}$ uniformly.  This is the dominant lever for
suppressing the alternating-sign $2\Delta y$ zonal-jet computational
mode that develops at the equator on partial cells.

\paragraph{Validated configuration.}
The 20-yr \texttt{global\_overturning\_realistic\_geometry} run
(branch \texttt{realistic-geometry-full}, PR \#224) uses
$A_h = 10^4\,\mathrm{m^2\,s^{-1}}$,
$B_h = 5{\times}10^9\,\mathrm{m^4\,s^{-1}}$,
$\kappa_{\mathrm{GM}} = \kappa_{\mathrm{Redi}} = 800\,\mathrm{m^2\,s^{-1}}$,
SMC03 pressure-gradient force, AL81 vorticity advection, implicit
Crank--Nicolson barotropic solver, and bottom-drag $r=2.5{\times}10^{-3}$.
Stratification reproduces the canonical thermohaline structure (warm
pool aloft, cold abyss, sloping isotherms, warm-equator/cold-pole SST
imprint).  Surface speeds remain inflated ${\sim}3$--$5\times$ above
realistic values from residual partial-cell $q$-stencil noise; the
follow-up plan is the full Sadourny--Salmon energy--enstrophy form
with all bottom-cell ENE corrections.  See
\texttt{docs/ocean\_experiments/realistic\_geometry\_phase4\_results.md}
for the year-by-year diagnostics.

\section{Carbonate Chemistry and Air--Sea CO$_2$ Exchange}

\subsection{Gas Transfer Velocity}

Air--sea CO$_2$ exchange is parameterised as a bulk flux proportional to a
gas transfer (piston) velocity $k_w$, which the quadratic wind-speed
relation of \citet{Wanninkhof2014} ties to the 10\,m wind $U_{10}$ and the
CO$_2$ Schmidt number $\mathrm{Sc}$, normalised to its reference value of
660:
\begin{equation}
  k_w = 0.251\,U_{10}^2\,\Bigl(\frac{\mathrm{Sc}}{660}\Bigr)^{-1/2},
\end{equation}
where the Schmidt number is a polynomial function of temperature:
\begin{equation}
  \mathrm{Sc} = 2116.8 - 136.25\,T + 4.7353\,T^2
  - 0.092307\,T^3 + 7.555\times10^{-4}\,T^4.
\end{equation}

\subsection{Net Air--Sea Flux}

The net flux is the piston velocity times the air--sea difference in CO$_2$
partial pressure, converted to a concentration gradient by the
temperature- and salinity-dependent Henry's-law solubility $K_0$; the sign
convention makes $F_{\mathrm{CO}_2}>0$ an outgassing from a supersaturated
ocean:
\begin{equation}
  F_{\mathrm{CO}_2} = k_w\,K_0\,
  (p\mathrm{CO}_{2,\mathrm{ocean}} - p\mathrm{CO}_{2,\mathrm{atm}}),
\end{equation}
where $K_0$ is Henry's law solubility.  The ocean surface $p$CO$_2$ is
computed from DIC, ALK, $T$, $S$ via the carbonate equilibria, solved for
$[\mathrm{H}^+]$ with the Newton--Raphson iteration of \citet{Follows2006},
which exploits the near-linear dependence of total alkalinity on $\mathrm{H}^+$
to converge in a few steps within the JIT-compiled column loop.


\section{NPZD Ecosystem Model}
\label{sec:npzd}

The ecosystem closure carries four biological tracers, NO$_3$ (nutrients),
$P$ (phytoplankton), $Z$ (zooplankton), and $D$ (detritus), exchanging
nitrogen along a single trophic chain following \citet{Fasham1990}.  Each
budget balances the source and sink terms of the cycle: phytoplankton gain
by growth $\mu_P P$ and lose to grazing $G$ and mortality; grazed nitrogen
is partitioned between assimilated zooplankton biomass (efficiency
$\gamma_Z$) and egested detritus; detritus remineralises at rate $r_D$ and
sinks at speed $w_s$; and nitrate is drawn down by uptake and replenished
by remineralisation, closing the nitrogen budget:
\begin{align}
  \frac{\pp P}{\pp t} &= \mu_P\,P - G - m_P\,P, \\
  \frac{\pp Z}{\pp t} &= \gamma_Z\,G - m_Z\,Z^2, \\
  \frac{\pp D}{\pp t} &= (1-\gamma_Z)G + m_P P + m_Z Z^2
  - r_D D + w_s\frac{\pp D}{\pp z}, \\
  \frac{\pp\mathrm{NO}_3}{\pp t} &= -\mu_P\,P + r_D\,D.
\end{align}

\paragraph{Phytoplankton growth.}
The growth rate multiplies the maximum rate $\mu_{\max}$ by a temperature
factor $f(T)$ and the more limiting of nutrient and light availability
(Liebig's law of the minimum), with the nutrient limitation a
Michaelis--Menten saturation in NO$_3$ and the light limitation a
saturating function of photosynthetically available radiation (PAR):
\begin{equation}
  \mu_P = \mu_{\max}\,f(T)\,\min(L_N,\,L_I),
  \qquad L_N = \frac{\mathrm{NO}_3}{k_N+\mathrm{NO}_3},
  \qquad L_I = 1-e^{-k_{\mathrm{PAR}}\cdot\mathrm{PAR}}.
\end{equation}

\paragraph{Grazing (Holling III).}
Zooplankton grazing uses a Holling type-III (sigmoidal) functional
response, whose $P^2$ numerator gives a low-prey refuge that stabilises the
predator--prey oscillation:
\begin{equation}
  G = g_{\max}\,\frac{P^2}{K_g+P^2}\,Z.
\end{equation}

Redfield stoichiometry ($R_{C:N}=6.625$) couples biology to DIC/ALK.


\section{Ocean Bottom Drag}

The bottom stress $\vect{\tau}_b$ removes momentum from the lowest wet
layer and is the main sink for the barotropic flow; two formulations are
available.

\paragraph{Linear drag.}
A Rayleigh (linear) drag $\vect{\tau}_b = -r\,\vect{u}_b$, with configurable
coefficient $r$, is the simplest closure and keeps the momentum operator
linear for idealised spin-down problems.

\paragraph{Quadratic drag.}
The quadratic law $\vect{\tau}_b = -C_d\,|\vect{u}_b|\,\vect{u}_b$, with
$C_d = 2.5\times10^{-3}$ (default), follows the turbulent log-layer scaling
and is preferred for realistic geometry where bottom speeds vary widely.

\section{Ocean Surface Forcing}

The surface boundary condition supplies the momentum, heat, and freshwater
fluxes that drive the ocean.  Three modes are available, trading physical
fidelity against simplicity:
\begin{itemize}[nosep]
  \item \textbf{Prescribed}: Fixed wind stress ($\tau_x$, $\tau_y$) and heat flux with latitudinal profiles.
  \item \textbf{Restoring}: SST/SSS restoring toward climatology (Haney-style) with cosine latitude temperature profile ($25^\circ$C at equator, $0^\circ$C at poles).
  \item \textbf{Bulk formulas}: COARE-like air--sea fluxes with drag ($C_D$), Stanton ($C_H$), and Dalton ($C_E$) coefficients, reference height, and stability corrections, in the CORE forced-ocean configuration of \citet{LargeYeager2004}.
\end{itemize}
The bulk mode lets the ocean feed back on its own fluxes (a warmer surface
reduces sensible/latent loss), which a prescribed-flux setup cannot, and is
the standard choice for hindcast spinups.

\section{Shortwave Penetration}

Solar radiation that penetrates the surface heats a finite layer rather
than just the top cell, which controls the near-surface stratification and
mixed-layer heat budget.  Subsurface shortwave absorption follows the
Jerlov water-type classification \citep{Jerlov1976}
with five types (I, IA, IB, II, III).  Each type defines a two-band
exponential decay profile \citep{PaulsonSimpson1977}, splitting the flux into a rapidly attenuated
red band and a more penetrating blue-green band:
\begin{equation}
  I(z) = I_0\bigl[R\,e^{-z/\zeta_1} + (1-R)\,e^{-z/\zeta_2}\bigr],
\end{equation}
where the partition $R$ and the two e-folding depths $\zeta_1,\zeta_2$
depend on the water type (clearer water gives larger $\zeta_2$ and deeper
heating).

\section{Ocean Convection}

Static instability ($N^2<0$) must be removed rapidly to represent deep
convective overturning; two closures are provided.

\subsection{Enhanced Diffusion}
The simplest is convective adjustment by enhanced diffusivity: wherever the
stratification is statically unstable ($N^2 < 0$), the vertical diffusivity
is raised to $K_{\mathrm{conv}} = K_{\mathrm{max}}$, with smooth (sigmoid)
transitions to keep the closure differentiable, so that the unstable column
mixes back toward neutral within a few steps.

\subsection{Plume Model}
A more physical alternative is an entraining mass-flux plume that carries
dense surface water downward, with entrainment rate
$\alpha_{\mathrm{plume}}=0.1$ diluting the plume with ambient water and a
background detrainment $\varepsilon=10^{-3}$~m$^{-1}$ depositing it,
resolving the convective transport rather than only diffusing the
instability away.

\section{Frazil Ice}
\label{sec:frazil}

When the ocean cools below its freezing point the supercooling is removed by
forming frazil ice in place.  For a layer of initial liquid mass $M=\rho\Delta
z$ that produces ice mass $m$ (negative on melting) of salinity $S_i$, the
closure conserves mass, salt and heat content under a constant-enthalpy ice
approximation (ice sensible heat, pressure work and density changes are
omitted),
\begin{equation}
  M'=M-m,\qquad M'S'=MS-mS_i,\qquad M'c_pT'-m\Lf=Mc_pT,
\end{equation}
so the transported ice carries the constant specific enthalpy $-\Lf$
relative to liquid water at 0\,$^\circ$C.  The non-linear liquidus is solved
by a fixed number of contractive fixed-point iterations in in-situ
temperature, converting to and from the model's potential temperature through
the equation of state.  Optionally, frazil formed at depth remelts in warmer
layers above.  The closure is opt-in in the OMIP driver, where the
exported ice mass is deposited into the slab sea-ice tile, which must use the
same enthalpy and ice salinity (fresh ice for the slab).

\section{Richardson-Number Vertical Mixing}

Below the surface boundary layer, mixing is driven by shear instability,
parameterised so that the diffusivity decreases monotonically with the
gradient Richardson number $\mathrm{Ri}=N^2/S^2$, the ratio of stabilising
buoyancy stratification $N^2$ to destabilising vertical shear $S^2$:
\begin{equation}
  K_v = K_{v,0}\,(1 + 5\,\mathrm{Ri})^{-1},
  \qquad \mathrm{Ri} = \frac{N^2}{S^2},
\end{equation}
so that low-$\mathrm{Ri}$ (strongly sheared) regions mix toward the maximum
$K_{v,0}$ while well-stratified, weakly sheared interior layers approach
the molecular background.  This complements the KPP boundary-layer scheme
of Section~\ref{sec:kpp} with an interior shear-instability closure.

\section{Slab Land}

\subsection{Surface Energy Balance}
\begin{equation}
  C_s\,d_s\,\frac{\dd T_s}{\dd t}
  = (1-\alpha_l)\,\mathrm{SW}^\downarrow
  + \varepsilon_l(\mathrm{LW}^\downarrow-\SB T_s^4)
  - \mathrm{SH} - \mathrm{LH}.
\end{equation}
This is the surface energy balance for a slab of heat capacity $C_s d_s$:
absorbed shortwave $(1-\alpha_l)\mathrm{SW}^\downarrow$ (with albedo $\alpha_l$),
net longwave (downwelling $\mathrm{LW}^\downarrow$ minus emission
$\varepsilon_l\SB T_s^4$ at emissivity $\varepsilon_l$), and turbulent sensible
$\mathrm{SH}$ and latent $\mathrm{LH}$ losses sum to the storage tendency.  The
finite slab heat capacity gives the surface a diurnal memory rather than forcing
instantaneous radiative equilibrium.

\subsection{Bucket Hydrology}
\begin{equation}
  \frac{\dd W}{\dd t} = P - E, \qquad W\in[0,W_{\max}].
\end{equation}
Moisture availability
$\beta=\beta_{\min}+(1-\beta_{\min})\,W/W_{\max}$ modulates evaporation
via $q_{\mathrm{sfc}}=\beta\,q_s(T_s)$.


\section{Multi-Layer Land Model}

\subsection{Soil Thermal Diffusion}
\begin{equation}
  C_{\mathrm{eff}}(z)\,\frac{\pp T}{\pp t}
  = \frac{\pp}{\pp z}\!\Bigl[k_{\mathrm{eff}}(z)\,\frac{\pp T}{\pp z}\Bigr],
\end{equation}
with effective heat capacity:
\begin{equation}
  C_{\mathrm{eff}} = (1-\theta_{\mathrm{sat}})\,C_{\mathrm{soil}}
  + \theta\,C_{\mathrm{water}}
  + (\theta_{\mathrm{sat}}-\theta)\,C_{\mathrm{air}},
\end{equation}
and thermal conductivity following the \citet{Johansen1975} parameterisation
via the Kersten number.  Solved implicitly using the Thomas algorithm with
surface heat flux and geothermal flux boundary conditions.

\subsection{Richards Equation (Soil Hydraulics)}
\begin{equation}
  \frac{\pp\theta}{\pp t} = \frac{\pp}{\pp z}
  \!\Bigl[K(\psi)\,\Bigl(\frac{\pp\psi}{\pp z}+1\Bigr)\Bigr],
\end{equation}
where $\theta$ is volumetric water content, $\psi$ is matric potential,
and $K(\psi)$ is hydraulic conductivity.  This is the mixed form of the Richards
equation: vertical water flux is driven by the sum of the matric-potential
gradient $\pp\psi/\pp z$ and the unit gravitational gradient, so that under
saturated, hydrostatic conditions ($\pp\psi/\pp z=-1$) the flux vanishes.

The closure relating $\psi$ and $K$ to $\theta$ requires a water-retention
curve.  Six are available; the default van Genuchten form \citep{VanGenuchten1980}
gives a smooth, differentiable $\psi(\theta)$ with a continuous derivative at
saturation, which is important for stable implicit solves and for autodiff:
\begin{center}
\begin{tabular}{ll}
\toprule
Curve & $\psi(\theta)$ \\
\midrule
Van Genuchten (1980) & $\psi = \alpha^{-1}[(S_e^{-1/m}-1)^{1/n}]$ \\
Campbell (1974) & $\psi = \psi_s(S_e)^{-b}$ \\
Brooks--Corey (1964) & $\psi = \psi_d\,(S_e)^{-1/\lambda}$ \\
Clapp--Hornberger (1978) & Power-law form \\
\bottomrule
\end{tabular}
\end{center}
where $S_e = (\theta-\theta_r)/(\theta_{\mathrm{sat}}-\theta_r)$ is
effective saturation.

\paragraph{Root water uptake.}
Root distribution: $f_{\mathrm{root}}(z)=\exp(-z/z_{\mathrm{root}})$,
with default $z_{\mathrm{root}}=0.5$~m.
Plant-available water between wilting point ($\theta_{\mathrm{wp}}$)
and field capacity ($\theta_{\mathrm{fc}}$).

\subsection{Snow Budget}
\begin{equation}
  \frac{\dd h_{\mathrm{swe}}}{\dd t} = P_{\mathrm{snow}} - M,
  \qquad M = \max\!\Bigl(0,\;\frac{Q_{\mathrm{net}}}{\Lf\,\rho_w}\Bigr),
\end{equation}
with age-dependent albedo: $\alpha_{\mathrm{snow}}(t)=\alpha_{\max}\,e^{-t/\tau_{\mathrm{age}}}
+ \alpha_{\min}(1-e^{-t/\tau_{\mathrm{age}}})$.

\subsection{Soil Freezing and Thawing}
Optionally the soil column carries the latent heat of freezing and thawing of
its water, and the hydraulic conductivity of partly frozen soil is reduced by
the CLM5 ice impedance factor $10^{-e\,f_{\mathrm{ice}}}$, with
$f_{\mathrm{ice}}$ the ice fraction of the pore water and $e=6$ as in CLM5.
Both are enabled in the production configuration.

\section{Two-Leaf Canopy Surface Scheme}
\label{sec:two-leaf}

The default land surface scheme resolves the vegetation canopy as two big
leaves, sunlit and shaded, above a soil surface, sharing one canopy air space
(after the DifferBESS formulation).  Each call solves by Newton iteration for
the six-variable canopy state
\begin{equation}
  \bigl(T_{f,\mathrm{sun}},\,T_{f,\mathrm{sh}},\,C_{i,\mathrm{sun}},\,
  C_{i,\mathrm{sh}},\,T_c,\,q_c\bigr),
\end{equation}
the two leaf temperatures, the two intercellular CO$_2$ concentrations, and the
temperature and humidity of the canopy air.  The residuals are the leaf energy
balances, the coupling of Farquhar photosynthesis \citep{Farquhar1980} to
stomatal conductance (Ball--Berry by default, Medlyn optional), and the
conductance-weighted mixing of heat and vapour from leaves, soil and the
atmosphere into the canopy air.  Leaf latent heat uses the bulk-transfer form
$\lambda\rho(q_f-q_c)/(r_b+r_s)$ by default (a second-order
Penman--Monteith solution is optional), with the latent heat taken from the
temperature-dependent family of Section~\ref{sec:latent-heat}.  Shortwave
radiation is split into direct and diffuse components and partitioned
between sunlit and shaded leaves by a canopy radiative-transfer model.  An
outer Picard iteration reconciles the canopy's fast turbulent response with
the soil column's thermal time constant: the soil skin temperature is held
fixed during the Newton solve and updated between passes.  Above-canopy
stability follows Monin--Obukhov similarity, using the CLM5 functions on the
unstable side and the \citet{Beljaars1991} functions on the stable side.

Canopy parameters are supplied per plant functional type from the CLM
surface data set, and leaf area index, canopy height and wet-soil albedo are
refreshed through the season; a canopy run without that surface data is
refused rather than given generic constants.  The parameters are built by the
same routine as in the offline LMIP land simulations, so the coupled model
runs the land physics and calibrated parameters of the offline calibration.  Two alternatives
remain selectable: a simple surface energy balance (for idealised studies)
and the CLM-ML-JAX multilayer canopy, which resolves the canopy in many
layers and is coupled through the same surface-flux interface.

\paragraph{Land coupling interval.}
On the MPAS lane the land tile may be called once every
$\Delta t_{\mathrm{land}}$ seconds with the atmospheric forcing averaged over
the interval, so that the interval's mass and energy are conserved, and its
fluxes and skin temperature held in between.  The production configuration
uses $\Delta t_{\mathrm{land}}=1800$~s, the CAM6 land coupling interval.


\section{Land Carbon Cycle}
\label{sec:carbon}

\subsection{DALEC-990 Six-Pool Model}

Six prognostic pools: labile $C_{\mathrm{lab}}$, foliage $C_f$,
root $C_r$, wood $C_w$, litter $C_{\mathrm{lit}}$, and
soil organic matter $C_{\mathrm{SOM}}$.

\paragraph{Gross Primary Production (GPP).}
\begin{equation}
  \mathrm{GPP} = \varepsilon\,\mathrm{APAR}\,f_T\,f_{\mathrm{CO}_2}\,\beta,
  \qquad \mathrm{APAR} = f_{\mathrm{APAR}}\,\mathrm{PAR},
  \qquad f_{\mathrm{APAR}} = 1-e^{-k_{\mathrm{ext}}\,\mathrm{LAI}},
\end{equation}
where $\varepsilon$ is light-use efficiency, $f_T=\exp[-0.5((T-T_{\mathrm{opt}})/T_{\mathrm{width}})^2]$
is the Gaussian temperature response, and
$f_{\mathrm{CO}_2}=\mathrm{CO}_2/(K_{\mathrm{CO}_2}+\mathrm{CO}_2)$
is Michaelis--Menten CO$_2$ response.

\paragraph{Soil respiration.}
Exponential $Q_{10}$ temperature sensitivity with moisture limitation.

\subsection{Farquhar (1980) Photosynthesis}

The biochemical C3 photosynthesis model of \citet{Farquhar1980} represents
net assimilation as the slower of two co-limiting processes minus respiration:
\begin{equation}
  A = \min(W_c,\, W_j) - R_d,
\end{equation}
where $A$ is net assimilation, $W_c$ the Rubisco-limited and $W_j$ the
light- (RuBP-regeneration-)limited gross rate, and $R_d$ leaf dark respiration:
\begin{align}
  W_c &= V_{c,\max}\frac{C_i - \Gamma^*}{C_i + K_c(1+O/K_o)},
  & &\text{(Rubisco-limited)}, \\
  W_j &= \frac{J\,(C_i - \Gamma^*)}{4(C_i + 2\Gamma^*)},
  & &\text{(light-limited)}.
\end{align}
Here $C_i$ is the intercellular CO$_2$, $\Gamma^*$ the CO$_2$ compensation point,
$K_c$ and $K_o$ the Michaelis constants for carboxylation and oxygenation, $O$
the oxygen concentration, and $J$ the electron-transport rate.  The maximum
carboxylation capacity $V_{c,\max}$ and $J_{\max}$ follow peaked Arrhenius
temperature responses \citep{Bernacchi2001}, capturing the decline of enzyme
activity at high leaf temperature.  The co-limitation minimum is implemented as a
smooth (differentiable) function so the assimilation rate remains
gradient-friendly through the transition between the two regimes.

\subsection{Stomatal Conductance}

Three models couple stomata to photosynthesis.  The first two are empirical
optimality relations in which conductance $g_s$ scales with assimilation $A$ and
a humidity term, with $g_0$ the residual (cuticular) conductance and $g_1$ the
slope; closing the loop with the diffusion constraint $A=g_s(C_s-C_i)/1.6$ ties
the carbon and water exchange consistently.

\paragraph{Ball--Berry (1987).}
$g_s = g_0 + g_1\,A\,\mathrm{RH}/C_s$, with conductance proportional to relative
humidity $\mathrm{RH}$ at the leaf surface \citep{Ball1987}.

\paragraph{Medlyn (2011).}
$g_s = g_0 + 1.6\bigl(1+g_1/\!\sqrt{\mathrm{VPD}}\bigr)\,A/C_s$, derived from
stomatal optimisation theory and expressed through vapour-pressure deficit
$\mathrm{VPD}$ rather than relative humidity \citep{Medlyn2011}.

\paragraph{Jarvis (1976).}
$g_s = g_{s,\max}\,f(\mathrm{PAR})\,f(T)\,f(\mathrm{VPD})\,f(\theta)$,
a multiplicative environmental-stress reduction of a maximum conductance
(CO$_2$-independent; for when the carbon cycle is inactive), following the
\citet{Jarvis1976} formulation.

The coupled $A$--$g_s$--$C_i$ system is solved by 5 fixed-point
iterations, unrolled for JAX JIT compatibility.


\section{Plant Functional Types}
\label{sec:pft}

Land surface parameters are spatially heterogeneous and depend on vegetation type.  legoESM implements a CLM5-style Plant Functional Type (PFT) system with 17 types spanning needleleaf/broadleaf trees (evergreen and deciduous, temperate and tropical), shrubs, grasses (C3/C4), and crops.

\subsection{Parameter Lookup}

For each grid cell, the effective parameter $\bar{p}$ is a PFT-fraction-weighted average:
\begin{equation}
  \bar{p} = \sum_{k=1}^{17} f_k\,p_k,
\end{equation}
where $f_k$ is the fractional coverage of PFT~$k$ and $p_k$ is the parameter value for that type.

\subsection{Trainable Parameters}

Twelve land surface parameters are trainable per PFT: vegetation albedo ($\alpha_{\mathrm{veg}}$), emissivity ($\varepsilon$), roughness length ($z_0$), maximum soil water ($W_{\max}$), soil heat capacity ($C_{\mathrm{soil}}$), soil depth ($d_{\mathrm{soil}}$), root depth ($z_{\mathrm{root}}$), wilting point ($\theta_{\mathrm{wp}}$), field capacity ($\theta_{\mathrm{fc}}$), maximum carboxylation rate ($V_{c,\max,25}$), leaf carbon mass per area (LCMA), and stomatal slope ($g_1$).

Each parameter is bounded via sigmoid transforms:
\begin{equation}
  p = p_{\min} + (p_{\max}-p_{\min})\,\sigma(x_{\mathrm{raw}}),
\end{equation}
where $x_{\mathrm{raw}}$ is the unconstrained trainable value.

\subsection{Neural Parameter Provider}

An alternative to PFT lookup, a 3-hidden-layer fully connected network (GELU activation, 48 hidden units) maps static land features---cyclic latitude/longitude, one-hot soil type, normalised elevation, precipitation, temperature, and forest age---to the 12 land parameters.  Sigmoid output bounds match the PFT physical ranges.


\section{DifferLand: Differentiable Land Model Training}
\label{sec:differland}

The DifferLand framework enables end-to-end gradient-based optimisation of land surface and carbon cycle parameters.  Three carbon cycle modes are available:
\begin{itemize}[nosep]
  \item \textbf{none}: Carbon cycle disabled; LAI prescribed.
  \item \textbf{differland}: Prognostic DALEC-990 with trainable allocation fractions, decomposition rates, and phenology parameters.
  \item \textbf{seasonal}: Prescribed seasonal LAI cycle; carbon pools diagnostic only.
\end{itemize}

\subsection{Phenology}

Leaf emergence and fall follow hemisphere-aware Gaussian windows:
\begin{equation}
  f_{\mathrm{on}}(d) = \exp\!\Bigl[-\frac{(d-d_{\mathrm{Bday}})^2}{2\,\tau_{\mathrm{on}}^2}\Bigr],
  \qquad
  f_{\mathrm{off}}(d) = \exp\!\Bigl[-\frac{(d-d_{\mathrm{Fday}})^2}{2\,\tau_{\mathrm{off}}^2}\Bigr],
\end{equation}
where $d$ is the day of year, $d_{\mathrm{Bday}}$ and $d_{\mathrm{Fday}}$ are budburst and leaf-fall dates, and $\tau$ controls the transition width.

\subsection{Decomposition}

Litter and SOM decomposition rates follow $Q_{10}$ temperature sensitivity with moisture limitation:
\begin{equation}
  k(T,\theta) = k_0\,Q_{10}^{(T-T_{\mathrm{ref}})/10}\,f_w(\theta),
\end{equation}
where $f_w$ is a piecewise-linear function of soil moisture.

\subsection{NPP Allocation}

Net primary production ($\mathrm{NPP}=\mathrm{GPP}-R_a$) is allocated sequentially: foliar $\to$ labile $\to$ root $\to$ wood, with allocation fractions as trainable parameters.

\chapter{Sea Ice}
\label{ch:ice}
% #############################################################################

\section{Thermodynamic Slab}

The thermodynamics follow the zero-layer slab tradition of \citet{Semtner1976},
with the energy-conserving enthalpy refinements of \citet{BitzLipscomb1999}.

\subsection{Surface Temperature}
\begin{equation}
  \rho_i\,c_i\,\frac{h_{\mathrm{eff}}}{2}\,\frac{\dd T_i}{\dd t}
  = Q_{\mathrm{sfc}} - \frac{k_i(T_f-T_i)}{h_{\mathrm{eff}}},
  \qquad h_{\mathrm{eff}}=\max(h_i,h_{\min}).
\end{equation}
The ice surface temperature $T_i$ responds to the net surface flux $Q_{\mathrm{sfc}}$
balanced against conduction of heat from the freezing ocean interface at $T_f$
through the ice of effective thickness $h_{\mathrm{eff}}$ with conductivity
$k_i$.  The floor $h_{\min}$ keeps the conductive flux finite for vanishingly
thin ice.

\subsection{Growth and Melt}
\begin{equation}
  \frac{\dd h_i}{\dd t} = \frac{F_{\mathrm{cond}}-F_{\mathrm{ocean}}}
  {\rho_i\,\Lf}.
\end{equation}
The ice thickness $h_i$ grows when the conductive flux $F_{\mathrm{cond}}$
extracting heat upward exceeds the ocean heat flux $F_{\mathrm{ocean}}$ supplied
from below; the imbalance is converted to mass through the latent heat of fusion
$\Lf$.  The sign convention therefore ties freezing and melting directly to the
column energy budget.

\subsection{Concentration}
\begin{equation}
  \frac{\dd c}{\dd t} = \begin{cases}
    (\dd h/\dd t)(1-c)/h_{\mathrm{new}} & \text{growing},\\
    (\dd h/\dd t)\,c/h_{\mathrm{eff}} & \text{melting}.
  \end{cases}
\end{equation}


\paragraph{Surface latent heat.}
Sublimation from the ice surface is charged at the temperature-dependent
$\Ls(T_{\mathrm{ice}})$ of Section~\ref{sec:latent-heat}, evaluated at the
same skin temperature that sets the surface saturation humidity, and the heat
reported to the coupler is paired with the sublimated mass.

\section{Prognostic Sea-Ice Skin for Prescribed-Ice Runs}
\label{sec:ice-skin}

In AMIP runs the sea-ice concentration is prescribed and there is no ice
model, so without further treatment an ice-covered cell would sit at a fixed
temperature year-round, far warmer than the real winter ice surface.  On the
MPAS lane an optional prognostic skin temperature $T_s$ follows the
zero-layer conduction model of \citet{Semtner1976} through an ice slab of
climatological thickness $h$, with half the slab's heat capacity
$C=\rho_i c_{pi} h/2$ as thermal inertia:
\begin{equation}
  C\,\frac{\dd T_s}{\dd t} = F_{\mathrm{net}}
  + \frac{k_i}{h}\,\bigl(T_b - T_s\bigr),
\end{equation}
where $F_{\mathrm{net}}$ is the net downward surface energy flux (net
shortwave and longwave into the surface minus the upward sensible and latent
heat fluxes), $k_i$ the ice conductivity and $T_b$ the freezing point of
seawater at the ice base.  The conductive term is integrated backward-Euler,
which is unconditionally stable for any timestep; the surface cannot warm
above 0\,$^\circ$C, and an open-water cell resets to the seawater freezing
point so that it refreezes from there.  In polar night $F_{\mathrm{net}}<0$
and the skin cools until conduction from the ocean balances the loss,
$T_s=T_b+F_{\mathrm{net}}h/k_i$.  The production configuration enables it.

\section{EVP Rheology}

Following the elastic--viscous--plastic (EVP) rheology of
\citet{HunkeDukowicz1997}, the ice momentum equation is
\begin{equation}
  m\,\frac{\pp\vect{u}_i}{\pp t} = \vect{\tau}_a + \vect{\tau}_w
  - mf\hat{\vect{k}}\times\vect{u}_i
  - mg\grad\eta + \divg\bm{\sigma},
\end{equation}
where $m$ is the ice mass per unit area, $\vect{u}_i$ the ice velocity,
$\vect{\tau}_a$ and $\vect{\tau}_w$ the air and ocean stresses, $f$ the Coriolis
parameter, $\eta$ the sea-surface height, and $\bm{\sigma}$ the internal stress
tensor from an elliptic yield curve with eccentricity $e=2$.  The plastic limit
is the physical target; the elastic term is a numerical regularisation that lets
the equation be advanced by explicit subcycling rather than an implicit solve.
Ice strength:
\begin{equation}
  P = P^*\,h\,\exp\!\big(-C(1-c)\big),
  \qquad P^*=27.5\;\text{kPa},\; C=20.
\end{equation}
Here $P^*$ is the ice-strength parameter and $C$ the concentration-decay
constant, so the plastic strength rises with thickness $h$ and falls as the pack
opens ($c\to0$).  The elastic term provides subcycling stability
($N_{\mathrm{evp}}=120$ substeps); the modified (mEVP) formulation
\citep{Bouillon2013} recasts the relaxation so that the subcycled solution
converges to the same viscous--plastic limit independently of the substep count.


\section{Multi-Category Ice Thickness Distribution}

The subgrid ice-thickness distribution theory of \citet{Thorndike1975} treats
the ice pack as a probability distribution over thickness rather than a single
mean floe, which is essential because growth, melt, and the conductive flux are
all strongly nonlinear in thickness.  For $N_{\mathrm{cat}}>1$, per-category
state $(h_k,T_k,c_k)$ evolves independently under thermodynamics, then the
\citet{Lipscomb2001} linear remapping redistributes ice across thickness
categories, conservatively maintaining a well-resolved thickness distribution
without the numerical diffusion of a simple rebinning.


\section{Free-Drift Dynamics}

When \texttt{dynamics="free\_drift"}, ice velocity is diagnosed from ocean and atmospheric drag:
\begin{equation}
  \vect{u}_i = C_{\mathrm{ocean}}\,\vect{u}_{\mathrm{ocean}}
  + \frac{C_{\mathrm{atm}}\,\rho_{\mathrm{air}}}{\rho_{\mathrm{ice}}}\,\vect{u}_{\mathrm{wind}},
\end{equation}
with $C_{\mathrm{ocean}}=5.5\times10^{-3}$, $C_{\mathrm{atm}}=1.3\times10^{-3}$.

\section{Ice Tracer Transport}

When \texttt{transport="advect"}, ice thickness, concentration, and temperature are advected by the ice velocity field.  For multi-category ice, advection is applied independently to each category via \texttt{jax.vmap}.

\label{ch:coupler}

\section{Surface Flux Blending}

Fluxes are area-weighted blends over ocean, land, sea-ice, and lake tiles:
\begin{equation}
  X_{\mathrm{blend}} = f_{\mathrm{ocn}}\,X_{\mathrm{ocn}}
  + f_{\mathrm{land}}\,X_{\mathrm{land}}
  + f_{\mathrm{ice}}\,X_{\mathrm{ice}}
  + f_{\mathrm{lake}}\,X_{\mathrm{lake}}.
\end{equation}
Here $X$ is any surface flux (momentum, sensible heat, latent heat, or a
radiative quantity) and $f_{\mathrm{ocn}},f_{\mathrm{land}},f_{\mathrm{ice}},
f_{\mathrm{lake}}$ are the fractional areas of each subgrid tile within the grid
cell.  Each tile carries its own surface temperature and roughness and is run
through its own bulk-flux closure, then the fluxes are aggregated by area; the
constraint $\sum f_i = 1$ guarantees that the blended flux conserves the
grid-cell energy and momentum budgets.

\section{Ocean Albedo}

The ocean surface albedo uses the \citet{Briegleb1986} zenith-angle-dependent
formula:
\begin{equation}
  \alpha_{\mathrm{ocn}} = \frac{0.026}{1.1\,\mu_0^{1.7}+0.065}
  + 0.15\,(\mu_0-0.1)(\mu_0-0.5)(\mu_0-1.0),
\end{equation}
where $\mu_0=\cos\theta_z$ is the cosine of the solar zenith angle.  Albedo rises
sharply at low sun ($\mu_0\to0$), reproducing the strong glint of the ocean
under grazing illumination that a constant albedo would miss.

\section{Lake Model}

A two-layer model with epilimnion (warm, mixed, default depth $h_{\mathrm{epi}}=5$~m)
and hypolimnion (cold, deep, $h_{\mathrm{hypo}}=20$~m).

\subsection{Energy Balance}
The epilimnion temperature evolves under the surface energy budget:
\begin{equation}
  \rho_w\,c_w\,h_{\mathrm{epi}}\,\frac{\dd T_{\mathrm{epi}}}{\dd t}
  = \mathrm{SW}_{\mathrm{net}} + \mathrm{LW}_{\mathrm{net}} - \mathrm{SH} - \mathrm{LH} - F_{\mathrm{mix}},
\end{equation}
The mixed epilimnion of depth $h_{\mathrm{epi}}$, density $\rho_w$, and specific
heat $c_w$ stores the net surface radiation and turbulent fluxes, less the
downward mixing flux $F_{\mathrm{mix}}$ that ventilates heat into the
hypolimnion.  The mixing flux between the two layers is
\begin{equation}
  F_{\mathrm{mix}} = \rho_w\,c_w\,k_{\mathrm{eff}}\,\frac{T_{\mathrm{epi}}-T_{\mathrm{hypo}}}{d_{\mathrm{mid}}},
\end{equation}
with wind-enhanced effective diffusivity
$k_{\mathrm{eff}} = k_{\mathrm{mix}}\,(1+\alpha_{\mathrm{wind}}\,|\vect{V}|)$.

\subsection{Freezing}
Lake temperature is clamped at $T_f = 273.15$~K, the freezing point of fresh
water, below which further cooling is diverted into ice formation rather than
temperature.  Two surface bulk-flux options are provided: fixed exchange
coefficients, or an iterative scheme based on Monin--Obukhov similarity theory
\citep{MoninObukhov1954}, which makes the turbulent exchange coefficients depend
on the surface-layer stability rather than holding them constant.

\section{Spherical Fourier Neural Operator (SFNO)}

The Spherical Fourier Neural Operator \citep{Bonev2023} extends the Fourier
neural operator \citep{Li2021} from the periodic torus to the sphere by
replacing the planar FFT with the spherical-harmonic transform, so the learned
convolution kernel is rotationally consistent and free of the seam artifacts a
flat-FFT operator would imprint at the poles.  Because the spectral convolution
acts globally in one layer, the operator captures the long-range teleconnections
that a purely local convolution cannot, which is what makes it attractive as a
learned dynamical core or hybrid physics emulator in the spirit of
\citet{Kochkov2024}.

\subsection{Architecture}
\begin{enumerate}[nosep]
  \item \textbf{Encoder}: Pointwise linear $n_{\mathrm{in}}\to n_{\mathrm{emb}}$.
  \item \textbf{$N$ processor blocks}, each containing:
    \begin{itemize}[nosep]
      \item Layer normalisation,
      \item SH analysis $\to$ learned spectral convolution $\to$ SH synthesis,
      \item GELU activation,
      \item Pointwise MLP (two layers with expansion factor),
      \item Skip connection.
    \end{itemize}
  \item \textbf{Decoder}: Pointwise linear $n_{\mathrm{emb}}\to n_{\mathrm{out}}$.
  \item \textbf{Big-skip residual}: $\text{output}=\text{input}+\text{decoder}(\cdots)$.
\end{enumerate}

\subsection{Spectral Convolution}

In the SH coefficient space:
\begin{equation}
  \hat f_{nm}^{\mathrm{out}} = W_{nm}\,\hat f_{nm}^{\mathrm{in}},
\end{equation}
where $\hat f_{nm}^{\mathrm{in}}$ and $\hat f_{nm}^{\mathrm{out}}$ are the input
and output spherical-harmonic coefficients at total wavenumber $n$ and zonal
wavenumber $m$, and $W_{nm}\in\mathbb{R}^{n_{\mathrm{emb}}\times n_{\mathrm{emb}}}$
is a learnable weight matrix per wavenumber pair.  Mixing channels independently
at each $(n,m)$ makes the operation a true spectral convolution: it is diagonal
in the harmonic index, so the cost stays linear in the number of retained modes
while the kernel still couples every grid point through the inverse transform.

The SFNO can serve as a learned dynamical core or physics emulator within
the legoESM framework, sharing the same spectral transform infrastructure
as the conventional spectral cores.

\chapter{Data Assimilation}
\label{ch:da}
% #############################################################################

\section{Incremental 4D-Var}

legoESM provides a fully implemented incremental 4D-Var data assimilation
system \citep{Courtier1994,Rabier2000}, leveraging JAX's automatic
differentiation to compute exact adjoints without hand-coded tangent-linear or
adjoint models.  The incremental formulation of \citet{Courtier1994} linearises
the analysis problem about a background trajectory and solves for an increment,
which keeps the inner minimisation quadratic and tractable while the outer loop
relinearises about the updated state; here the JAX adjoint supplies the exact
gradient that the inner loop requires.

\subsection{Control Vector}

The control vector $\vect{x}$ comprises the prognostic atmospheric fields:
\begin{itemize}[nosep]
  \item Horizontal winds $(u, v)$;
  \item Temperature $T$;
  \item Specific humidity $q$;
  \item Surface pressure $p_s$.
\end{itemize}
The control vector specification supports both grid-point and spectral
representations, with configurable variable subsets for targeted assimilation.

\subsection{Cost Function}

The cost function minimises the sum of background and observation terms:
\begin{equation}
  J(\vect{x}) = \half(\vect{x}-\vect{x}_b)^T\mathbf{B}^{-1}(\vect{x}-\vect{x}_b)
  + \half\sum_i (\mathcal{H}_i[\mathcal{M}_{t_0\to t_i}(\vect{x})]-\vect{y}_i)^T
  \mathbf{R}_i^{-1}(\mathcal{H}_i[\mathcal{M}_{t_0\to t_i}(\vect{x})]-\vect{y}_i),
\end{equation}
where $\vect{x}_b$ is the background state, $\mathbf{B}$ is the background
error covariance, $\mathcal{M}_{t_0\to t_i}$ is the forward model propagating
the state from the analysis time $t_0$ to observation time $t_i$,
$\mathcal{H}_i$ are observation operators, $\vect{y}_i$ are observations, and
$\mathbf{R}_i$ are observation error covariances.  The first term penalises
departure from the prior weighted by its inverse covariance; the second
penalises model--observation mismatch summed over the assimilation window, so
the minimiser of $J$ is the trajectory that best reconciles the background with
all observations distributed in time \citep{Rabier2000}.

\subsection{Background Error Covariance}

Four $\mathbf{B}$ matrix families:
\begin{itemize}[nosep]
  \item \textbf{Diagonal}: $\mathbf{B}=\diag(\sigma_b^2)$;
  \item \textbf{Diffusion}: Implicit diffusion-based correlation modelling;
  \item \textbf{Spectral}: Diagonal in spectral space (scale-dependent variances);
  \item \textbf{Hybrid}: Linear combination of flow-dependent ensemble
    covariance and static $\mathbf{B}$.
\end{itemize}
The hybrid family blends a static climatological $\mathbf{B}$ with a
flow-dependent ensemble estimate; because a finite ensemble produces spurious
long-range correlations, the ensemble term is tapered by a compactly supported
Gaspari--Cohn correlation function \citep{GaspariCohn1999}, which sets distant
covariances exactly to zero while keeping the localised matrix positive
definite.

\subsection{Minimisation}

L-BFGS and conjugate gradient solvers with optional
$\mathbf{B}^{1/2}$ preconditioning for improved convergence.
The gradient $\grad_{\vect{x}}J$ is computed exactly via
\texttt{jax.grad} through the full forward model trajectory.

\subsection{Observation Operators}

Three observation operator types:
\begin{itemize}[nosep]
  \item \textbf{Direct}: Identity mapping for in-situ observations on model
    grid points;
  \item \textbf{Interpolating}: Bilinear/trilinear interpolation from model
    grid to observation locations;
  \item \textbf{Composite}: Chained operators for derived quantities
    (e.g., satellite radiances via a forward radiative transfer step).
\end{itemize}
All operators are JAX-differentiable, so \texttt{jax.grad} propagates
through observation-space transformations seamlessly.

\subsection{Analysis--Forecast Cycling}

Sequential cycling: the analysis from one assimilation window becomes the
background for the next, with checkpoint/restart support.

\subsection{Incremental Analysis Update}

To reduce initialisation shocks, the analysis increment
$\delta\vect{x}=\vect{x}_a-\vect{x}_b$ is applied gradually over an
IAU window of $N_{\mathrm{IAU}}$ timesteps:
\begin{equation}
  \vect{x}^{n+1} = \mathcal{M}(\vect{x}^n) + \frac{\delta\vect{x}}{N_{\mathrm{IAU}}},
  \qquad n = 0,\ldots,N_{\mathrm{IAU}}-1.
\end{equation}
Here $\vect{x}_a$ and $\vect{x}_b$ are the analysis and background states and
$\delta\vect{x}/N_{\mathrm{IAU}}$ is the fraction of the increment injected each
step.  Spreading the correction over the window lets the model's fast adjustment
processes absorb it in balance, so the gravity-wave noise that an instantaneous
insertion would excite is suppressed; this produces dynamically balanced
analyses and is the default cycling mode.

\chapter{Conservation and Numerical Corrections}
\label{ch:conservation}
% #############################################################################

\section{Atmospheric Mass Conservation}

Because surface pressure measures the column-integrated mass, any residual
imbalance left by the transport and physics updates appears as a drift in the
global mean $p_s$.  Dry-air mass is restored by a uniform adjustment to $p_s$:
\begin{equation}
  \Delta\bar p = \frac{\sum_i A_i\,p_{s,i}^{\mathrm{new}} - M_{\mathrm{target}}}
  {\sum_i A_i},
  \qquad
  p_{s,i}^{\mathrm{corr}} = p_{s,i}^{\mathrm{new}} - \Delta\bar p.
\end{equation}
Here $A_i$ is the cell area, $p_{s,i}^{\mathrm{new}}$ the uncorrected surface
pressure, and $M_{\mathrm{target}}$ the area-integrated mass to be conserved;
$\Delta\bar p$ is the area-weighted mean error subtracted uniformly from every
column.  A spatially constant offset removes the global drift without altering
horizontal pressure gradients, so the geostrophic balance and wind field are
left untouched.

\paragraph{Initial-mass anchoring.}
For long integrations, $M_{\mathrm{target}}=M_0=\sum_i A_i\,p_{s,i}^{\mathrm{init}}$
prevents cumulative $O(\varepsilon)$ drift.  All accumulations use float64.

\paragraph{Moisture conservation.}
Column moisture is rescaled:
$q^{\mathrm{corr}}=q^{\mathrm{new}}\cdot Q_{\mathrm{old}}/Q_{\mathrm{new}}$,
where $Q_{\mathrm{old}}$ and $Q_{\mathrm{new}}$ are the global water masses
before and after the update.  Multiplicative rescaling preserves the sign and
relative vertical structure of $q$, so positivity is maintained while the total
water is exactly restored.

\paragraph{Column-conserving tracer positivity.}
Transport undershoots leave small negative tracer values that must be
removed.  Clipping them to zero creates mass: on a state from a century AMIP
integration, one step of the plain clip invented water at a rate equivalent to
about 30~kg\,m$^{-2}$ per year.  Instead, the
deficit clipped in a column is borrowed back from that column's positive values
weighted by their true layer mass, so the column integral is unchanged; a
column whose total is itself negative passes the residual to a global
redistribution.  Each water species and each hydrometeor number concentration
is borrowed only from itself.  This borrow is the default on every
atmospheric grid; because it preserves every column integral it adds no column
water, although it moves water (and hence latent energy) between layers of the
column.

\paragraph{Energy-consistent moisture floor.}
Where a hard floor $q\ge0$ is used instead of the borrow (for example on the
physics-side vapour floors), the latent heat implied by the added water can
optionally be charged to the temperature (cooling for vapour, warming for the
ice species), so that the floor conserves moist static energy.  The
production configuration enables it.

\paragraph{Conservative vertical transport.}
The transport operators themselves are built to conserve where the fixers
cannot: the spectral core pairs its vertical transport of momentum and
temperature with continuity (Section~\ref{sec:spe}), and the MPAS hybrid lane
transports tracers vertically in a form whose column integral telescopes to
the boundary fluxes (Section~\ref{sec:pe}).

\section{Ocean Conservation}

The ocean's free surface plays the role surface pressure plays in the
atmosphere: the global-mean elevation $\eta$ records the total volume, so a
volume drift is removed by a uniform shift of $\eta$.
Volume: $\eta^{\mathrm{corr}}=\eta^{\mathrm{new}}
+(\sum\eta_{\mathrm{old}}\,A-\sum\eta_{\mathrm{new}}\,A)/\sum A$.

Heat and salt: uniform additive correction per unit volume.
All three grids (cubed-sphere, lat-lon, MPAS) compute corrections simultaneously from the original pre-fix state and upcast to accumulation precision before global reductions.

\textbf{Note:} These are uniform additive fixers that violate local conservation.  The proper solution is flux-form tracer advection with barotropic--baroclinic flux reconciliation.

\chapter{Differentiable Training}
\label{ch:training}
% #############################################################################

Because every component is written in differentiable JAX, the gradient of a
trajectory loss with respect to model parameters is available exactly through
the compiled time-stepping kernel, with no hand-coded adjoint.  This turns
parameter estimation, neural-network coupling, and hybrid learned--physical
modelling into a single optimisation problem.  The \texttt{training/} module
provides end-to-end differentiable training pipelines for three modes:

\section{Physics Parameter Tuning}

\texttt{TrainablePhysicsParams} wraps 8 physics parameters (convective
relaxation time, mixing length, drag coefficients, etc.) as an Equinox
module with sigmoid-based constraints mapping from unconstrained space to
valid physical ranges.  Gradients flow through
\texttt{eqx.filter\_value\_and\_grad} applied to the model's
\texttt{build\_segment\_fn(...).raw} (non-JIT, non-donating variant for AD
compatibility).

\section{Neural GCM Training}

Spectral neural GCM training couples a learned column model with the
spectral dynamical core.  The loss function combines area-weighted MSE,
spectral loss (penalising errors at each total wavenumber), and
per-variable MSE, imported from \texttt{ml/loss.py}.  Optimisation uses
\texttt{ml/training.create\_optimizer()} (warmup + cosine decay + gradient
clipping).

\section{SFNO--Dycore Coupling}

The Spherical Fourier Neural Operator can be coupled to any dynamical
core for hybrid learned--physical simulations.  Training uses the same
segment-based architecture, with \texttt{SegmentForcing} as an explicit
argument (not closure-captured) to prevent JIT recompilation when forcing
data changes.

\section{ERA5 Data Ingestion}

\texttt{era5\_to\_state.py} converts ERA5 reanalysis (lat-lon) to any
model grid with a local Zarr cache for efficient repeated access.
Vertical interpolation handles pressure-to-sigma/hybrid coordinate
mapping.

The \texttt{ParallelRuntime.create()} entry point detects MPI rank/size,
validates device counts, and routes to the correct halo/reduction backend.

\section{Domain Decomposition}

\paragraph{Cubed sphere.}
Valid device counts: 1, 2, 3, 6, and $6k^2$ for $k\ge 2$.
Each face can be further tiled into sub-face patches.
\texttt{initialize\_distributed(global\_n=N)} $\to$
\texttt{scatter\_to\_local()} distributes the global state to rank-local
patches; \texttt{gather\_to\_global()} is used only for I/O.

\paragraph{Voronoi/MPAS.}
The unstructured cell graph is partitioned by a capability-aware
\texttt{method="auto"} default: METIS $k$-way graph partitioning (via the
optional \texttt{pymetis} dependency, \texttt{pip install -e ".[mesh]"}) when
available, otherwise the dependency-free recursive coordinate bisection (RCB)
geometric partitioner.  Graph partitioning minimizes the edge cut, reducing both
load imbalance and halo (communication) volume on irregular or
variable-resolution meshes; on the near-uniform icosahedral mesh RCB is already
well balanced, so the METIS advantage grows with rank count (the
boundary/interior ratio rises).  A third \texttt{method="sfc"} orders cells along
a Hilbert space-filling curve and assigns balanced contiguous chunks --- a
dependency-free yet locality-preserving alternative.  Independently,
\texttt{reorder\_voronoi\_for\_sharding} orders cells \emph{within} each shard
along the Hilbert curve so every contiguous \texttt{NamedSharding} chunk is
spatially compact (cache and GPU memory locality).  Each rank's local arrays use
\emph{owned-first} indexing (owned cells precede halo cells), so owned-cell loops
are a contiguous slice.  A two-layer halo supports biharmonic operators.

\section{Numerical Precision}
\label{sec:precision}

Each run selects one precision policy, which assigns a floating-point type to
four roles --- storage of the state, computation in the kernels, accumulation
of sums and reductions, and control quantities such as solver residuals:
\begin{center}
\begin{tabular}{lcccc}
\toprule
Mode & Storage & Compute & Accumulate & Control \\
\midrule
\texttt{fp32} & 32 & 32 & 32 & 32 \\
\texttt{fp64} & 64 & 64 & 64 & 64 \\
\texttt{mixed} & 32 & 32 & 64 & 64 \\
\texttt{mixed\_fp64\_storage} & 64 & 32 & 64 & 64 \\
\bottomrule
\end{tabular}
\end{center}
The modes with float64 storage need a float64-capable backend.  The spectral
shallow-water and primitive-equation cores also offer a complex64 transform
path for float32 runs.  The production AMIP configuration runs in
\texttt{fp64}.

\section{MPI Differentiability}

All halo exchange \texttt{sendrecv} calls go through a
\texttt{@jax.custom\_vjp} wrapper (\texttt{\_sendrecv\_vjp}) that swaps
source and destination ranks in the backward pass, enabling
\texttt{jax.grad} through distributed halo exchange.  Global reductions
use AD-safe \texttt{allreduce(SUM)} with a custom VJP; \texttt{MAX},
\texttt{MIN}, \texttt{allgather}, and \texttt{bcast} are not
differentiable and are used only in diagnostics.  Conservation fixers
(\texttt{fix\_mass}, \texttt{zero\_mean\_tendency}) correctly flow
gradients through global reductions.

The native 4D halo exchange path (\texttt{pad\_halo\_4d},
\texttt{pad\_halo\_vector\_4d}) exchanges all vertical levels in one
MPI message per neighbour, replacing the earlier per-level
\texttt{vmap(pad\_halo)} which issued $n_{\mathrm{lev}}$ separate
messages.

\section{Ensemble Parallelism}

\texttt{jax.vmap} across ensemble members with \texttt{jax.lax.scan}
over time steps.  Support for perturbed initial conditions, ensemble
mean/std/percentile diagnostics, and gradient checkpointing.

\section{Multi-Device Collective Reductions}
\label{sec:gpu-scaling}

The 2026-05 GPU-scaling branch (\#228) compresses per-RK3 step
collectives across all dycore backends.  On the cubed-sphere
finite-volume path the four sequential allreduces (one per
prognostic variable) collapse to a single fused reduction with
shape $(B,h,h,n_{\mathrm{var}})$, cutting halo bandwidth by
${\sim}36\text{--}144\times$ at high resolution.  The spectral
primitive-equation core fuses the FFT and Legendre transforms into a
single pass and stacks per-tracer spherical-harmonic analyses; on
MPAS, MPI \texttt{sendrecv}s drop $12\to 6$ per substep and
mass-fix payloads $3\to 2$.  Fifteen SPMD-correctness unit tests
gate the changes and ensure SPMD-trace stability under JAX 0.10.
Real-hardware GPU/MPI validation on the Levante cluster is
described in \texttt{docs/REAL\_HARDWARE\_SCALING.md} and
\texttt{docs/GPU\_SCALING\_BRANCH.md}.

\texttt{start\_year} so multi-year files are sampled on their actual
calendar timeline rather than collapsed onto a 12-month cyclic axis.

\paragraph{Time-axis dispatch.}
For every channel, the loader inspects the file's CF \texttt{time:units}
and \texttt{calendar} attributes via \texttt{\_load\_time\_anchor} and
maps the simulation day onto the file's absolute axis through
\texttt{\_simday\_to\_file\_day}.  Cyclic 12-month climatologies and
multi-year transient series are dispatched automatically:
ozone files with $n_t > 12$ records preserve interannual evolution; the
volcanic file's 12-month layout per year is sampled at the active
calendar month so that 1982 (El Chich\'on) and 1991 (Pinatubo) appear
at the correct simulation dates.

\paragraph{GHG annual file.}
Each of \{CO$_2$, CH$_4$, N$_2$O, CFC-11, CFC-12\} is shape
$(n_t,1,1)$ with time units \texttt{"year as \%Y.\%f"}.  Linear
interpolation in fractional years yields scalar concentrations passed to
RRTMGP as volume mixing ratios via
\texttt{ghg\_concentrations\_to\_vmr}.  Unit scales (1e-6, 1e-9, 1e-12)
match input4MIPs convention.  GHG concentrations are consumed by
RRTMGP only --- the gray-radiation pathway uses a constant CO$_2$
optical depth and does not respond to the prescribed time series.

\paragraph{Ozone.}
$\mathrm{O}_3$ volume mixing ratio $X_{O_3}(t,\phi,p)$ is loaded with
auto-detection of variable name (\texttt{vmro3}, \texttt{tro3},
\texttt{O3}, \texttt{ozone}) and unit (mol mol$^{-1}$ vs.\ kg kg$^{-1}$
auto-converted).  The CMIP6 layout $(t,p,\phi,\lambda)$ is auto-swapped
to $(t,\phi,p)$ after a zonal mean.  Vertical interpolation in
\texttt{\_interp\_vertical} handles both ascending and descending
pressure axes (CMIP6 files ship $1000 \to 0.1$~hPa).

\paragraph{Solar TSI and 14-band SW.}
The MPI-M file provides daily \texttt{TSI}$(t)$ in W~m$^{-2}$ and
\texttt{SSI\_frac}$(t,n_{\mathrm{band}}{=}14)$ summing to one.  When
\texttt{source="spectral\_file"}, the 14 RRTMG-SW bands are expanded to
112~$g$-points by uniform fill within each band via
\texttt{\_expand\_bands\_to\_gpoints}; the per-$g$-point fractions are
passed into the SW solver to modulate the band-integrated insolation.
Solar geometry (zenith angle, declination) is computed analytically and
is not part of the prescribed forcing.

\paragraph{Aerosol and volcanic AOD.}
Background AOD is a zonal-mean monthly climatology
$(\mathrm{aod}_{550})(t,\phi)$.  Multi-band Kinne files
$(t, n_{\mathrm{band}}, \phi, \lambda)$ are reduced to $(t, \phi)$ by
zonal mean and band sum.  The volcanic channel adds a second AOD field
on top, with optional scaling \texttt{volcanic\_scale}; both are clipped
to $\mathrm{AOD} \ge 0$ before reaching the SW radiation pathway.

\paragraph{Deck driver.}
\texttt{scripts/run/run\_amip\_cmip6\_deck.py} pins a CMIP6 AMIP physics
stack of RRTMG radiation, Sundqvist cloud fraction, Sundqvist
large-scale condensation (the deck microphysics default --- Kessler
in the integrated AMIP path produces NaN winds at day ${\sim}2$ and
is tracked as a known issue), SBM convection, and Louis turbulence,
and fixes \texttt{--ghg-forcing external}, \texttt{--ozone-forcing external},
\texttt{--solar-source spectral\_file}, \texttt{--solar-tsi-var TSI},
\texttt{--solar-spectral-var SSI\_frac}.  When forcing files are
absent the user must opt in with \texttt{--auto-generate} to invoke
\texttt{scripts/data/generate\_amip\_forcing.py} for synthetic CMIP6-shape
replacements; otherwise the deck refuses to run.
\texttt{scripts/validate/validate\_amip\_run.py} reads the resulting CMOR
output for post-run sanity.

\paragraph{Multi-grid dispatch coverage.}
\texttt{scripts/validate/smoke\_test\_amip\_all\_grids.py} exercises the deck
\emph{dispatch path} on cubed-sphere (centred / FV3 / C-D), lat-lon
(centred / FV3 / C-grid), Gaussian spectral, and Voronoi/MPAS.
For run-time bound and stability the smoke test uses gray radiation
with aerosol and volcanic disabled (\texttt{--radiation gray
--no-aerosol --no-volcanic}); it confirms the (grid, discretisation,
forcing-loader) machinery wires up but does \emph{not} validate the
full forcing stack on every grid.  The Voronoi/MPAS smoke case runs with \texttt{--turbulence none},
since it checks the dycore and forcing wiring rather than realism (the
production deck runs CLUBB on MPAS), at the standard $600$~s step.  The MPAS run
path feeds the CMOR accumulators through a native-cell bridge that regrids to
the CMOR latitude--longitude grid (gathering the owned cells of every rank in
multi-rank runs); the spectral run path bypasses \texttt{DiagnosticCollector},
so detailed zonal/profile diagnostics are unavailable there.  Production AMIP
runs use the MPAS lane (Section~\ref{sec:production-amip}).

\chapter{Verification and Testing}
\label{ch:verification}
% #############################################################################

The legoESM codebase comprises approximately 385~source modules
($\sim$102{,}000~lines of code), validated by 3{,}489~tests across
216~test files.

\section{Williamson Standard Test Cases}
\label{sec:williamson}

The shallow water dynamical cores are verified against the standard
Williamson test suite \citep{Williamson1992}, the community benchmark set that
isolates the distinct error modes of a horizontal core:
\begin{itemize}[nosep]
  \item \textbf{Case 1}: Advection of a cosine bell;
  \item \textbf{Case 2}: Global steady-state nonlinear geostrophic flow;
  \item \textbf{Case 5}: Zonal flow over an isolated mountain;
  \item \textbf{Case 6}: Rossby--Haurwitz wave.
\end{itemize}
Each case probes a different property: Case~1 has an exact solution so it
measures pure advective accuracy and shape preservation; Case~2 is a steady
geostrophic state whose departure norm exposes spurious grid imprinting; Case~5
and the Rossby--Haurwitz wave of Case~6 test the nonlinear response to
topography and the maintenance of a propagating planetary wave.
A comprehensive diagnostic suite (\texttt{williamson\_diagnostic.py})
computes $L_1$, $L_2$, and $L_\infty$ error norms against analytical
solutions where available, and performs cross-discretisation comparison
across all five grid families (cubed-sphere C-D, spectral, finite-volume
lat-lon, C-grid lat-lon, and MPAS/Voronoi).

\section{Spectral Dynamical Core Test Suite}
\label{sec:spectral-tests}

The spectral transform dynamical cores (shallow water and primitive
equation) are validated by a dedicated comprehensive test suite covering:
\begin{itemize}[nosep]
  \item \textbf{Conservation}: Total mass, energy, and enstrophy
    conservation to machine precision (shallow water) and within
    bounded drift (primitive equation with hyperdiffusion);
  \item \textbf{Stability}: Long-integration stability under the dry
    Held--Suarez forcing \citep{HeldSuarez1994} --- Newtonian relaxation to a
    prescribed radiative-equilibrium temperature plus boundary-layer Rayleigh
    drag --- at T21/L40 and T42/L40 resolutions, which exercises the core's
    climate-statistics fidelity without any physics parameterisation;
  \item \textbf{Spectral convergence}: Verification that error norms
    decrease with increasing truncation wavenumber;
  \item \textbf{Semi-implicit correctness}: Validation that the implicit
    gravity-wave solver matches reference solutions and permits
    CFL numbers $>1$ for gravity-wave modes.
\end{itemize}

\section{Cross-Discretisation Intercomparison}

All five shallow water discretisations are compared on the same test
problems, verifying consistent convergence rates and inter-scheme
agreement in error norms.  This ensures that the shared physics interface
produces consistent results regardless of the dynamical core choice.

\section{MPI Distributed Tests}

Dedicated distributed test suites (\texttt{tests/distributed/}) verify:
\begin{itemize}[nosep]
  \item \textbf{Halo exchange correctness}: Scalar and vector 4D halo
    exchange on 2--6 ranks matches serial reference within round-off;
  \item \textbf{MPI differentiability}: \texttt{jax.grad} through
    halo-exchange and allreduce operations produces gradients matching
    single-rank reference (\texttt{test\_mpi\_differentiability.py});
  \item \textbf{MPI driver integration}: Full model stepping under MPI
    produces results consistent with serial execution
    (\texttt{test\_mpi\_driver.py}).
\end{itemize}
